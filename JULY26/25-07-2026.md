# 3536. Maximum Product of Two Digits

**Easy** | [LeetCode](https://leetcode.com/problems/maximum-product-of-two-digits/)

---

## Problem Statement

You are given a positive integer `n`.  
Return the **maximum** product of any two digits in `n`.

**Note:** You may use the same digit twice **if** it appears more than once in `n`.

---

## Examples

### Example 1
```

Input: n = 31
Output: 3
Explanation:

· The digits are [3, 1].
· The only product is 3 * 1 = 3.

```

### Example 2
```

Input: n = 22
Output: 4
Explanation:

· The digits are [2, 2].
· Products: 2 * 2 = 4.

```

### Example 3
```

Input: n = 124
Output: 8
Explanation:

· The digits are [1, 2, 4].
· Products: 12=2, 14=4, 2*4=8.
· Maximum is 8.

```

---

## Constraints
- `10 <= n <= 10^9`

---

## Approach

Since all digits are in the range `[0, 9]`, the maximum product is achieved by multiplying the **two largest digits** of `n`.

We must handle duplicate digits correctly:
- If the largest digit appears more than once, we can multiply it by itself.
- Otherwise, we multiply the largest and the second largest digit.

We can find these two largest digits in a single pass over the digits of `n` without storing them all.

### Algorithm
1. Initialize `max1 = -1` and `max2 = -1`.
2. While `n > 0`:
   - Extract the last digit `d = n % 10`.
   - If `d > max1`:
     - `max2 = max1`
     - `max1 = d`
   - Else if `d > max2`:
     - `max2 = d`
   - Remove the last digit: `n /= 10`
3. Return `max1 * max2`.

This ensures duplicates are considered because when a digit equals `max1` and `max2` is smaller, it will be assigned to `max2`.

---

## Complexity Analysis
- **Time Complexity:** `O(log n)` – at most 10 digits for the given constraint.
- **Space Complexity:** `O(1)` – only a few variables are used.

---

## Code

```java
class Solution {
    public int maxProduct(int n) {
        int max1 = -1, max2 = -1;
        
        while (n > 0) {
            int d = n % 10;
            
            if (d > max1) {
                max2 = max1;
                max1 = d;
            } else if (d > max2) {
                max2 = d;
            }
            
            n /= 10;
        }
        
        return max1 * max2;
    }
}
```

---

Alternative Solution (using sorting)

```java
class Solution {
    public int maxProduct(int n) {
        List<Integer> digits = new ArrayList<>();
        while (n > 0) {
            digits.add(n % 10);
            n /= 10;
        }
        Collections.sort(digits, Collections.reverseOrder());
        return digits.get(0) * digits.get(1);
    }
}
```

Both solutions are acceptable given the small number of digits.

---

Notes

· The problem guarantees at least two digits because n >= 10.
· If n contains a 0, the maximum product could be 0 (e.g., n = 10), which is correctly returned.
