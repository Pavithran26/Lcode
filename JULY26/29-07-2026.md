# 3518. Smallest Palindromic Rearrangement II (Hard).

## Problem Statement

You are given a palindromic string `s` and an integer `k`.

Return the **k‑th lexicographically smallest** palindromic permutation of `s`.  
If there are fewer than `k` distinct palindromic permutations, return an empty string.

> **Note:** Different rearrangements that yield the same palindromic string are considered identical and are counted once.

### Examples

**Example 1:**
```
Input: s = "abba", k = 2
Output: "baab"
Explanation: The two distinct palindromic rearrangements are "abba" and "baab".
Lexicographically, "abba" comes before "baab", so the 2nd one is "baab".
```

**Example 2:**
```
Input: s = "aa", k = 2
Output: ""
Explanation: There is only one palindromic rearrangement "aa". Since k = 2 exceeds the number, return "".
```

**Example 3:**
```
Input: s = "bacab", k = 1
Output: "abcba"
Explanation: The two distinct palindromic rearrangements are "abcba" and "bacab".
Lexicographically, "abcba" comes first.
```

## Approach

The solution uses **combinatorial counting** based on the first half of the palindrome.

### Key Observations

1. A palindrome of length `n` is fully determined by its first half (length `m = n // 2`) and an optional middle character when `n` is odd.

2. Counting distinct palindromic permutations is equivalent to counting distinct permutations of the **half‑string** (multiset of counts divided by 2).

3. The total number of distinct palindromic permutations is:

   \[
   \text{total} = \frac{m!}{\prod_{i=0}^{25} (\text{half}[i])!}
   \]

   where `half[i] = count[i] // 2`.

4. We construct the k‑th lexicographically smallest permutation of the half‑string using a **position‑by‑position** greedy approach.

   For each position, we try characters from `'a'` to `'z'`.  
   If the character `c` is available, we compute how many valid permutations start with `c` at the current position:

   \[
   \text{ways} = \frac{\text{total} \times \text{half}[c]}{\text{remaining positions}}
   \]

   - If `k <= ways`, we pick `c` and continue to the next position.
   - Otherwise, we subtract `ways` from `k` and try the next character.

5. After constructing the half, we build the full palindrome by appending the mirror of the half (and the middle character if present).

### Complexity

- **Time Complexity:** \(O(26 \cdot n)\), where `n` is the length of the string.  
  In practice, 26 is constant, so it is \(O(n)\).

- **Space Complexity:** \(O(n)\) for storing counts, factorials, and the result string.

## Java Solution

```java
import java.math.BigInteger;

class Solution {
    public String smallestPalindrome(String s, int k) {
        int n = s.length();
        int[] cnt = new int[26];
        for (char c : s.toCharArray()) {
            cnt[c - 'a']++;
        }

        int m = n / 2;
        int[] half = new int[26];
        for (int i = 0; i < 26; i++) {
            half[i] = cnt[i] / 2;
        }

        // Precompute factorials up to m
        BigInteger[] fact = new BigInteger[m + 1];
        fact[0] = BigInteger.ONE;
        for (int i = 1; i <= m; i++) {
            fact[i] = fact[i - 1].multiply(BigInteger.valueOf(i));
        }

        // Total distinct palindromic permutations
        BigInteger denom = BigInteger.ONE;
        for (int i = 0; i < 26; i++) {
            if (half[i] > 0) {
                denom = denom.multiply(fact[half[i]]);
            }
        }
        BigInteger total = fact[m].divide(denom);

        if (total.compareTo(BigInteger.valueOf(k)) < 0) {
            return "";
        }

        // Find middle character (only for odd length)
        int centerIdx = -1;
        if (n % 2 == 1) {
            for (int i = 0; i < 26; i++) {
                if (cnt[i] % 2 == 1) {
                    centerIdx = i;
                    break;
                }
            }
        }

        StringBuilder halfBuilder = new StringBuilder();
        int rem = m;

        // Greedily build the k‑th lexicographic half
        for (int pos = 0; pos < m; pos++) {
            for (int c = 0; c < 26; c++) {
                if (half[c] == 0) continue;

                // Number of valid half‑strings if we put 'a'+c at this position
                BigInteger ways = total
                        .multiply(BigInteger.valueOf(half[c]))
                        .divide(BigInteger.valueOf(rem));

                if (ways.compareTo(BigInteger.valueOf(k)) >= 0) {
                    halfBuilder.append((char) ('a' + c));
                    half[c]--;
                    total = ways;
                    rem--;
                    break;
                } else {
                    k -= ways.intValue();
                }
            }
        }

        String halfStr = halfBuilder.toString();
        StringBuilder ans = new StringBuilder(halfStr);

        if (centerIdx != -1) {
            ans.append((char) ('a' + centerIdx));
        }

        ans.append(new StringBuilder(halfStr).reverse());
        return ans.toString();
    }
}
```

## Constraints

- `1 <= s.length <= 10^4`
- `s` consists of lowercase English letters.
- `s` is guaranteed to be palindromic.
- `1 <= k <= 10^6`

## Usage

Compile and run with your favorite Java environment. The method `smallestPalindrome` expects a string `s` and an integer `k`, and returns the result as described.
