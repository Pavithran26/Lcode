# 3014. Minimum Number of Pushes to Type Word I

[LeetCode Problem Link](https://leetcode.com/problems/minimum-number-of-pushes-to-type-word-i/)

## Problem Statement

You are given a string `word` containing distinct lowercase English letters.  
Telephone keypads have keys 2–9 (8 keys total) that can be remapped to any collections of letters. Each letter must be mapped to exactly one key, and each key can hold any number of letters.

To type a letter, you press its key a certain number of times:
- The first letter on a key requires 1 push,
- the second requires 2 pushes,
- and so on.

You need to find the **minimum** total number of key pushes required to type the entire `word` after optimally remapping the letters to the 8 keys.

### Constraints
- `1 <= word.length <= 26`
- `word` consists of lowercase English letters.
- All letters in `word` are **distinct**.

---

## Example

**Example 1**  
Input: `word = "abcde"`  
Output: `5`  
Explanation:  
Map each of the 5 letters to a different key as the first letter → each costs 1 push → total 5.

"e"->1, "f"->1, "g"->1, "h"->1, "i"->1, "j"->1 → that's 6 more.

Thus with 10 letters, we need to distribute them among 8 keys to minimize sum of positions (1-indexed) per key. The optimal is to fill keys as evenly as possible: first 8 letters get position 1, next 8 get position 2, etc. Since 10 = 8 + 2, we have 8 letters at position 1 and 2 letters at position 2. So the problem reduces to: we have n distinct letters; we assign each to a position (1,2,3,...) on a key. There are 8 keys, so at each position we can have up to 8 letters. To minimize total sum, we assign letters to the smallest positions first. So the cost = sum_{i=0}^{n-1} ( floor(i/8) + 1 ), where i is 0-indexed.

## Approach

Since all letters are distinct, the actual characters don't matter—only the length `n` of `word`.

We need to place `n` letters across 8 keys, with each key having a sequence of positions (1st, 2nd, 3rd, ...). The cost for a letter is its position on its key.

To minimize total cost, we should fill positions in increasing order:
- First, put as many letters as possible in position 1 (up to 8 letters).
- Then position 2 (next 8), and so on.

Thus, the cost = number of letters in position 1 * 1 + number in position 2 * 2 + ...

Mathematically:
Let `n` be the length.  
Let `fullGroups = n / 8` (number of complete groups of 8 that get filled).  
Let `remaining = n % 8` (letters in the next group).

The cost = sum_{k=1}^{fullGroups} 8 * k + remaining * (fullGroups + 1).  
This is because the first 8 letters cost 1 each, next 8 cost 2 each, etc.  
Simplify: `8 * (1+2+...+fullGroups) + remaining * (fullGroups+1)`  
= `8 * fullGroups*(fullGroups+1)/2 + remaining*(fullGroups+1)`  
= `4 * fullGroups*(fullGroups+1) + remaining*(fullGroups+1)`.

Alternatively, we can iterate over the indices and sum `i/8 + 1`.

---

## Complexity Analysis

- **Time Complexity:** O(n) if iterating, or O(1) using formula.
- **Space Complexity:** O(1).

---

## Solution Code (Java)

### Iterative Approach
```java
class Solution {
    public int minimumPushes(String word) {
        int n = word.length();
        int pushes = 0;
        for (int i = 0; i < n; i++) {
            pushes += i / 8 + 1;
        }
        return pushes;
    }
}
```

### Formula Approach (O(1))
```java
class Solution {
    public int minimumPushes(String word) {
        int n = word.length();
        int fullGroups = n / 8;
        int remaining = n % 8;
        return 4 * fullGroups * (fullGroups + 1) + remaining * (fullGroups + 1);
    }
}
```

---

## Explanation of Formula

- `fullGroups` = how many times we completely fill all 8 keys with the same position number.
- `remaining` = extra letters that will be placed at position `fullGroups + 1`.
- Sum of costs for full groups: each group of 8 costs `8 * groupNumber`. Sum over groupNumber from 1 to fullGroups is `8 * fullGroups*(fullGroups+1)/2` = `4 * fullGroups*(fullGroups+1)`.
- Remaining letters each cost `(fullGroups+1)`, so add `remaining * (fullGroups+1)`.
