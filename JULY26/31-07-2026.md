# 3016. Minimum Number of Pushes to Type Word II

[LeetCode Problem Link](https://leetcode.com/problems/minimum-number-of-pushes-to-type-word-ii/)

## Problem Statement

You are given a string `word` containing lowercase English letters.

Telephone keypads have keys mapped with distinct collections of lowercase English letters. For example, the key `2` is mapped with `["a","b","c"]`:
- Push once to type `"a"`
- Push twice to type `"b"`
- Push three times to type `"c"`

We are allowed to **remap** the keys numbered `2` to `9` to **any** distinct collections of letters. Each letter must be mapped to exactly one key. Keys may have any number of letters (including zero).

Find the **minimum** total number of key pushes needed to type the given `word`.

---

## Examples

### Example 1
```
Input: word = "abcde"
Output: 5
```
**Explanation:** Map each letter to a different key as the first letter → cost = 1 per letter.

### Example 2
```
Input: word = "xyzxyzxyzxyz"
Output: 12
```
**Explanation:** `x`, `y`, `z` each appear 4 times. Map them as first letters on 3 keys → total = `4+4+4 = 12`.

### Example 3
```
Input: word = "aabbccddeeffgghhiiiiii"
Output: 24
```

---

## Key Insight

Since we can remap letters arbitrarily, the optimal strategy is:

- Assign the **most frequent** letters to the **cheapest** positions on the keys.
- There are **8 keys** (numbers 2–9).
- On each key:
  - 1ˢᵗ letter costs `1` push
  - 2ⁿᵈ letter costs `2` pushes
  - 3ʳᵈ letter costs `3` pushes
  - 4ᵗʰ letter costs `4` pushes
- Therefore, the first 8 most frequent letters cost `1` each, the next 8 cost `2` each, etc.

---

## Algorithm

1. Count the frequency of each of the 26 lowercase letters in `word`.
2. Sort the frequencies in **descending** order.
3. Iterate over the sorted frequencies:
   - For the letter at index `i` (0‑based), its push cost is `(i / 8) + 1`.
   - Add `freq * cost` to the total answer.
4. Return the total.

**Time Complexity:** `O(n + 26 log 26)` → effectively `O(n)`  
**Space Complexity:** `O(1)` (fixed 26 counters)

---

## Java Solution

```java
import java.util.*;

class Solution {
    public int minimumPushes(String word) {
        int[] freq = new int[26];
        for (char c : word.toCharArray()) {
            freq[c - 'a']++;
        }
        
        // Convert to Integer array and sort descending
        Integer[] counts = Arrays.stream(freq).boxed().toArray(Integer[]::new);
        Arrays.sort(counts, Collections.reverseOrder());
        
        int totalPushes = 0;
        for (int i = 0; i < 26; i++) {
            if (counts[i] == 0) break;
            int pressCost = (i / 8) + 1;  // 1 for first 8, 2 for next 8, etc.
            totalPushes += counts[i] * pressCost;
        }
        return totalPushes;
    }
}
```

## Step‑by‑Step Walkthrough (Example 3)

Frequencies:
- `i` → 6
- `a`, `b`, `c`, `d`, `e`, `f`, `g`, `h` → 2 each (8 letters)

Sorted: `[6, 2, 2, 2, 2, 2, 2, 2, 2, 0, ...]`

| Index | Letter | Frequency | Push Cost | Contribution |
|-------|--------|-----------|-----------|--------------|
| 0     | i      | 6         | 1         | 6 × 1 = 6    |
| 1–7   | a–g    | 2 × 7     | 1         | 14 × 1 = 14  |
| 8     | h      | 2         | 2         | 2 × 2 = 4    |
| **Total** |        |           |           | **24**       |

Matches the expected output.

---

## Notes

- The keys `1`, `*`, `#`, and `0` are not used.
- We don't have to map letters to every key; unused keys are allowed.
- Greedy assignment of highest frequencies to lowest push costs guarantees optimality.
