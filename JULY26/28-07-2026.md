# 3517. Smallest Palindromic Rearrangement I

**Difficulty:** Medium  
**Topics:** String, Greedy, Counting  
**Companies:** Premium Lock Icon  
**Hint:** Given a palindromic string `s`, return the lexicographically smallest palindromic permutation of `s`.

---

## Problem Statement

You are given a palindromic string `s`. Return the **lexicographically smallest** palindromic permutation of `s`.

### Examples

#### Example 1
```
Input: s = "z"
Output: "z"
```
**Explanation:** A string of only one character is already the lexicographically smallest palindrome.

#### Example 2
```
Input: s = "babab"
Output: "abbba"
```
**Explanation:** Rearranging `"babab"` → `"abbba"` gives the smallest lexicographic palindrome.

#### Example 3
```
Input: s = "daccad"
Output: "acddca"
```
**Explanation:** Rearranging `"daccad"` → `"acddca"` gives the smallest lexicographic palindrome.

---

## Constraints

- `1 <= s.length <= 10^5`
- `s` consists of lowercase English letters.
- `s` is **guaranteed** to be palindromic.

---

## Approach

Since `s` is already a palindrome, its character frequencies are symmetric: at most one character can have an odd count (the middle character). To obtain the lexicographically smallest palindrome, we need to arrange the **left half** in ascending order, place the middle character (if any) in the center, and mirror the left half for the right half.

### Steps

1. **Count frequencies** of each character in `s`.
2. **Build the left half** by taking `count / 2` of each character, iterating from `'a'` to `'z'` (ascending order).
3. **Identify the middle character** – it will be the character with an odd frequency (at most one).
4. **Construct the result** as:
   ```
   left + middle + reverse(left)
   ```
5. Return the resulting string.

This greedy approach ensures the smallest lexicographic order because we place the smallest possible characters at the earliest positions of the left half.

---

## Complexity Analysis

- **Time Complexity:** `O(n)`, where `n` is the length of `s`. We iterate over the string once to build frequencies and then over the 26 lowercase letters to build the result.
- **Space Complexity:** `O(n)` for the output string (or `O(1)` if we consider the fixed-size frequency array and output not counted).

---

## Code (Java)

```java
class Solution {
    public String smallestPalindrome(String s) {
        int[] freq = new int[26];
        for (char c : s.toCharArray()) {
            freq[c - 'a']++;
        }

        StringBuilder left = new StringBuilder();
        char middle = 0;

        for (int i = 0; i < 26; i++) {
            char c = (char) ('a' + i);
            // Add half of the occurrences to the left half
            for (int j = 0; j < freq[i] / 2; j++) {
                left.append(c);
            }
            // Track the character with odd count
            if (freq[i] % 2 == 1) {
                middle = c;
            }
        }

        String right = new StringBuilder(left).reverse().toString();
        String middleStr = middle == 0 ? "" : String.valueOf(middle);

        return left.toString() + middleStr + right;
    }
}
```
