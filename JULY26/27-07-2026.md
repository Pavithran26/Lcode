# LeetCode 1464. Maximum Product of Two Elements in an Array

[![LeetCode](https://img.shields.io/badge/LeetCode-1464-orange)](https://leetcode.com/problems/maximum-product-of-two-elements-in-an-array/)
[![Difficulty](https://img.shields.io/badge/Difficulty-Easy-brightgreen)](https://leetcode.com/problems/maximum-product-of-two-elements-in-an-array/)
[![Language](https://img.shields.io/badge/Language-Java-blue)](https://www.java.com/)

## 📝 Problem Statement

Given the array of integers `nums`, you will choose **two different indices** `i` and `j` of that array.  
Return the maximum value of `(nums[i] - 1) * (nums[j] - 1)`.

---

### 🔍 Examples

#### Example 1:
```
Input: nums = [3,4,5,2]
Output: 12
Explanation: 
Choose indices i=1 (4) and j=2 (5).
(4-1)*(5-1) = 3*4 = 12
```

#### Example 2:
```
Input: nums = [1,5,4,5]
Output: 16
Explanation: 
Choose indices i=1 (5) and j=3 (5).
(5-1)*(5-1) = 4*4 = 16
```

#### Example 3:
```
Input: nums = [3,7]
Output: 12
Explanation: 
(7-1)*(3-1) = 6*2 = 12
```

---

### 📌 Constraints

- `2 <= nums.length <= 500`
- `1 <= nums[i] <= 10^3`

---

## 🧠 Solution Approach

The product `(nums[i] - 1) * (nums[j] - 1)` is **maximized** when we pick the **two largest** numbers from the array.

Since `nums[i] >= 1`, subtracting `1` does not change the relative ordering of the numbers.  
Therefore, we simply need to find the **first** and **second maximum** values in the array.

### Algorithm (Single Pass)

We can find the two largest elements in **one pass** without sorting:

1. Initialize `max1` and `max2` to `Integer.MIN_VALUE`.
2. For each number `num` in `nums`:
   - If `num > max1`, shift `max1` to `max2` and update `max1` to `num`.
   - Else if `num > max2`, update `max2` to `num`.
3. Return `(max1 - 1) * (max2 - 1)`.

This avoids the O(n log n) sorting overhead and is optimal for this problem.

---

## 💻 Java Code

```java
class Solution {
    public int maxProduct(int[] nums) {
        // Initialize the two largest values
        int max1 = Integer.MIN_VALUE;
        int max2 = Integer.MIN_VALUE;
        
        for (int num : nums) {
            if (num > max1) {
                // New largest found: shift previous largest to second
                max2 = max1;
                max1 = num;
            } else if (num > max2) {
                // New second largest found
                max2 = num;
            }
        }
        
        return (max1 - 1) * (max2 - 1);
    }
}
```

---

## ⏱️ Complexity Analysis

- **Time Complexity:** `O(n)` – we iterate through the array exactly once.
- **Space Complexity:** `O(1)` – only two integer variables are used.

---

## 🔄 Alternative Approach

A simpler alternative is to **sort** the array and pick the last two elements:

```java
Arrays.sort(nums);
int n = nums.length;
return (nums[n-1] - 1) * (nums[n-2] - 1);
```

This also gives the correct answer, but the time complexity is `O(n log n)`.

---

## ✅ Key Takeaways

- Recognizing that the maximum product comes from the two largest numbers is the core insight.
- Using a single pass keeps the solution efficient and optimal.
- The problem is a straightforward application of finding top-k elements (where k=2).
