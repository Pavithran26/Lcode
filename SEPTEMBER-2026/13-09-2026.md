# 835. Image Overlap

## Problem

You are given two binary square matrices `img1` and `img2` of size `n x n`.

You can translate one image by sliding all `1` bits left, right, up, and/or down any number of units.  
Then you place it on top of the other image.

The **overlap** is the number of positions that have a `1` in both images.

Return the **largest possible overlap**.

### Example 1

```text
Input: img1 = [[1,1,0],[0,1,0],[0,1,0]], img2 = [[0,0,0],[0,1,1],[0,0,1]]
Output: 3
```

### Example 2

```text
Input: img1 = [[1]], img2 = [[1]]
Output: 1
```

### Example 3

```text
Input: img1 = [[0]], img2 = [[0]]
Output: 0
```

### Constraints

- `n == img1.length == img1[i].length`
- `n == img2.length == img2[i].length`
- `1 <= n <= 30`
- `img1[i][j]` is either `0` or `1`
- `img2[i][j]` is either `0` or `1`

---

## Approach

Instead of trying every possible translation directly, we can record all `1` positions in both images.

For every `1` in `img1` and every `1` in `img2`, compute the offset needed to align them:

```text
offsetRow = row2 - row1
offsetCol = col2 - col1
```

If many pairs of `1`s share the same offset, then translating one image by that offset will make all those pairs overlap.

We count how many pairs produce each offset and return the maximum count.

To handle negative offsets easily, we shift the offset by `n` when storing it in a 2D array.

---

## Algorithm

1. Collect coordinates of all `1`s in `img1` into `ones1`.
2. Collect coordinates of all `1`s in `img2` into `ones2`.
3. Create a 2D counter array of size `2n x 2n`.
4. For each `(r1, c1)` in `ones1` and `(r2, c2)` in `ones2`:
   - Compute `dr = r2 - r1 + n`
   - Compute `dc = c2 - c1 + n`
   - Increment `count[dr][dc]`
   - Update the answer with the new count.
5. Return the maximum count.

---

## Complexity

- **Time Complexity:** `O(n^4)` in the worst case, because there can be `O(n^2)` ones in each image.
- **Space Complexity:** `O(n^2)` for the offset counter array.

With `n <= 30`, this is efficient enough.

---

## Java Solution

```java
import java.util.*;

class Solution {
    public int largestOverlap(int[][] img1, int[][] img2) {
        int n = img1.length;
        List<int[]> ones1 = new ArrayList<>();
        List<int[]> ones2 = new ArrayList<>();

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (img1[i][j] == 1) ones1.add(new int[]{i, j});
                if (img2[i][j] == 1) ones2.add(new int[]{i, j});
            }
        }

        // Offset range is from -(n-1) to (n-1), so shift by n.
        int[][] count = new int[2 * n][2 * n];
        int ans = 0;

        for (int[] p : ones1) {
            for (int[] q : ones2) {
                int dr = q[0] - p[0] + n;
                int dc = q[1] - p[1] + n;

                ans = Math.max(ans, ++count[dr][dc]);
            }
        }

        return ans;
    }
}
