# LeetCode 3524. Find X Value of Array I

## Problem

You are given an array of positive integers `nums`, and a positive integer `k`.

You are allowed to perform an operation once on `nums`, where in each operation you can remove any non-overlapping prefix and suffix from `nums` such that `nums` remains non-empty.

You need to find the x-value of `nums`, which is the number of ways to perform this operation so that the product of the remaining elements leaves a remainder of `x` when divided by `k`.

Return an array `result` of size `k` where `result[x]` is the x-value of `nums` for `0 <= x <= k - 1`.

A prefix of an array is a subarray that starts from the beginning of the array and extends to any point within it.

A suffix of an array is a subarray that starts at any point within the array and extends to the end of the array.

Note that the prefix and suffix to be chosen for the operation can be empty.

## Examples

### Example 1

```text
Input: nums = [1,2,3,4,5], k = 3
Output: [9,2,4]
```

### Example 2

```text
Input: nums = [1,2,4,8,16,32], k = 4
Output: [18,1,2,0]
```

### Example 3

```text
Input: nums = [1,1,2,1,1], k = 2
Output: [9,6]
```

## Constraints

- `1 <= nums[i] <= 10^9`
- `1 <= nums.length <= 10^5`
- `1 <= k <= 5`

## Approach

Removing a prefix and a suffix from `nums` leaves a **contiguous subarray**.  
So the problem is equivalent to counting all non-empty contiguous subarrays whose product modulo `k` equals each `x`.

We can solve this with dynamic programming over remainders.

Let `dp[r]` be the number of subarrays ending at the previous index whose product modulo `k` is `r`.

For each number `num` in `nums`:

1. Compute `rem = num % k`.
2. Start a new subarray consisting only of `num`:  
   `cur[rem] = 1`
3. Extend all previous subarrays ending at the previous index:  
   For each remainder `r`, if `dp[r] > 0`, then  
   `cur[(r * rem) % k] += dp[r]`
4. Add all values of `cur` to the final answer.
5. Set `dp = cur`.

Since `k <= 5`, this is very efficient.

## Complexity

- **Time:** `O(n * k)`
- **Space:** `O(k)`

## Java Solution

```java
class Solution {
    public long[] resultArray(int[] nums, int k) {
        long[] ans = new long[k];
        long[] prev = new long[k];

        for (int num : nums) {
            int rem = num % k;
            long[] cur = new long[k];

            // Subarray consisting only of the current element
            cur[rem] = 1;

            // Extend all subarrays ending at the previous position
            for (int r = 0; r < k; r++) {
                if (prev[r] > 0) {
                    int newRem = (r * rem) % k;
                    cur[newRem] += prev[r];
                }
            }

            for (int r = 0; r < k; r++) {
                ans[r] += cur[r];
            }

            prev = cur;
        }

        return ans;
    }
}
```
