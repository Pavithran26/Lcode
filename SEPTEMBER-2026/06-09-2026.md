# 115. Distinct Subsequences

## Problem Statement

Given two strings `s` and `t`, return the number of distinct **subsequences** of `s` which equal `t`.

The answer is guaranteed to fit in a 32-bit signed integer.

### Examples

**Example 1:**
```

Input: s = "rabbbit", t = "rabbit"
Output: 3

```
There are 3 ways to form `"rabbit"` from `"rabbbit"`.

**Example 2:**
```

Input: s = "babgbag", t = "bag"
Output: 5

```

### Constraints
- `1 <= s.length, t.length <= 1000`
- `s` and `t` consist of English letters.

---

## Approach

We use **Dynamic Programming** with space optimization (1D array).

### DP Definition
Let `dp[j]` represent the number of ways to form the prefix `t[0..j-1]` using the currently processed prefix of `s`.

### Base Case
- `dp[0] = 1` — there is exactly 1 way to form an empty string (choose no characters).

### Transition
Iterate through each character `ch` in `s` (from left to right). For each character, update the DP array from **right to left** (`j = t.length` down to `1`):

- If `ch == t.charAt(j-1)`, then we can either:
  - Skip this character (value stays the same),
  - Match it with `t[j-1]`, adding the number of ways to form `t[0..j-2]` (i.e., `dp[j-1]`).

Thus:
```

if (ch == t.charAt(j-1)) {
dp[j] += dp[j-1];
}

```

### Why iterate backwards?
This ensures that when computing `dp[j]`, we use `dp[j-1]` from the **previous** iteration of `s` (i.e., before processing the current character). If we iterated forward, we would reuse the same character multiple times (unbounded subsequences), which is incorrect.

### Final Answer
`dp[t.length()]` gives the number of distinct subsequences of `s` equal to `t`.

---

## Complexity Analysis

- **Time Complexity:** `O(m * n)` — where `m = s.length()` and `n = t.length()`. We iterate over every character of `s` and for each we traverse up to `n`.
- **Space Complexity:** `O(n)` — only a 1D array of size `n+1` is used.

---

## Java Code

```java
class Solution {
    public int numDistinct(String s, String t) {
        int m = s.length();
        int n = t.length();
        
        // dp[j] = number of ways to form t[0..j-1] from processed part of s
        int[] dp = new int[n + 1];
        dp[0] = 1; // empty subsequence
        
        for (int i = 0; i < m; i++) {
            char ch = s.charAt(i);
            // Traverse backwards to avoid reusing the same character
            for (int j = n; j >= 1; j--) {
                if (ch == t.charAt(j - 1)) {
                    dp[j] += dp[j - 1];
                }
            }
        }
        
        return dp[n];
    }
}
```

---

Key Takeaways

· Classic DP problem for counting subsequences.
· Space optimization from 2D to 1D is possible because transition for dp[i][j] depends only on dp[i-1][j] and dp[i-1][j-1].
· Reverse iteration is crucial to maintain the "distinct" property (each character used at most once).
