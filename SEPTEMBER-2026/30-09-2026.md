# 1111. Maximum Nesting Depth of Two Valid Parentheses Strings

## Problem Statement

A string is a **valid parentheses string (VPS)** if and only if it consists of `"("` and `")"` characters only, and:

- It is the empty string, or
- It can be written as `AB` (A concatenated with B), where A and B are VPS's, or
- It can be written as `(A)`, where A is a VPS.

We define the **nesting depth** `depth(S)` of any VPS S as follows:

- `depth("") = 0`
- `depth(A + B) = max(depth(A), depth(B))`, where A and B are VPS's
- `depth("(" + A + ")") = 1 + depth(A)`, where A is a VPS

Given a VPS `seq`, split it into two disjoint subsequences A and B, such that A and B are VPS's (and `A.length + B.length = seq.length`). The subsequences may not necessarily be contiguous.

Choose any such A and B such that `max(depth(A), depth(B))` is the **minimum possible** value.

Return an answer array (of length `seq.length`) that encodes such a choice of A and B: `answer[i] = 0` if `seq[i]` is part of A, else `answer[i] = 1`.

## Approach

### Key Insight

The optimal strategy is to **distribute the nesting depth evenly** between the two groups. Since the maximum depth of the original string is `D`, the best we can do is give each group a depth of at most `ceil(D / 2)`.

We can achieve this by assigning parentheses to groups based on the **parity of the current nesting depth**.

### Algorithm

1. Initialize `depth = 0` and an empty result list.
2. Traverse each character in `seq`:
   - If the character is `'('`:
     - Assign it to group `depth % 2`
     - Increment `depth`
   - If the character is `')'`:
     - Decrement `depth`
     - Assign it to group `depth % 2`
3. Return the result list.

### Why It Works

- **Validity:** Since matching parentheses are always at the same depth after processing the closing bracket, they receive the same group assignment. This keeps pairs together, ensuring both A and B are valid parentheses strings.
- **Minimized Max Depth:** By alternating assignments based on depth parity, the nesting depth is split roughly in half between the two groups. The maximum depth of each group becomes at most `ceil(D / 2)`, which is the theoretical minimum.

### Trace Example: `"(()())"`

| Step | Char | Depth Before | Assignment | Depth After |
|------|------|--------------|------------|-------------|
| 1    | `(`  | 0            | 0          | 1           |
| 2    | `(`  | 1            | 1          | 2           |
| 3    | `)`  | 1            | 1          | 1           |
| 4    | `(`  | 1            | 1          | 2           |
| 5    | `)`  | 1            | 1          | 1           |
| 6    | `)`  | 0            | 0          | 0           |

**Result:** `[0, 1, 1, 1, 1, 0]` ✓

## Solution (Dart)

```dart
class Solution {
  List<int> maxDepthAfterSplit(String seq) {
    List<int> result = [];
    int depth = 0;

    for (int i = 0; i < seq.length; i++) {
      if (seq[i] == '(') {
        // Assign based on current depth parity, then increase depth
        result.add(depth % 2);
        depth++;
      } else {
        // Decrease depth first, then assign based on new depth parity
        depth--;
        result.add(depth % 2);
      }
    }

    return result;
  }
}
```

## Alternative Approaches

### Approach 2: Split by Half Depth

Instead of using parity directly, we can compute the maximum depth first, then assign any parenthesis whose depth is greater than `maxDepth / 2` to one group, and the rest to the other.

```dart
class Solution {
  List<int> maxDepthAfterSplit(String seq) {
    int maxDepth = 0, depth = 0;
    
    // First pass: find max depth
    for (var ch in seq.split('')) {
      if (ch == '(') {
        depth++;
        maxDepth = maxDepth > depth ? maxDepth : depth;
      } else {
        depth--;
      }
    }
    
    // Second pass: assign based on half of max depth
    List<int> result = [];
    depth = 0;
    int half = maxDepth ~/ 2;
    
    for (var ch in seq.split('')) {
      if (ch == '(') {
        depth++;
        result.add(depth > half ? 1 : 0);
      } else {
        result.add(depth > half ? 1 : 0);
        depth--;
      }
    }
    
    return result;
  }
}
```

Both approaches yield the same optimal result. The parity-based approach is simpler and requires only one pass.
