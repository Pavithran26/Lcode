# LeetCode 1621. Number of Sets of K Non-Overlapping Line Segments

**Difficulty:** Medium  
**Topics:** Math, Combinatorics, Dynamic Programming

## Problem

Given `n` points on a 1-D plane, where the `i`-th point is at `x = i`, find the number of ways we can draw exactly `k` non-overlapping line segments such that each segment covers two or more points.

- The endpoints of each segment must have integral coordinates.
- The `k` line segments do not have to cover all `n` points.
- They are allowed to share endpoints.
- Return the answer modulo `10^9 + 7`.

## Examples

### Example 1

```text
Input: n = 4, k = 2
Output: 5

Explanation:
The 5 different ways are:
{(0,2),(2,3)}, {(0,1),(1,3)}, {(0,1),(2,3)}, {(1,2),(2,3)}, {(0,1),(1,2)}
```

### Example 2

```text
Input: n = 3, k = 1
Output: 3

Explanation:
The 3 ways are: {(0,1)}, {(0,2)}, {(1,2)}
```

### Example 3

```text
Input: n = 30, k = 7
Output: 796297179

Explanation:
The total number of possible ways is 3796297200.
Taking this number modulo 10^9 + 7 gives 796297179.
```

## Approach

This problem can be solved using combinatorics.

We need to choose `k` non-overlapping line segments. Each segment has length at least `1`, and there are `k + 1` gaps between/around the segments where the gap size can be `0` or more.

Let:

- `x_i >= 1` be the length of the `i`-th segment.
- `g_i >= 0` be the size of the gaps.

The total number of points used is `n`, so the total length plus gaps must equal `n - 1`:

\[
\sum_{i=1}^{k} x_i + \sum_{i=0}^{k} g_i = n - 1
\]

Using stars and bars, the number of solutions is:

\[
\binom{n + k - 1}{2k}
\]

We compute this binomial coefficient modulo `10^9 + 7` using factorials and modular inverses.

## Complexity

- **Time Complexity:** `O(n + k)`
- **Space Complexity:** `O(n + k)`

## Java Solution

```java
class Solution {
    private static final int MOD = 1_000_000_007;

    public int numberOfSets(int n, int k) {
        // The number of ways is C(n + k - 1, 2k)
        int N = n + k - 1;
        int R = 2 * k;

        if (R > N) return 0;

        long[] fact = new long[N + 1];
        long[] invFact = new long[N + 1];

        fact[0] = 1;
        for (int i = 1; i <= N; i++) {
            fact[i] = fact[i - 1] * i % MOD;
        }

        invFact[N] = modPow(fact[N], MOD - 2);
        for (int i = N; i > 0; i--) {
            invFact[i - 1] = invFact[i] * i % MOD;
        }

        long ans = fact[N];
        ans = ans * invFact[R] % MOD;
        ans = ans * invFact[N - R] % MOD;

        return (int) ans;
    }

    private long modPow(long base, long exp) {
        long result = 1;
        while (exp > 0) {
            if ((exp & 1) == 1) {
                result = result * base % MOD;
            }
            base = base * base % MOD;
            exp >>= 1;
        }
        return result;
    }
}
```

## Key Formula

\[
\text{Answer} = \binom{n + k - 1}{2k} \mod (10^9 + 7)
\]
