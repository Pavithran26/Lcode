# 3870. Count Commas in Range

## Problem Statement

You are given an integer `n`.

Return the total number of commas used when writing all integers from `[1, n]` (inclusive) in standard number formatting.

### Standard Formatting Rules:

- A comma is inserted after every three digits from the right.
- Numbers with fewer than 4 digits contain no commas.

### Examples

**Example 1:**

```
Input: n = 1002
Output: 3
Explanation: 
The numbers "1,000", "1,001", and "1,002" each contain one comma, giving a total of 3.
```

**Example 2:**

```
Input: n = 998
Output: 0
Explanation: 
All numbers from 1 to 998 have fewer than four digits. Therefore, no commas are used.
```

### Constraints

- `1 <= n <= 10^5`

---

## Approach

To solve this problem efficiently, we do **not** need to iterate over every number from 1 to `n`. Instead, we can group numbers by their **digit length**.

### Key Insight

A number with `d` digits contains exactly:

\[
\frac{d - 1}{3} \quad \text{(integer division)}
\]

commas.

For example:

| Digits (`d`) | Commas formula | Example      |
| ------------ | --------------- | ------------ |
| 1–3          | 0               | 5 → `5`      |
| 4–6          | 1               | 1000 → `1,000` |
| 7–9          | 2               | 1000000 → `1,000,000` |

### Algorithm

1. Initialize `start = 1` (the smallest number with current digit length) and `digits = 1`.
2. Loop while `start <= n`:
   - Let `end = min(n, start * 10 - 1)`. This gives the range of numbers with `digits` digits that are ≤ `n`.
   - Count how many numbers are in this range: `count = end - start + 1`.
   - Each number in this range contributes `(digits - 1) / 3` commas.
   - Add `count * ((digits - 1) / 3)` to the total.
   - Move to the next digit length: `start *= 10`, `digits++`.
3. Return the total.

### Time Complexity

- **O(log₁₀ n)** — we iterate once per digit length. With `n ≤ 10^5`, this is at most 6 iterations.

### Space Complexity

- **O(1)** — only a few integer variables are used.

---

## Code (Java)

```java
class Solution {
    public int countCommas(int n) {
        long total = 0;
        long start = 1;      // First number with current digit length
        int digits = 1;      // Current digit length

        while (start <= n) {
            long end = Math.min((long) n, start * 10 - 1);
            long count = end - start + 1;

            // A d-digit number has (d - 1) / 3 commas
            total += count * ((digits - 1) / 3);

            start *= 10;
            digits++;
        }

        return (int) total;
    }
}
```

## Notes

- The problem constraints are small (`n ≤ 10^5`), so a brute-force loop over every number would also pass easily. However, the mathematical grouping approach demonstrates better algorithm design and works for much larger inputs.
- The solution uses `long` for intermediate calculations to avoid overflow when multiplying `start * 10`.
