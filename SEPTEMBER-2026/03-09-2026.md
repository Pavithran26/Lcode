# 3876. Construct Uniform Parity Array II

**Difficulty:** Medium  
**Topics:** Array, Greedy, Math  
**Companies:** LeetCode  
**Acceptance Rate:** 57.1%

## Problem Statement

You are given an array `nums1` of `n` distinct integers.

You want to construct another array `nums2` of length `n` such that the elements in `nums2` are either **all odd** or **all even**.

For each index `i`, you must choose exactly one of the following (in any order):

1. `nums2[i] = nums1[i]`
2. `nums2[i] = nums1[i] - nums1[j]`, for an index `j != i`, such that `nums1[i] - nums1[j] >= 1`

Return `true` if it is possible to construct such an array, otherwise return `false`.

---

## Examples

### Example 1

**Input:** `nums1 = [1,4,7]`  
**Output:** `true`

**Explanation:**  
- `nums2[0] = nums1[0] = 1` (odd)  
- `nums2[1] = nums1[1] - nums1[0] = 4 - 1 = 3` (odd)  
- `nums2[2] = nums1[2] = 7` (odd)  
Result: `[1, 3, 7]` → all odd → `true`

---

### Example 2

**Input:** `nums1 = [2,3]`  
**Output:** `false`

**Explanation:**  
- To make all even: `3` cannot be changed because it cannot subtract a smaller number (no number < 3 to make it even).  
- To make all odd: `2` cannot be changed because it cannot subtract a smaller number (no number < 2).  
→ Impossible → `false`

---

### Example 3

**Input:** `nums1 = [4,6]`  
**Output:** `true`

**Explanation:**  
- Keep both as they are: `[4, 6]` → all even → `true`

---

## Constraints

- `1 <= n == nums1.length <= 10^5`
- `1 <= nums1[i] <= 10^9`
- `nums1` consists of **distinct** integers.

---

## Approach & Intuition

The key lies in the **minimum element** of the array.

Let `min` be the smallest value in `nums1`.

### 1. If `min` is odd
- Every other number `x` can be transformed:
  - If `x` is odd → keep it as is.
  - If `x` is even → compute `x - min`, which is odd (odd - odd = even? Wait, odd - odd = even. Actually, we need all odd. Let's re-evaluate:
    - Odd numbers: keep as odd.
    - Even numbers: subtract an odd number (the min) from them → even - odd = odd.
  - So we can make **all numbers odd**.
- Answer: `true`

### 2. If `min` is even and there are **no odd numbers** (all numbers are even)
- Keep all numbers as they are → all even.
- Answer: `true`

### 3. If `min` is even and there is **at least one odd number**
- **All even?** The smallest odd number cannot be subtracted by a smaller number (since `min` is the smallest and is even, but even - even = even. However, we have an odd number. The odd number cannot become even because `odd - even = odd` and `odd` itself is odd. We need to subtract a smaller number `j` to change it. The smallest number is even, so subtracting it keeps it odd. We could try keeping it as odd, but then we need all elements to be odd. The smallest even number cannot become odd because there is no smaller odd number to subtract from it. So all odd fails. All even fails because the odd number cannot become even.
- Answer: `false`

### Simplified Condition
Return `true` **if and only if** (`min` is odd) **OR** (`there is no odd number in the array`).

---

## Complexity Analysis

- **Time Complexity:** `O(n)` — we iterate through the array once to find the minimum and check for odd numbers.
- **Space Complexity:** `O(1)` — only a few variables are used.

---

## Code (Java)

```java
class Solution {
    public boolean uniformArray(int[] nums1) {
        int min = nums1[0];
        boolean hasOdd = false;

        for (int x : nums1) {
            if (x < min) {
                min = x;
            }
            if (x % 2 == 1) {
                hasOdd = true;
            }
        }

        // If the minimum is odd, we can make all numbers odd.
        // If there are no odd numbers, all numbers are even already.
        return (min % 2 == 1) || !hasOdd;
    }
}
```

## Alternative View (Edge Cases)

| Min is odd | `[1, 4, 7]` | `true` | Even numbers subtract the min to become odd. |

| Min is even + odd exists | `[2, 3]` | `false` | Odd can't become even, even can't become odd. |
