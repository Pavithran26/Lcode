# 2267. Check if There Is a Valid Parentheses String Path

## Problem Statement

A **parentheses string** is a non-empty string consisting only of `'('` and `')'`. It is **valid** if any of the following conditions is true:

- It is `"()"`.
- It can be written as `AB` (A concatenated with B), where A and B are valid parentheses strings.
- It can be written as `(A)`, where A is a valid parentheses string.

You are given an `m x n` matrix of parentheses `grid`. A **valid parentheses string path** in the grid is a path satisfying all of the following conditions:

- The path starts from the upper left cell `(0, 0)`.
- The path ends at the bottom-right cell `(m - 1, n - 1)`.
- The path only ever moves **down** or **right**.
- The resulting parentheses string formed by the path is **valid**.

Return `true` if there exists a valid parentheses string path in the grid. Otherwise, return `false`.

---

## Examples

### Example 1

**Input:**
```scala
grid = [["(","(","("],
        [")","(",")"],
        ["(","(",")"],
        ["(","(",")"]]
```

**Output:** `true`

**Explanation:** Two possible paths form valid parentheses strings:
- `"()(())"` 
- `"((()))"`

There may be other valid paths as well.

---

### Example 2

**Input:**
```scala
grid = [[")",")"],
        ["(","("]]
```

**Output:** `false`

**Explanation:** The two possible paths form the strings `"))("` and `")(("`. Neither is valid.

---

## Constraints

| Constraint | Value |
|------------|-------|
| `m == grid.length` | |
| `n == grid[i].length` | |
| `1 <= m, n <= 100` | |
| `grid[i][j]` | `'('` or `')'` |

---

## Approach: Dynamic Programming

### Key Observations

1. **Path length** is always `m + n - 1` cells.
2. A valid parentheses string **must have even length** → if `(m + n - 1)` is odd, return `false` immediately.
3. **Balance** = `(number of '(') - (number of ')')`. For a valid string:
   - Balance must **never go negative** at any prefix.
   - Final balance must be **exactly 0**.
4. First cell must be `'('` and last cell must be `')'`.

### DP State

```
dp[i][j] = set of all possible balances when reaching cell (i, j)
```

### Transitions

For each cell `(i, j)`, we can arrive from:
- **Top** → `(i-1, j)`
- **Left** → `(i, j-1)`

For every balance `b` in the predecessor's set:

```
newBalance = b + (grid[i][j] == '(' ? 1 : -1)
```

Accept `newBalance` if:
- `newBalance >= 0` (never go negative)
- `newBalance <= maxBalance - (i + j)` (pruning: not enough remaining cells to ever reach 0)

### Answer

Check if `0` is in `dp[m-1][n-1]`.

## Solution (Scala)

```scala
object Solution {
    def hasValidPath(grid: Array[Array[Char]]): Boolean = {
        val m = grid.length
        val n = grid(0).length
        
        // Path length must be even for valid parentheses
        if ((m + n - 1) % 2 != 0) return false
        
        // First must be '(' and last must be ')'
        if (grid(0)(0) == ')' || grid(m-1)(n-1) == '(') return false
        
        // dp[i][j] = set of possible balances at cell (i, j)
        val dp = Array.ofDim[scala.collection.mutable.HashSet[Int]](m, n)
        for (i <- 0 until m; j <- 0 until n) {
            dp(i)(j) = scala.collection.mutable.HashSet[Int]()
        }
        
        // Initial cell
        dp(0)(0).add(1)
        
        val maxBalance = m + n - 1
        
        for (i <- 0 until m) {
            for (j <- 0 until n) {
                if (i == 0 && j == 0) {
                    // already initialized
                } else {
                    val delta = if (grid(i)(j) == '(') 1 else -1
                    
                    // From top
                    if (i > 0) {
                        for (bal <- dp(i-1)(j)) {
                            val newBal = bal + delta
                            if (newBal >= 0 && newBal <= maxBalance - (i + j)) {
                                dp(i)(j).add(newBal)
                            }
                        }
                    }
                    
                    // From left
                    if (j > 0) {
                        for (bal <- dp(i)(j-1)) {
                            val newBal = bal + delta
                            if (newBal >= 0 && newBal <= maxBalance - (i + j)) {
                                dp(i)(j).add(newBal)
                            }
                        }
                    }
                }
            }
        }
        
        dp(m-1)(n-1).contains(0)
    }
}
```

## Complexity Analysis

| Metric | Complexity |
|--------|------------|
| **Time** | `O(m × n × (m + n))` |
| **Space** | `O(m × n × (m + n))` |

Each cell can hold up to `O(m + n)` distinct balance values, and there are `m × n` cells.

With `m, n ≤ 100`, this is well within limits (~10⁶ operations).

---

## Alternative Approaches

| Approach | Time | Space | Notes |
|----------|------|-------|-------|
| **DFS + Memoization** | `O(m × n × (m+n))` | `O(m × n × (m+n))` | Same complexity, recursive |
| **BFS with State (i, j, balance)** | `O(m × n × (m+n))` | `O(m × n × (m+n))` | Queue-based |
| **DP with Bitset** | `O(m × n × (m+n) / 64)` | `O(m × n × (m+n) / 64)` | Uses bitset for balance sets |

---

## Edge Cases

1. **Single cell grid** `[["("]]` → length 1 is odd → `false`
2. **Grid starts with `')'`** → `false` immediately
3. **Grid ends with `'('`** → `false` immediately
4. **Odd total path length** → `false` immediately
5. **All `'('`** → final balance > 0 → `false`
