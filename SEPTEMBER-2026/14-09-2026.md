# 836. Rectangle Overlap

## 📝 Problem Description

An axis-aligned rectangle is represented as a list `[x1, y1, x2, y2]`, where `(x1, y1)` is the coordinate of its bottom-left corner, and `(x2, y2)` is the coordinate of its top-right corner. Its top and bottom edges are parallel to the X-axis, and its left and right edges are parallel to the Y-axis.

Two rectangles overlap if the area of their intersection is **positive**. To be clear, two rectangles that only touch at the corner or edges do not overlap.

Given two axis-aligned rectangles `rec1` and `rec2`, return `true` if they overlap, otherwise return `false`.

## 💡 Examples

**Example 1:**
*   **Input:** `rec1 = [0,0,2,2]`, `rec2 = [1,1,3,3]`
*   **Output:** `true`

**Example 2:**
*   **Input:** `rec1 = [0,0,1,1]`, `rec2 = [1,0,2,1]`
*   **Output:** `false`

**Example 3:**
*   **Input:** `rec1 = [0,0,1,1]`, `rec2 = [2,2,3,3]`
*   **Output:** `false`

## 📌 Constraints

*   `rec1.length == 4`
*   `rec2.length == 4`
*   `-10^9 <= rec1[i], rec2[i] <= 10^9`
*   `rec1` and `rec2` represent a valid rectangle with a non-zero area.

## 🧠 Solution Approach

Instead of checking all the ways the rectangles *don't* overlap, we can directly check if they *do* overlap. Two rectangles overlap if and only if their projections on both the X-axis and Y-axis intersect.

For two rectangles `rec1 = [x1, y1, x2, y2]` and `rec2 = [x1', y1', x2', y2']`:
1.  **X-axis overlap:** The right edge of `rec1` is to the right of the left edge of `rec2` **AND** the left edge of `rec1` is to the left of the right edge of `rec2`.
    *   `rec1[2] > rec2[0] && rec1[0] < rec2[2]`
2.  **Y-axis overlap:** The top edge of `rec1` is above the bottom edge of `rec2` **AND** the bottom edge of `rec1` is below the top edge of `rec2`.
    *   `rec1[3] > rec2[1] && rec1[1] < rec2[3]`

Using strict inequalities (`>`, `<`) ensures that rectangles touching only at edges or corners are not considered overlapping (as required by the problem).

## ⏱️ Complexity Analysis

*   **Time Complexity:** `O(1)` - We only perform a constant number of arithmetic comparisons.
*   **Space Complexity:** `O(1)` - We use no additional data structures.

## 💻 Java Solution

```java
class Solution {
    public boolean isRectangleOverlap(int[] rec1, int[] rec2) {
        return rec1[2] > rec2[0] && // Right of rec1 > Left of rec2
               rec1[3] > rec2[1] && // Top of rec1 > Bottom of rec2
               rec1[0] < rec2[2] && // Left of rec1 < Right of rec2
               rec1[1] < rec2[3];   // Bottom of rec1 < Top of rec2
    }
}
