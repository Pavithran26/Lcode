# 3498. Reverse Degree of a String

**Difficulty:** Easy  
**Topics:** String, Math  

## Problem Description

Given a string `s`, calculate its **reverse degree**.

The **reverse degree** is calculated as follows:
1. For each character, multiply its position in the reversed alphabet (`'a' = 26`, `'b' = 25`, ..., `'z' = 1`) with its position in the string (1-indexed).
2. Sum these products for all characters in the string.

Return the **reverse degree** of `s`.

### Examples

**Example 1:**
```text
Input: s = "abc"
Output: 148
Explanation:
Letter  | Index in Reversed Alphabet | Index in String | Product
'a'     | 26                         | 1               | 26
'b'     | 25                         | 2               | 50
'c'     | 24                         | 3               | 72
The reverse degree is 26 + 50 + 72 = 148.
```

Example 2:

```text
Input: s = "zaza"
Output: 160
Explanation:
Letter  | Index in Reversed Alphabet | Index in String | Product
'z'     | 1                          | 1               | 1
'a'     | 26                         | 2               | 52
'z'     | 1                          | 3               | 3
'a'     | 26                         | 4               | 104
The reverse degree is 1 + 52 + 3 + 104 = 160.
```

Constraints

· 1 <= s.length <= 1000
· s contains only lowercase English letters.

---

Solution (Java)

```java
class Solution {
    public int reverseDegree(String s) {
        int totalSum = 0;
        
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            
            // Position in string (1-indexed)
            int stringIndex = i + 1;
            
            // Position in reversed alphabet ('a' = 26, 'b' = 25, ..., 'z' = 1)
            // 'z' is ASCII 122, 'a' is ASCII 97.
            // 'z' - c + 1 works: for 'z' it's 1, for 'a' it's 26.
            int reversedAlphabetIndex = 'z' - c + 1;
            
            // Multiply and add to the total sum
            totalSum += stringIndex * reversedAlphabetIndex;
        }
        
        return totalSum;
    }
}
```

Explanation

1. Iterate through the string: We loop through each character of the string s using a for loop.
2. String Position: Since the string position is 1-indexed, for an index i in the loop (which starts at 0), the position is i + 1.
3. Reversed Alphabet Position: We calculate this using the formula 'z' - c + 1.
   · For 'a': 'z' - 'a' + 1 equals 25 + 1 = 26.
   · For 'z': 'z' - 'z' + 1 equals 0 + 1 = 1.
   · This correctly maps a to 26 and z to 1.
4. Accumulate: We multiply these two values and add them to totalSum.
5. Return: Finally, we return the calculated totalSum.

Complexity Analysis

· Time Complexity: O(n), where n is the length of the string s, as we iterate through the string exactly once.
· Space Complexity: O(1), as we only use a few integer variables for the calculation regardless of the input size.
