# 1477. Find Two Non-overlapping Sub-arrays Each With Target Sum

## Problem Description

You are given an array of integers `arr` and an integer `target`.

You have to find **two non-overlapping sub-arrays** of `arr` each with a sum equal to `target`. There can be multiple answers so you have to find an answer where the sum of the lengths of the two sub-arrays is **minimum**.

Return the minimum sum of the lengths of the two required sub-arrays, or return `-1` if you cannot find such two sub-arrays.

### Examples

**Example 1:**
```text
Input: arr = [3,2,2,4,3], target = 3
Output: 2
Explanation: Only two sub-arrays have sum = 3 ([3] and [3]). The sum of their lengths is 2.
```

Example 2:

```text
Input: arr = [7,3,4,7], target = 7
Output: 2
Explanation: Although we have three non-overlapping sub-arrays of sum = 7 ([7], [3,4] and [7]), but we will choose the first and third sub-arrays as the sum of their lengths is 2.
```

Example 3:

```text
Input: arr = [4,3,2,6,2,3,4], target = 6
Output: -1
Explanation: We have only one sub-array of sum = 6.
```

Constraints

· 1 <= arr.length <= 10^5
· 1 <= arr[i] <= 1000
· 1 <= target <= 10^8

---

Approach

Since all elements in the array are positive, we can use the Sliding Window technique to find sub-arrays with a sum equal to target in linear time.

To ensure the two sub-arrays are non-overlapping, we can use a two-pass strategy:

1. Forward Pass (Prefix Minimums): 
   We calculate the minimum length of a valid sub-array ending at or before each index i. We store this in an array dp, where dp[i] represents the minimum length of a valid sub-array found in the range arr[0...i].
2. Backward Pass (Suffix Combination):
   We slide a window from right to left to find the second valid sub-array. When we find a valid sub-array starting at index i, we combine its length with the best valid sub-array that ends before i (which is stored in dp[i-1]).

Algorithm Steps

1. Initialize a dp array of size n with Integer.MAX_VALUE.
2. Use a sliding window (left to right) to find sub-arrays summing to target.
3. If a valid sub-array is found, update the minimum length found so far (minLen) and set dp[right] = minLen.
4. Use a second sliding window (left to right) starting from the end of the array.
5. If a valid sub-array is found starting at left, check if there is a valid non-overlapping sub-array before it using dp[left - 1].
6. If valid, update the global minimum ans = Math.min(ans, currentLen + dp[left - 1]).
7. Return ans if it was updated, otherwise return -1.

---

Complexity Analysis

· Time Complexity: O(N), where N is the length of arr. Both the forward and backward passes use a sliding window that processes each element at most twice.
· Space Complexity: O(N) to store the dp array which records the prefix minimum lengths.

---

Java Solution

```java
import java.util.Arrays;

class Solution {
    public int minSumOfLengths(int[] arr, int target) {
        int n = arr.length;
        
        // dp[i] will store the minimum length of a valid subarray with sum = target
        // in the range arr[0...i]
        int[] dp = new int[n];
        Arrays.fill(dp, Integer.MAX_VALUE);
        
        int currentSum = 0;
        int left = 0;
        int minLen = Integer.MAX_VALUE;
        
        // Forward pass: Find minimum length of subarrays ending at or before each index
        for (int right = 0; right < n; right++) {
            currentSum += arr[right];
            
            // Shrink window if sum exceeds target
            while (currentSum > target) {
                currentSum -= arr[left];
                left++;
            }
            
            // If target sum is found, update the minimum length
            if (currentSum == target) {
                minLen = Math.min(minLen, right - left + 1);
            }
            
            // Store the minimum length found so far in the prefix
            dp[right] = minLen;
        }
        
        int ans = Integer.MAX_VALUE;
        currentSum = 0;
        int right = n - 1;
        
        // Backward pass: Find the second valid subarray and combine with dp
        for (int left2 = n - 1; left2 >= 0; left2--) {
            currentSum += arr[left2];
            
            // Shrink window if sum exceeds target
            while (currentSum > target) {
                currentSum -= arr[right];
                right--;
            }
            
            // If target sum is found
            if (currentSum == target) {
                int currentLen = right - left2 + 1;
                // Check if there is a valid non-overlapping subarray before left2
                if (left2 > 0 && dp[left2 - 1] != Integer.MAX_VALUE) {
                    ans = Math.min(ans, currentLen + dp[left2 - 1]);
                }
            }
        }
        
        return ans == Integer.MAX_VALUE ? -1 : ans;
    }
}
