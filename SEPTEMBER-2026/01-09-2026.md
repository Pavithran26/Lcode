# 3568. Minimum Moves to Clean the Classroom

## Problem Statement

You are given an `m x n` grid `classroom` where a student must collect all litter items `'L'`. The grid contains:

- `'S'` – starting position (exactly one)
- `'L'` – litter to collect (at most 10 cells)
- `'R'` – reset area that restores the student's energy to full capacity (can be used multiple times)
- `'X'` – obstacle, cannot pass through
- `'.'` – empty space

You are also given an integer `energy` – the maximum energy capacity. The student starts with this energy at `'S'`.  
Moving to an adjacent cell (up, down, left, right) costs **1 unit of energy**.  
If energy reaches `0`, the student can **only** continue if they are on a reset area `'R'` (which then resets energy to maximum).

Return the **minimum number of moves** required to collect all litter items, or `-1` if impossible.

### Constraints

- `1 <= m, n <= 20` (grid size ≤ 400 cells)
- `1 <= energy <= 50`
- At most **10** litter cells.
- Exactly one `'S'`.

## Example

```
Input: classroom = ["S.", "XL"], energy = 2
Output: 2

Input: classroom = ["LS", "RL"], energy = 4
Output: 3

Input: classroom = ["L.S", "RXL"], energy = 3
Output: -1
```

## Solution Approach

This problem is a **shortest‑path** problem on a state space, where each state is defined by three components:

1. **Position** – current cell (0 … `m*n - 1`)
2. **Remaining energy** – an integer from `0` to `energy`
3. **Mask** – a bitmask representing which litter items have been collected (up to 10 bits)

The total number of possible states is  
`(m*n) * (energy+1) * 2^k` with `k ≤ 10`, which is at most  
`400 * 51 * 1024 ≈ 20.9 million`. This is manageable for a BFS.

### BFS over States

We perform a Breadth‑First Search (BFS) over the state space:

- Start state: at `'S'`, with full `energy`, and mask = `0`.
- For each state, we try all four moves.
- A move to a neighbouring cell is allowed if:
  - It is not an obstacle `'X'`.
  - The student has **at least 1 unit** of energy remaining before the move (i.e., `e > 0`).
- After moving:
  - Decrease energy by 1.
  - If the new cell is `'R'`, set energy to full (`energy`).
  - If the new cell is `'L'`, set the corresponding bit in the mask.
- If after the move the energy becomes `0` **and** the new cell is **not** `'R'`, the move is illegal (the student cannot continue from there). However, the move itself could still be valid if the energy becomes zero and the cell is `'R'` (since it resets immediately).
- Stop and return the move count when the mask becomes `(1 << k) - 1`, i.e., all litter collected.

### State Encoding

To save memory, we encode the state into a single integer:

```
[ mask (10 bits) ] [ energy (6 bits) ] [ cell id (10 bits) ]
```

- `cell id` – index in the flattened grid (0 … 399)
- `energy` – 0 … 50 (6 bits suffice)
- `mask` – up to 10 bits

BFS queue stores these encoded integers.

A `visited` array of size `(m*n) * (energy+1) * (1<<k)` marks already‑seen states.  
We use a 1‑D byte array for efficiency.

### Complexity

- **Time complexity:** `O(m * n * energy * 2^k)`  
  Each state is visited at most once, and from each state we try 4 moves.
- **Space complexity:** same as time for the visited array and queue.

With `m*n ≤ 400`, `energy ≤ 50`, `k ≤ 10`, this fits well within limits.

## Code (Java)

```java
import java.util.*;

class Solution {
    public int minMoves(String[] classroom, int energy) {
        int m = classroom.length;
        int n = classroom[0].length();
        char[][] grid = new char[m][n];
        int area = m * n;
        
        int[] litterBit = new int[area];
        Arrays.fill(litterBit, -1);
        int startId = -1;
        
        // Parse grid and locate litter cells.
        for (int i = 0; i < m; i++) {
            grid[i] = classroom[i].toCharArray();
            for (int j = 0; j < n; j++) {
                int id = i * n + j;
                char c = grid[i][j];
                if (c == 'S') startId = id;
                else if (c == 'L') litterBit[id] = 0; // placeholder
            }
        }
        
        // Assign a bit index to each litter cell.
        int k = 0;
        for (int id = 0; id < area; id++) {
            if (litterBit[id] != -1) {
                litterBit[id] = k++;
            }
        }
        
        if (k == 0) return 0;
        int fullMask = (1 << k) - 1;
        
        // State: (cellId, energy, mask)
        // BFS over all possible states.
        int totalStates = area * (1 << k) * (energy + 1);
        byte[] visited = new byte[totalStates];
        int[] queue = new int[totalStates];
        int head = 0, tail = 0;
        
        // Encode state into one int: [mask (10 bits)] [energy (6 bits)] [cellId (10 bits)]
        int startMask = 0;
        int startEnergy = energy;
        int startState = (startMask << 16) | (startEnergy << 10) | startId;
        int startIdx = ((startMask * (energy + 1) + startEnergy) * area) + startId;
        visited[startIdx] = 1;
        queue[tail++] = startState;
        
        int[] dr = {-1, 1, 0, 0};
        int[] dc = {0, 0, -1, 1};
        int dist = 0;
        
        while (head < tail) {
            int levelSize = tail - head;
            for (int l = 0; l < levelSize; l++) {
                int state = queue[head++];
                int id = state & 0x3FF;
                int e = (state >> 10) & 0x3F;
                int mask = state >> 16;
                
                int r = id / n;
                int c = id % n;
                
                for (int d = 0; d < 4; d++) {
                    int nr = r + dr[d];
                    int nc = c + dc[d];
                    if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
                    
                    char ch = grid[nr][nc];
                    if (ch == 'X') continue;
                    if (e == 0) continue; // no energy to move
                    
                    int newId = nr * n + nc;
                    int newE = e - 1;
                    
                    // Reset area restores energy to full.
                    if (ch == 'R') {
                        newE = energy;
                    }
                    
                    int newMask = mask;
                    int bit = litterBit[newId];
                    if (bit != -1) {
                        newMask |= (1 << bit);
                    }
                    
                    // Collected all litter.
                    if (newMask == fullMask) {
                        return dist + 1;
                    }
                    
                    // If energy becomes 0 on a non-reset cell, no further moves are possible.
                    if (newE == 0 && ch != 'R') {
                        continue;
                    }
                    
                    int newState = (newMask << 16) | (newE << 10) | newId;
                    int idx = ((newMask * (energy + 1) + newE) * area) + newId;
                    
                    if (visited[idx] == 0) {
                        visited[idx] = 1;
                        queue[tail++] = newState;
                    }
                }
            }
            dist++;
        }
        
        return -1;
    }
}
```

## Key Points

- **State‑space BFS** is the natural choice because we need the **minimum moves**.
- The energy constraint is handled by the energy dimension.
- Reset areas `'R'` allow refuelling only when the student is on them, and they can be used repeatedly.
- The mask efficiently tracks which litter has been collected.
- Early termination when all litter is collected.
