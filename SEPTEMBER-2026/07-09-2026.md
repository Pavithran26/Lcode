# 940. Distinct Subsequences II

This repository contains a Java solution for LeetCode problem [940. Distinct Subsequences II](https://leetcode.com/problems/distinct-subsequences-ii/).

## Problem Statement

Given a string `s`, return the number of distinct non‑empty subsequences of `s`. Since the answer may be very large, return it modulo `10^9 + 7`.

A subsequence of a string is a new string that is formed from the original string by deleting some (can be none) of the characters without disturbing the relative positions of the remaining characters.

### Examples

**Example 1:**
```
Input: s = "abc"
Output: 7
Explanation: The 7 distinct subsequences are "a", "b", "c", "ab", "ac", "bc", and "abc".
```

**Example 2:**
```
Input: s = "aba"
Output: 6
Explanation: The 6 distinct subsequences are "a", "b", "ab", "aa", "ba", and "aba".
```

**Example 3:**
```
Input: s = "aaa"
Output: 3
Explanation: The 3 distinct subsequences are "a", "aa" and "aaa".
```

## Constraints

- `1 <= s.length <= 2000`
- `s` consists of lowercase English letters.

## Solution Approach

We use dynamic programming to count distinct subsequences efficiently.

### Intuition

Let `total` be the number of distinct non‑empty subsequences seen so far.  
We also maintain an array `end[26]` where `end[c]` stores how many distinct subsequences end with character `c`.

When processing a new character `ch`:
- Every existing subsequence can be extended by appending `ch`, and we can also start a new subsequence consisting of just `ch` (this corresponds to appending `ch` to the empty subsequence).
- Thus, the number of **new** subsequences we can form is `total + 1`.
- However, some of these subsequences may already exist if we have seen `ch` before. Those duplicates are exactly the subsequences that previously ended with `ch` (i.e., `end[idx]`).
- So the actual number of distinct new subsequences ending with `ch` is:
  ```
  add = (total + 1 - end[idx]) mod MOD
  ```
- We then update:
  - `total = (total + add) mod MOD`
  - `end[idx] = (end[idx] + add) mod MOD`

All operations are performed modulo `10^9 + 7`.

### Algorithm Steps

1. Initialize `total = 0`.
2. Initialize `end` array of size 26 with zeros.
3. For each character `ch` in `s`:
   - `idx = ch - 'a'`
   - `add = (total + 1 - end[idx] + MOD) % MOD`
   - `total = (total + add) % MOD`
   - `end[idx] = (end[idx] + add) % MOD`
4. Return `total`.

### Complexity Analysis

- **Time Complexity:** O(n), where n is the length of the string. We process each character once.
- **Space Complexity:** O(1) – only a fixed array of 26 integers is used.

## Java Code

```java
class Solution {
    public int distinctSubseqII(String s) {
        final int MOD = 1_000_000_007;
        
        int total = 0;              // total distinct non-empty subsequences
        int[] end = new int[26];    // end[c] = count of subsequences ending with char c
        
        for (char ch : s.toCharArray()) {
            int idx = ch - 'a';
            
            // New subsequences formed by appending ch to all existing subsequences + empty string
            // Subtract already existing subsequences ending with ch
            int add = (total + 1 - end[idx] + MOD) % MOD;
            
            total = (total + add) % MOD;
            end[idx] = (end[idx] + add) % MOD;
        }
        
        return total;
    }
}
```

Example:

System.out.println(sol.distinctSubseqII("abc")); // Output: 7
