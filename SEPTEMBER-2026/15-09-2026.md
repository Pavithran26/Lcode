# 2472. Maximum Number of Non-overlapping Palindrome Substrings

**Difficulty:** Hard  
**Topics:** String, Dynamic Programming  
**Problem Link:** https://leetcode.com/problems/maximum-number-of-non-overlapping-palindrome-substrings/

## Problem Description

You are given a string `s` and a positive integer `k`.

Select a set of **non-overlapping** substrings from `s` such that:

- The length of each substring is at least `k`.
- Each substring is a palindrome.

Return the **maximum number** of substrings in an optimal selection.

A substring is a contiguous sequence of characters within a string.

## Examples

### Example 1

```text
Input: s = "abaccdbbd", k = 3
Output: 2
Explanation:
We can select "aba" and "dbbd".
Both are palindromes and have length at least k = 3.
It can be shown that we cannot select more than two valid substrings.
```

### Example 2

```text
Input: s = "adbcda", k = 2
Output: 0
Explanation:
There is no palindrome substring of length at least 2 in the string.
```

## Constraints

- `1 <= k <= s.length <= 2000`
- `s` consists of lowercase English letters.

## Approach

1. **Precompute Palindromes**
   - Use a 2D boolean array `isPal[i][j]` to mark whether `s[i..j]` is a palindrome.
   - Transition:
     - If `s[i] == s[j]` and either the length is `<= 2` or `isPal[i + 1][j - 1]` is true, then `isPal[i][j] = true`.

2. **Dynamic Programming**
   - Let `dp[i]` be the maximum number of valid non-overlapping palindromic substrings using the prefix `s[0..i-1]`.
   - Initialize `dp[0] = 0`.
   - For each index `i`:
     - Skip the character: `dp[i + 1] = max(dp[i + 1], dp[i])`.
     - Try every palindrome starting at `i` with length at least `k`:
       - If `isPal[i][j]` is true, update `dp[j + 1] = max(dp[j + 1], dp[i] + 1)`.

3. **Answer**
   - Return `dp[n]`, where `n = s.length()`.

## Complexity

- **Time Complexity:** `O(n^2)`
- **Space Complexity:** `O(n^2)`

Where `n` is the length of the string `s`.

## Java Solution

```java
class Solution {
    public int maxPalindromes(String s, int k) {
        int n = s.length();

        // isPal[i][j] = true if s[i..j] is a palindrome
        boolean[][] isPal = new boolean[n][n];

        for (int len = 1; len <= n; len++) {
            for (int i = 0; i + len - 1 < n; i++) {
                int j = i + len - 1;

                if (s.charAt(i) == s.charAt(j)) {
                    if (len <= 2 || isPal[i + 1][j - 1]) {
                        isPal[i][j] = true;
                    }
                }
            }
        }

        // dp[i] = max number of valid substrings using prefix s[0..i-1]
        int[] dp = new int[n + 1];

        for (int i = 0; i < n; i++) {
            // Skip current character
            dp[i + 1] = Math.max(dp[i + 1], dp[i]);

            // Try every palindrome starting at i with length >= k
            for (int j = i + k - 1; j < n; j++) {
                if (isPal[i][j]) {
                    dp[j + 1] = Math.max(dp[j + 1], dp[i] + 1);
                }
            }
        }

        return dp[n];
    }
}
```

## Notes

- The palindrome precomputation uses the standard DP technique for checking palindromic substrings in `O(n^2)`.
- The second DP greedily considers all valid palindromes starting at each position while allowing the option to skip characters.
- This solution passes within the given constraints because `n <= 2000`, so `O(n^2)` time and space are acceptable.
