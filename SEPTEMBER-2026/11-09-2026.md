# 3483. Unique 3-Digit Even Numbers

## Problem

You are given an array of digits called `digits`. Your task is to determine the number of distinct three-digit even numbers that can be formed using these digits.

**Note:**  
- Each copy of a digit can only be used once per number.  
- There may not be leading zeros.

### Examples

#### Example 1
```text
Input: digits = [1,2,3,4]
Output: 12
Explanation: The 12 distinct 3-digit even numbers are:
124, 132, 134, 142, 214, 234, 312, 314, 324, 342, 412, 432.
Note that 222 cannot be formed because there is only 1 copy of digit 2.
```

#### Example 2
```text
Input: digits = [0,2,2]
Output: 2
Explanation: The only 3-digit even numbers are 202 and 220.
```

#### Example 3
```text
Input: digits = [6,6,6]
Output: 1
Explanation: Only 666 can be formed.
```

#### Example 4
```text
Input: digits = [1,3,5]
Output: 0
Explanation: No even 3-digit numbers can be formed.
```

## Constraints

- `3 <= digits.length <= 10`
- `0 <= digits[i] <= 9`

## Approach

Since the maximum length of `digits` is only `10`, we can use a brute-force approach.

1. Use three nested loops to choose three distinct indices `i`, `j`, and `k`.
2. Ensure:
   - The hundreds digit `digits[i]` is not `0`.
   - The last digit `digits[k]` is even.
3. Form the number: `digits[i] * 100 + digits[j] * 10 + digits[k]`.
4. Store the number in a `HashSet` to automatically remove duplicates.
5. Return the size of the set.

## Java Solution

```java
class Solution {
    public int totalNumbers(int[] digits) {
        Set<Integer> result = new HashSet<>();
        int n = digits.length;

        for (int i = 0; i < n; i++) {
            if (digits[i] == 0) continue; // no leading zero

            for (int j = 0; j < n; j++) {
                if (j == i) continue;

                for (int k = 0; k < n; k++) {
                    if (k == i || k == j) continue;
                    if (digits[k] % 2 != 0) continue; // must be even

                    int num = digits[i] * 100 + digits[j] * 10 + digits[k];
                    result.add(num);
                }
            }
        }

        return result.size();
    }
}
```

## Complexity Analysis

- **Time Complexity:** `O(n^3)`, where `n = digits.length`. Since `n <= 10`, this is very fast.
- **Space Complexity:** `O(1)` effectively, because the number of possible 3-digit even numbers is bounded by `450`. The `HashSet` stores at most a constant number of values.
