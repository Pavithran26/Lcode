# 2265. Count Nodes Equal to Average of Subtree

## Problem Statement

Given the `root` of a binary tree, return the number of nodes where the value of the node is equal to the **average** of the values in its **subtree**.

**Note:**
- The average of `n` elements is the sum of the `n` elements divided by `n` and **rounded down** to the nearest integer.
- A **subtree** of `root` is a tree consisting of `root` and all of its descendants.

### Examples

**Example 1:**
```
Input: root = [4,8,5,0,1,null,6]
Output: 5
Explanation: 
For the node with value 4: The average of its subtree is (4 + 8 + 5 + 0 + 1 + 6) / 6 = 24 / 6 = 4.
For the node with value 5: The average of its subtree is (5 + 6) / 2 = 11 / 2 = 5.
For the node with value 0: The average of its subtree is 0 / 1 = 0.
For the node with value 1: The average of its subtree is 1 / 1 = 1.
For the node with value 6: The average of its subtree is 6 / 1 = 6.
```

**Example 2:**
```
Input: root = [1]
Output: 1
Explanation: For the node with value 1: The average of its subtree is 1 / 1 = 1.
```

### Constraints
- The number of nodes in the tree is in the range `[1, 1000]`.
- `0 <= Node.val <= 1000`

---

## Approach

We can solve this problem using a **postorder traversal (DFS)**.  
For each node, we need to know two things about its subtree:
1. The **sum** of all node values in the subtree.
2. The **count** of nodes in the subtree.

Once we have these, we can compute the average as `sum / count` (integer division, which automatically rounds down).  
If the node's value equals this average, we increment our answer.

We return the `(sum, count)` pair to the parent node so it can compute its own subtree information.

### Algorithm

1. Initialize a global counter `count = 0`.
2. Define a recursive function `dfs(node)` that returns an array `[sum, nodeCount]`.
   - If `node` is `null`, return `[0, 0]`.
   - Recursively call `dfs` on `node.left` and `node.right`.
   - Compute `totalSum = node.val + leftSum + rightSum`.
   - Compute `totalCount = 1 + leftCount + rightCount`.
   - Compute `avg = totalSum / totalCount`.
   - If `node.val == avg`, increment `count`.
   - Return `[totalSum, totalCount]`.
3. Call `dfs(root)` and return `count`.

### Complexity Analysis

- **Time Complexity:** `O(n)` – We visit each node exactly once.
- **Space Complexity:** `O(h)` – Recursion stack depth, where `h` is the height of the tree. In the worst case (skewed tree), `h = n`; in the best case (balanced tree), `h = log n`.

## Solution (Java)

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    private int count = 0;

    public int averageOfSubtree(TreeNode root) {
        dfs(root);
        return count;
    }

    private int[] dfs(TreeNode node) {
        if (node == null) {
            return new int[]{0, 0}; // {sum, nodeCount}
        }

        int[] left = dfs(node.left);
        int[] right = dfs(node.right);

        int sum = node.val + left[0] + right[0];
        int nodeCount = 1 + left[1] + right[1];

        int avg = sum / nodeCount;
        if (node.val == avg) {
            count++;
        }

        return new int[]{sum, nodeCount};
    }
}
```

---

## Explanation of the Code

- The `dfs` method returns an integer array of size 2:  
  `result[0]` = sum of all values in the subtree rooted at `node`  
  `result[1]` = number of nodes in that subtree.
- For a `null` node, we return `{0, 0}`.
- For a non-null node, we first get the results from its left and right children.
- We then compute the total sum and total count for the current node's subtree.
- The average is calculated using integer division (`sum / nodeCount`), which rounds down.
- If the node's value matches this average, we increment the global `count`.
- Finally, we return the computed sum and count to the parent.
