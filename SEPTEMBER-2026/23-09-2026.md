# 1658. Minimum Operations to Reduce X to Zero

## Problem Description
You are given an integer array `nums` and an integer `x`. In one operation, you can either remove the leftmost or the rightmost element from the array `nums` and subtract its value from `x`. Note that this **modifies** the array for future operations.

Return the **minimum number of operations** to reduce `x` to **exactly** 0 if it is possible, otherwise, return `-1`.

### Examples

**Example 1:**
*   **Input:** `nums = [1,1,4,2,3], x = 5`
*   **Output:** `2`
*   **Explanation:** The optimal solution is to remove the last two elements to reduce x to zero.

**Example 2:**
*   **Input:** `nums = [5,6,7,8,9], x = 4`
*   **Output:** `-1`

**Example 3:**
*   **Input:** `nums = [3,2,20,1,1,3], x = 10`
*   **Output:** `5`
*   **Explanation:** The optimal solution is to remove the last three elements and the first two elements (5 operations in total) to reduce x to zero.

### Constraints
*   `1 <= nums.length <= 10^5`
*   `1 <= nums[i] <= 10^4`
*   `1 <= x <= 10^9`

---

## Approach: Sliding Window (Two Pointers)

The problem asks us to remove elements from the left and right ends to sum up to `x`. 
Instead of thinking about what to remove, we can think about what to **keep**. 

If we remove elements from the ends, the remaining elements form a **contiguous subarray** in the middle. 
Let `totalSum` be the sum of all elements in `nums`. If we remove elements with a total sum of `x`, the remaining subarray must have a sum of `totalSum - x`.

To minimize the number of operations (removals), we need to **maximize the length** of this remaining subarray. 

Since all elements in `nums` are positive (`nums[i] >= 1`), we can use the **Sliding Window** technique to find the longest subarray with a sum equal to `target = totalSum - x`.

### Algorithm Steps:
1. Calculate the `totalSum` of the array.
2. If `totalSum < x`, it's impossible to reach `x` even by removing all elements. Return `-1`.
3. Calculate `target = totalSum - x`.
4. If `target == 0`, we need to remove all elements. Return `nums.length`.
5. Initialize `left = 0`, `currentSum = 0`, and `maxLen = -1`.
6. Iterate `right` from `0` to `nums.length - 1`:
   * Add `nums[right]` to `currentSum`.
   * While `currentSum > target`, shrink the window from the left (`currentSum -= nums[left]; left++`).
   * If `currentSum == target`, update `maxLen = Math.max(maxLen, right - left + 1)`.
7. If `maxLen == -1`, return `-1`. Otherwise, return `nums.length - maxLen`.

### Complexity Analysis
*   **Time Complexity:** `O(N)`, where `N` is the length of `nums`. The `right` pointer traverses the array once, and the `left` pointer moves at most `N` times.
*   **Space Complexity:** `O(1)`, as we only use a few variables for calculations.

## Java Implementation

```java
class Solution {
    public int minOperations(int[] nums, int x) {
        int totalSum = 0;
        for (int num : nums) {
            totalSum += num;
        }
        
        // If the total sum is less than x, it's impossible to reduce x to 0
        if (totalSum < x) {
            return -1;
        }
        
        int target = totalSum - x;
        
        // If target is 0, we need to remove all elements
        if (target == 0) {
            return nums.length;
        }
        
        int left = 0;
        int currentSum = 0;
        int maxLen = -1;
        
        // Sliding window to find the longest subarray with sum equal to target
        for (int right = 0; right < nums.length; right++) {
            currentSum += nums[right];
            
            // Shrink the window from the left if the current sum exceeds the target
            while (currentSum > target && left <= right) {
                currentSum -= nums[left];
                left++;
            }
            
            // If we found a valid subarray, update the maximum length
            if (currentSum == target) {
                maxLen = Math.max(maxLen, right - left + 1);
            }
        }
        
        // If no valid subarray was found, return -1. Otherwise, return the remaining elements count.
        return maxLen == -1 ? -1 : nums.length - maxLen;
    }
}
```

Key Takeaways

· Reverse Thinking: Instead of finding the minimum elements to remove from the ends, find the maximum contiguous subarray to keep.
· Sliding Window: Works efficiently here because the array contains only positive integers, allowing the window sum to monotonically increase as the right pointer moves.
