# 1614. Maximum Nesting Depth of the Parentheses

## Problem Statement

Given a **valid parentheses string** `s`, return the **nesting depth** of `s`. The nesting depth is the **maximum number of nested parentheses**.

### Examples

**Example 1:**
```
Input:  s = "(1+(2*3)+((8)/4))+1"
Output: 3
Explanation: Digit 8 is inside of 3 nested parentheses in the string.
```

**Example 2:**
```
Input:  s = "(1)+((2))+(((3)))"
Output: 3
Explanation: Digit 3 is inside of 3 nested parentheses in the string.
```

**Example 3:**
```
Input:  s = "()(())((()()))"
Output: 3
```

### Constraints

- `1 <= s.length <= 100`
- `s` consists of digits `0-9` and characters `'+'`, `'-'`, `'*'`, `'/'`, `'('`, and `')'`.
- It is guaranteed that `s` is a **VPS** (Valid Parentheses String).

---

## Approach

We only care about the parentheses `(` and `)`. Every time we see an opening bracket, the current depth increases by 1; every time we see a closing bracket, it decreases by 1. We keep track of the maximum depth reached.

### Algorithm

1. Initialize `current = 0` and `max_depth = 0`.
2. Traverse each character in the string:
   - If `'('` → increment `current`, then update `max_depth = max(max_depth, current)`.
   - If `')'` → decrement `current`.
   - Otherwise → ignore.
3. Return `max_depth`.

### Complexity Analysis

| Metric | Value |
|--------|-------|
| Time   | O(n)  |
| Space  | O(1)  |

Where `n` is the length of the string.

---

## Erlang Solution

```erlang
-spec max_depth(S :: unicode:unicode_binary()) -> integer().
max_depth(S) ->
    max_depth(binary_to_list(S), 0, 0).

max_depth([], _Current, Max) ->
    Max;
max_depth([$( | Rest], Current, Max) ->
    NewCurrent = Current + 1,
    max_depth(Rest, NewCurrent, max(Max, NewCurrent));
max_depth([$) | Rest], Current, Max) ->
    max_depth(Rest, Current - 1, Max);
max_depth([_ | Rest], Current, Max) ->
    max_depth(Rest, Current, Max).
```

### Explanation

- `binary_to_list(S)` converts the input binary string into a list of characters.
- The recursive helper `max_depth/3` carries three values:
  - The remaining list of characters.
  - `Current` — the current nesting depth.
  - `Max` — the maximum depth seen so far.
- On `'('`: increment `Current` and update `Max`.
- On `')'`: decrement `Current`.
- On any other character: continue without change.
- Base case: when the list is empty, return `Max`.

### Dry Run

For `s = "(1+(2*3)+((8)/4))+1"`:

| Step | Char | Current | Max |
|------|------|---------|-----|
| 1    | `(`  | 1       | 1   |
| 2    | `1`  | 1       | 1   |
| 3    | `+`  | 1       | 1   |
| 4    | `(`  | 2       | 2   |
| 5    | `2`  | 2       | 2   |
| 6    | `*`  | 2       | 2   |
| 7    | `3`  | 2       | 2   |
| 8    | `)`  | 1       | 2   |
| 9    | `+`  | 1       | 2   |
| 10   | `(`  | 2       | 2   |
| 11   | `(`  | **3**   | **3** |
| 12   | `8`  | 3       | 3   |
| 13   | `)`  | 2       | 3   |
| 14   | `/`  | 2       | 3   |
| 15   | `4`  | 2       | 3   |
| 16   | `)`  | 1       | 3   |
| 17   | `)`  | 0       | 3   |
| 18   | `+`  | 0       | 3   |
| 19   | `1`  | 0       | 3   |

**Result: `3`** ✅

## Alternative One-Liner (Erlang)

Using `lists:foldl/3`:

```erlang
-spec max_depth(S :: unicode:unicode_binary()) -> integer().
max_depth(S) ->
    {_, Max} = lists:foldl(
        fun
            ($(, {Cur, M}) -> {Cur + 1, max(M, Cur + 1)};
            ($), {Cur, M}) -> {Cur - 1, M};
            (_,  {Cur, M}) -> {Cur, M}
        end,
        {0, 0},
        binary_to_list(S)
    ),
    Max.
```

---

## Key Takeaways

- Only the **parentheses characters** matter for computing depth.
- Since the input is guaranteed to be a **valid parentheses string**, we don't need to handle unbalanced cases.
- A simple counter + running maximum is enough — no stack required.
