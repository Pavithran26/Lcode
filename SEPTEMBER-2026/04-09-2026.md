# Smallest Stable Index I

## Problem Statement

You are given an integer array `nums` of length `n` and an integer `k`.

For each index `i`, define its **instability score** as:

```

max(nums[0..i]) - min(nums[i..n-1])

```

Where:

- `max(nums[0..i])` is the largest value among elements from index `0` to `i` (inclusive).
- `min(nums[i..n-1])` is the smallest value among elements from index `i` to `n-1` (inclusive).

An index `i` is called **stable** if its instability score is **less than or equal to** `k`.

Return the **smallest stable index**. If no such index exists, return `-1`.

### Constraints

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 10^9`
- `0 <= k <= 10^9`

---

## Examples

### Example 1

**Input:** `nums = [5,0,1,4]`, `k = 3`  
**Output:** `3`

**Explanation:**

| Index | max(nums[0..i]) | min(nums[i..n-1]) | Instability |
|-------|------------------|--------------------|-------------|
| 0     | 5                | 0                  | 5           |
| 1     | 5                | 0                  | 5           |
| 2     | 5                | 1                  | 4           |
| 3     | 5                | 4                  | 1           |

The first index with instability ≤ 3 is `3`.

---

### Example 2

**Input:** `nums = [3,2,1]`, `k = 1`  
**Output:** `-1`

**Explanation:**

| Index | max | min | Instability |
|-------|-----|-----|-------------|
| 0     | 3   | 1   | 2           |
| 1     | 3   | 1   | 2           |
| 2     | 3   | 1   | 2           |

No index has instability ≤ 1, so return `-1`.

---

### Example 3

**Input:** `nums = [0]`, `k = 0`  
**Output:** `0`

**Explanation:**

Only index `0`: `max([0]) = 0`, `min([0]) = 0`, instability = `0 ≤ 0`, so answer is `0`.

---

## Approach

We need to efficiently compute for each index `i`:

- `prefixMax[i] = max(nums[0..i])`
- `suffixMin[i] = min(nums[i..n-1])`

Then the instability is `prefixMax[i] - suffixMin[i]`.

We can precompute:

1. **Prefix Maximum** array: scan from left to right, keeping the maximum so far.
2. **Suffix Minimum** array: scan from right to left, keeping the minimum so far.

After that, iterate `i` from `0` to `n-1` and return the first index where `prefixMax[i] - suffixMin[i] <= k`.

### Complexity

- **Time:** `O(n)` – two passes for precomputation and one pass for checking.
- **Space:** `O(n)` for the two auxiliary arrays (or we can use only suffixMin and compute prefixMax on the fly, still `O(n)` space for suffixMin). Given constraints (n ≤ 100), this is trivial.

---

## Solution Code (Java)

```java
class Solution {
    public int firstStableIndex(int[] nums, int k) {
        int n = nums.length;

        // prefixMax[i] = max(nums[0..i])
        int[] prefixMax = new int[n];
        prefixMax[0] = nums[0];
        for (int i = 1; i < n; i++) {
            prefixMax[i] = Math.max(prefixMax[i - 1], nums[i]);
        }

        // suffixMin[i] = min(nums[i..n-1])
        int[] suffixMin = new int[n];
        suffixMin[n - 1] = nums[n - 1];
        for (int i = n - 2; i >= 0; i--) {
            suffixMin[i] = Math.min(suffixMin[i + 1], nums[i]);
        }

        // Find the first stable index
        for (int i = 0; i < n; i++) {
            int instability = prefixMax[i] - suffixMin[i];
            if (instability <= k) {
                return i;
            }
        }

        return -1;
    }
}
```

---

Alternative (Optimized Space)

We can avoid the prefixMax array by keeping a running maximum while scanning from left to right, but we still need the suffixMin array. That reduces space to O(n) anyway (only one auxiliary array). The code above is straightforward and clear.
