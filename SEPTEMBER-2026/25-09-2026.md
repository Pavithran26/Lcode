# LeetCode 1096. Brace Expansion II

## Problem

Under the given grammar, strings can represent a set of lowercase words.  
Let `R(expr)` denote the set of words the expression represents.

Grammar rules:

1. For every lowercase letter `x`, `R(x) = {x}`.
2. For expressions `e1, e2, ..., ek` with `k >= 2`,  
   `R({e1, e2, ...}) = R(e1) ∪ R(e2) ∪ ...`
3. For expressions `e1` and `e2`,  
   `R(e1 + e2) = {a + b for (a, b) in R(e1) × R(e2)}`,  
   where `+` denotes concatenation.

Given an expression, return the sorted list of words that the expression represents.
