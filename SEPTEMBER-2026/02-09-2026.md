# 3875. Construct Uniform Parity Array I

**Easy** | [LeetCode Problem Link](https://leetcode.com/problems/construct-uniform-parity-array-i/)

---

## Problem Description

You are given an array `nums1` of `n` **distinct** integers.  
You need to construct another array `nums2` of the same length such that **all elements in `nums2` are either all odd or all even**.

For each index `i`, you may choose **exactly one** of the following operations (in any order):

- `nums2[i] = nums1[i]`
- `nums2[i] = nums1[i] - nums1[j]`, for some index `j ≠ i`

Return `true` if it is possible to construct such an array, otherwise return `false`.

---

### Examples

**Example 1**  
```
Input: nums1 = [2,3]
Output: true
```
Explanation:  
- Choose `nums2[0] = 2 - 3 = -1` (odd)  
- Choose `nums2[1] = 3` (odd)  
Result: `[-1, 3]` – all odd → `true`

**Example 2**  
```
Input: nums1 = [4,6]
Output: true
```
Explanation:  
- Choose `nums2[0] = 4` (even)  
- Choose `nums2[1] = 6` (even)  
Result: `[4, 6]` – all even → `true`

---

## Solution

The answer is **always `true`** regardless of the input. Here's why:

### Case 1: At least one odd number exists in `nums1`
- For any **even** element `nums1[i]`, pick **any odd** element `nums1[j]` (with `j ≠ i`) and set  
  `nums2[i] = nums1[i] - nums1[j]` → **even – odd = odd**.
- For any **odd** element `nums1[i]`, simply keep it: `nums2[i] = nums1[i]` (odd).
- Thus we can make **all elements in `nums2` odd**.

### Case 2: All numbers in `nums1` are even
- Set `nums2[i] = nums1[i]` for every `i`.  
  Since every number is even, **all elements in `nums2` are even**.

Both cases cover every possible input, so the construction is always possible.

> **Note:** The array `nums1` consists of **distinct** integers, and the difference operation is allowed for any `j ≠ i`. Even if `n = 1`, the only option is to keep the single element, which automatically satisfies the parity condition (either all odd or all even).

## Alternative Implementation (for clarity)

If you prefer to explicitly check the parity cases (though unnecessary), you could write:

```java
class Solution {
    public boolean uniformArray(int[] nums1) {
        boolean hasOdd = false;
        for (int num : nums1) {
            if (num % 2 != 0) {
                hasOdd = true;
                break;
            }
        }
        // If there is at least one odd, we can make all odd.
        // If there is no odd, we can make all even.
        return true; // always true
    }
}
```

But the simpler `return true` is sufficient and demonstrates the insight.
