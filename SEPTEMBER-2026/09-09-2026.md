# 3871. Count Commas in Range II

## Problem Statement

Given an integer `n`, return the total number of commas used when writing all integers from `[1, n]` (inclusive) in standard number formatting.

In standard formatting:
- A comma is inserted after every three digits from the right.
- Numbers with fewer than 4 digits contain no commas.

### Examples

**Example 1:**
```
Input: n = 1002
Output: 3
Explanation: The numbers "1,000", "1,001", and "1,002" each contain one comma, giving a total of 3.
```

**Example 2:**
```
Input: n = 998
Output: 0
Explanation: All numbers from 1 to 998 have fewer than four digits, so no commas are used.
```

### Constraints
- `1 <= n <= 10^15`

---

## Approach

We count the total number of commas by splitting numbers based on their **digit length**.

### Key Observation
For a number with `d` digits, the number of commas it contains is:
```
commas = (d - 1) / 3   (integer division)
```
- `d = 1,2,3` → 0 commas  
- `d = 4,5,6` → 1 comma  
- `d = 7,8,9` → 2 commas  
- etc.

### Counting Strategy

1. **Count numbers with fewer than `L` digits** (where `L` is the number of digits of `n`).  
   For each length `d` from 1 to `L-1`:
   - The count of numbers with exactly `d` digits is `9 * 10^(d-1)` (except for `d=1`, but the formula works for all `d >= 1` because numbers from `10^(d-1)` to `10^d - 1`).
   - Multiply that count by `(d-1)/3` and add to the answer.

2. **Count numbers with exactly `L` digits** (from `10^(L-1)` to `n`).  
   - Count = `n - 10^(L-1) + 1`.
   - Multiply by `(L-1)/3` and add to the answer.

We precompute powers of 10 up to `10^15` to easily get `10^(d-1)`.

**Time Complexity:** O(log n) – we iterate over the number of digits (at most 16).  
**Space Complexity:** O(log n) – for the precomputed powers array.

---

## Java Solution

```java
class Solution {
    public long countCommas(long n) {
        String s = Long.toString(n);
        int L = s.length();

        // Precompute powers of 10 up to 10^15 (safe for n <= 10^15)
        long[] pow10 = new long[17];
        pow10[0] = 1;
        for (int i = 1; i < pow10.length; i++) {
            pow10[i] = pow10[i - 1] * 10;
        }

        long ans = 0;

        // Count numbers with exactly d digits for d < L
        for (int d = 1; d < L; d++) {
            long count = 9 * pow10[d - 1]; // numbers from 10^(d-1) to 10^d - 1
            if (d >= 4) { // only d >= 4 have at least one comma
                ans += count * ((d - 1) / 3);
            }
        }

        // Count numbers with exactly L digits: from 10^(L-1) to n
        long countLast = n - pow10[L - 1] + 1;
        if (L >= 4) {
            ans += countLast * ((L - 1) / 3);
        }

        return ans;
    }
}
```

### Explanation of Code

- We get the digit length `L` by converting `n` to a string.
- `pow10[i]` holds `10^i`.
- For each digit length `d` from 1 to `L-1`:
  - `count = 9 * pow10[d-1]` is the total count of numbers with exactly `d` digits.
  - `(d-1)/3` gives the commas per number.
  - We add to `ans` only if `d >= 4` (otherwise zero, but the multiplication would still give zero because `(d-1)/3 = 0`; the condition is optional).
- For the last digit length `L`:
  - `countLast = n - pow10[L-1] + 1` is the count of numbers from `10^(L-1)` to `n`.
  - Multiply by `(L-1)/3` and add.

## Notes

- The formula `(d-1)/3` works for all `d >= 1` because integer division truncates. For `d = 1,2,3` it yields 0.
- The upper bound `10^15` has 16 digits, so `pow10` size 17 is sufficient.

This approach avoids iterating over every number, making it efficient even for very large `n`.
