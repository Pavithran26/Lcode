# LeetCode 3525. Find X Value of Array II

## Problem Summary

You are given an array `nums` of positive integers, a positive integer `k`, and a list of queries.  
Each query is `[index, value, start, x]`.

For each query:

1. Update `nums[index] = value`. This update is **persistent** for all following queries.
2. Remove the prefix `nums[0 .. start-1]` (the empty prefix is represented by `start = 0`).
3. Consider the remaining subarray `A = nums[start .. n-1]`.
4. You may remove any suffix from `A` such that `A` remains non-empty.
5. The product of the remaining elements modulo `k` must equal `x`.
6. Return the number of ways to perform this operation.

In other words, after removing the prefix, you need to count the number of **non-empty prefixes** of the remaining subarray whose product modulo `k` equals `x`.

## Approach

The key observation is that after removing the prefix `nums[0 .. start-1]`, the operation of removing a suffix leaves a non-empty prefix of the subarray `nums[start .. n-1]`.  
So each query reduces to:

> Count non-empty prefixes of `nums[start .. n-1]` whose product modulo `k` is `x`.

Since `k <= 5`, we can efficiently maintain prefix product counts using a **segment tree**.

### Segment Tree Node

Each node represents a contiguous segment of the array and stores:

- `prod`: the product of all elements in the segment modulo `k`.
- `cnt[r]`: the number of non-empty prefixes of this segment whose product modulo `k` equals `r`.

### Merge Operation

Given a left child `L` and a right child `R`, their parent node is computed as:

- `prod = (L.prod * R.prod) % k`
- `cnt = L.cnt`
- For every remainder `r`, add `R.cnt[r]` to `cnt[(L.prod * r) % k]`.

This works because a prefix of the concatenated segment is either:
- a prefix of `L`, or
- the entire `L` followed by a non-empty prefix of `R`.

### Point Update

Updating `nums[index]` is a standard point update in the segment tree.  
After updating the leaf, we recompute all ancestors using the merge operation.

### Range Query

For a query `[start, n-1]`, we combine the relevant segment tree nodes from left to right.  
The final `cnt` array gives the number of non-empty prefixes for each remainder.  
The answer is `cnt[x]`.

## Complexity

- **Time:**  
  - Build: `O(n * k)`  
  - Each update: `O(k * log n)`  
  - Each query: `O(k * log n)`  
  - Total: `O((n + q) * k * log n)`  
  Since `k <= 5`, this is very fast.

- **Space:** `O(n * k)` for the segment tree.

## Java Solution

```java
class Solution {
    public int[] resultArray(int[] nums, int k, int[][] queries) {
        int n = nums.length;
        int size = 1;
        while (size < n) size <<= 1;

        // prod[node] = product of the whole segment modulo k
        // cnt[node][r] = number of non-empty prefixes of this segment
        //                 whose product modulo k is r
        int[] prod = new int[2 * size];
        int[][] cnt = new int[2 * size][k];

        for (int i = 0; i < 2 * size; i++) {
            prod[i] = 1; // identity for empty segments
        }

        for (int i = 0; i < n; i++) {
            int v = nums[i] % k;
            prod[size + i] = v;
            cnt[size + i][v] = 1;
        }

        for (int i = size - 1; i >= 1; i--) {
            pull(i, k, prod, cnt);
        }

        int[] ans = new int[queries.length];

        for (int qi = 0; qi < queries.length; qi++) {
            int[] q = queries[qi];

            int index = q[0];
            int value = q[1];
            int start = q[2];
            int x = q[3];

            update(index, value, k, size, prod, cnt);
            ans[qi] = query(start, n - 1, x, k, size, prod, cnt);
        }

        return ans;
    }

    private void pull(int node, int k, int[] prod, int[][] cnt) {
        int left = node << 1;
        int right = left | 1;

        prod[node] = (prod[left] * prod[right]) % k;

        int[] cur = cnt[node];
        int[] lc = cnt[left];
        int[] rc = cnt[right];

        for (int i = 0; i < k; i++) {
            cur[i] = lc[i];
        }

        int lp = prod[left];
        for (int r = 0; r < k; r++) {
            int c = rc[r];
            if (c != 0) {
                cur[(lp * r) % k] += c;
            }
        }
    }

    private void update(int index, int value, int k, int size, int[] prod, int[][] cnt) {
        int pos = size + index;
        int v = value % k;

        prod[pos] = v;
        for (int i = 0; i < k; i++) {
            cnt[pos][i] = 0;
        }
        cnt[pos][v] = 1;

        pos >>= 1;
        while (pos > 0) {
            pull(pos, k, prod, cnt);
            pos >>= 1;
        }
    }

    private int query(int l, int r, int x, int k, int size, int[] prod, int[][] cnt) {
        l += size;
        r += size;

        int leftProd = 1;
        int[] leftCnt = new int[k];
        int[] rightCnt = new int[k];

        while (l <= r) {
            if ((l & 1) == 1) {
                int nodeProd = prod[l];
                int[] nodeCnt = cnt[l];
                int[] newCnt = new int[k];

                for (int i = 0; i < k; i++) {
                    newCnt[i] = leftCnt[i];
                }

                for (int q = 0; q < k; q++) {
                    int c = nodeCnt[q];
                    if (c != 0) {
                        newCnt[(leftProd * q) % k] += c;
                    }
                }

                leftProd = (leftProd * nodeProd) % k;
                leftCnt = newCnt;
                l++;
            }

            if ((r & 1) == 0) {
                int nodeProd = prod[r];
                int[] nodeCnt = cnt[r];
                int[] newCnt = new int[k];

                for (int i = 0; i < k; i++) {
                    newCnt[i] = nodeCnt[i];
                }

                for (int q = 0; q < k; q++) {
                    int c = rightCnt[q];
                    if (c != 0) {
                        newCnt[(nodeProd * q) % k] += c;
                    }
                }

                rightCnt = newCnt;
                r--;
            }

            l >>= 1;
            r >>= 1;
        }

        int[] res = new int[k];
        for (int i = 0; i < k; i++) {
            res[i] = leftCnt[i];
        }

        for (int q = 0; q < k; q++) {
            int c = rightCnt[q];
            if (c != 0) {
                res[(leftProd * q) % k] += c;
            }
        }

        return res[x];
    }
}
