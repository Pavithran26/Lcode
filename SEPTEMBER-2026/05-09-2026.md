Smallest Stable Index II

Problem Statement

Given an integer array nums of length n and an integer k.

For each index i, define its instability score as:

```
max(nums[0..i]) - min(nums[i..n-1])
```

· max(nums[0..i]) is the maximum element from index 0 to i.
· min(nums[i..n-1]) is the minimum element from index i to n-1.

An index i is stable if its instability score is less than or equal to k.

Return the smallest stable index. If no such index exists, return -1.

---

Examples

Example 1

```
Input: nums = [5,0,1,4], k = 3
Output: 3
```

Explanation:

· i=0: max[5]=5, min[5,0,1,4]=0 → 5-0=5 > 3
· i=1: max[5,0]=5, min[0,1,4]=0 → 5-0=5 > 3
· i=2: max[5,0,1]=5, min[1,4]=1 → 5-1=4 > 3
· i=3: max[5,0,1,4]=5, min[4]=4 → 5-4=1 ≤ 3 → first stable index = 3

Example 2

```
Input: nums = [3,2,1], k = 1
Output: -1
```

Explanation:
All indices have score = 3 - 1 = 2 > 1, so no stable index exists.

Example 3

```
Input: nums = [0], k = 0
Output: 0
```

Explanation:
Score = 0 - 0 = 0 ≤ 0 → index 0 is stable.

---

Approach

We can solve this efficiently in O(n) time and O(n) extra space (or O(1) if we precompute suffix minima in-place).

Idea:

· For each index i, we need the maximum of the prefix nums[0..i] and the minimum of the suffix nums[i..n-1].
· Maintain a prefix maximum as we iterate from left to right.
· Precompute suffix minimum array where suffixMin[i] = minimum value in nums[i..n-1].
· Then for each i, compute score = prefixMax - suffixMin[i] and check if ≤ k.
· The first such i is the answer.

Steps:

1. If n == 0 (not possible given constraints but guard), return -1.
2. Build suffixMin array of length n:
   · suffixMin[n-1] = nums[n-1]
   · For i = n-2 down to 0: suffixMin[i] = min(nums[i], suffixMin[i+1])
3. Initialize prefixMax = Integer.MIN_VALUE.
4. Loop i = 0 to n-1:
   · Update prefixMax = max(prefixMax, nums[i])
   · If prefixMax - suffixMin[i] <= k, return i.
5. Return -1 if no index found.

Complexity:

· Time: O(n) – single pass for suffix min, single pass for checking.
· Space: O(n) – for suffixMin array (can be optimized to O(1) by modifying input or using a single variable if we precompute suffix minima in-place, but O(n) is fine).

---

Code

```java
class Solution {
    public int firstStableIndex(int[] nums, int k) {
        int n = nums.length;
        if (n == 0) return -1;

        // suffixMin[i] = minimum value in nums[i..n-1]
        int[] suffixMin = new int[n];
        suffixMin[n - 1] = nums[n - 1];
        for (int i = n - 2; i >= 0; i--) {
            suffixMin[i] = Math.min(nums[i], suffixMin[i + 1]);
        }

        int prefixMax = Integer.MIN_VALUE;

        for (int i = 0; i < n; i++) {
            prefixMax = Math.max(prefixMax, nums[i]);

            // use long to avoid overflow (though values fit in int, safe)
            if ((long) prefixMax - suffixMin[i] <= k) {
                return i;
            }
        }

        return -1;
    }
}
```

---

Edge Cases

· Single element: always stable if nums[0] - nums[0] = 0 ≤ k (k≥0).
· All scores > k → return -1.
· Large values: use long for subtraction to avoid overflow.
