# 1520. Maximum Number of Non-Overlapping Substrings

**Difficulty:** Hard  
**Topics:** String, Greedy, Interval Scheduling

---

## Problem

Given a string `s` of lowercase letters, find the maximum number of non-empty substrings of `s` that meet the following conditions:

1. The substrings do not overlap.
2. If a substring contains a character `c`, it must contain **all** occurrences of `c` in `s`.

If there are multiple solutions with the same maximum number of substrings, return the one with the **minimum total length**.

You may return the substrings in any order.

---

## Examples

### Example 1

```text
Input: s = "adefaddaccc"
Output: ["e","f","ccc"]
```

Explanation:  
The optimal choice is `["e","f","ccc"]`, which gives 3 non-overlapping valid substrings.

### Example 2

```text
Input: s = "abbaccd"
Output: ["d","bb","cc"]
```

Explanation:  
`["d","abba","cc"]` also has 3 substrings, but it has larger total length, so it is not optimal.

---

## Approach

1. **Record first and last occurrence** of every character in `s`.
2. For each character `c`:
   - Start with an interval `[l, r] = [first[c], last[c]]`.
   - Expand `l` and `r` until the interval contains all occurrences of every character inside it.
   - If after expansion `l == first[c]`, then this interval is a valid candidate substring.
3. **Sort candidates** by right endpoint ascending.  
   For equal right endpoints, sort by left endpoint descending (shorter interval first).
4. **Greedily pick intervals**:
   - Keep track of `lastEnd`.
   - If `interval.left > lastEnd`, take this interval and update `lastEnd = interval.right`.

This greedy strategy maximizes the number of intervals and minimizes total length for ties.

---

## Correctness

- Expanding intervals ensures that each candidate substring contains all occurrences of every character it contains.
- Only intervals whose left endpoint equals the first occurrence of some character are considered. Any optimal solution can be formed from these candidates.
- Sorting by right endpoint and greedily selecting non-overlapping intervals is the classic interval scheduling algorithm, which maximizes the number of selected intervals.
- For equal right endpoints, choosing the shorter interval reduces total length without reducing the maximum count.

---

## Complexity

- **Time:** `O(n * 26 + k log k)` where `k <= 26`. Effectively `O(n)`.
- **Space:** `O(26)` or `O(k)`.

---

## Java Solution

```java
import java.util.*;

class Solution {
    public List<String> maxNumOfSubstrings(String s) {
        int n = s.length();
        int[] first = new int[26];
        int[] last = new int[26];
        Arrays.fill(first, n);
        Arrays.fill(last, -1);

        for (int i = 0; i < n; i++) {
            int c = s.charAt(i) - 'a';
            if (first[c] == n) first[c] = i;
            last[c] = i;
        }

        List<int[]> intervals = new ArrayList<>();

        for (int c = 0; c < 26; c++) {
            if (first[c] == n) continue;

            int l = first[c];
            int r = last[c];

            // Expand interval until it contains all occurrences of every character inside it.
            boolean changed = true;
            while (changed) {
                changed = false;
                for (int i = l; i <= r; i++) {
                    int ch = s.charAt(i) - 'a';
                    if (first[ch] < l) {
                        l = first[ch];
                        changed = true;
                    }
                    if (last[ch] > r) {
                        r = last[ch];
                        changed = true;
                    }
                }
            }

            // Only keep the interval if its left endpoint is the first occurrence of c.
            if (l == first[c]) {
                intervals.add(new int[]{l, r});
            }
        }

        // Greedy interval scheduling:
        // maximize number of intervals, then minimize total length.
        intervals.sort((a, b) -> {
            if (a[1] != b[1]) return a[1] - b[1];
            return b[0] - a[0]; // shorter interval first for same right endpoint
        });

        List<String> ans = new ArrayList<>();
        int lastEnd = -1;

        for (int[] interval : intervals) {
            int l = interval[0];
            int r = interval[1];

            if (l > lastEnd) {
                ans.add(s.substring(l, r + 1));
                lastEnd = r;
            }
        }

        return ans;
    }
}
```
