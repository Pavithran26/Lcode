 LeetCode 2029. Stone Game IX

## Problem Statement

Alice and Bob play a game with `n` stones, each having an associated value. The players alternate turns, starting with Alice. On each turn, a player removes any stone. A player **loses** immediately if the sum of the values of all removed stones becomes divisible by `3`. If all stones are removed and no one has lost yet, Bob wins automatically (even if it is Alice's turn).

Both players play optimally. Return `true` if Alice wins, otherwise return `false`.

---

## Examples

### Example 1
```

Input: stones = [2,1]
Output: true

```
**Explanation:**  
Alice removes either stone. Bob removes the remaining one. The total sum is `3`, divisible by `3`, so Bob loses → Alice wins.

### Example 2
```

Input: stones = [2]
Output: false

```
**Explanation:**  
Alice removes the only stone. Sum is `2` (not divisible by `3`), and no stones remain → Bob wins.

### Example 3
```

Input: stones = [5,1,2,4,3]
Output: false

```
**Explanation:**  
Bob can force a win. One possible sequence leads to total sum `15`, which is divisible by `3` and Alice loses.

---

## Solution Approach

We only care about each stone's value modulo `3`. Let:

- `cnt[0]` = number of stones with value divisible by `3`
- `cnt[1]` = number of stones with value ≡ `1 (mod 3)`
- `cnt[2]` = number of stones with value ≡ `2 (mod 3)`

### Key Observations

1. **Stones with value % 3 == 0**  
   - Picking such a stone does **not** change the current remainder of the total sum.  
   - They act as "pass" moves. If the count of such stones is even, they cancel out (the same player will always be affected). If odd, they flip the turn parity.

2. **Winning condition**  
   - The game is decided by who is forced to make the total sum divisible by `3`.  
   - To win, Alice must force Bob into a losing position.

3. **Optimal strategy**  
   - If `cnt[0]` is even:
     - Alice can win **only if** both `cnt[1] > 0` and `cnt[2] > 0`.  
     - Reason: She starts with either type `1` or `2`, then the opponent must pick the other type to avoid losing, and the sequence continues. If one type is missing, Bob can always mirror to win.
   - If `cnt[0]` is odd:
     - Alice can win if the absolute difference `|cnt[1] - cnt[2]| > 2`.  
     - The odd number of zero‑modulo stones acts as an extra turn that flips the roles, giving Alice a chance if the imbalance is large enough.

### Final Conditions

```java
if (cnt[0] % 2 == 0) {
    return cnt[1] > 0 && cnt[2] > 0;
} else {
    return Math.abs(cnt[1] - cnt[2]) > 2;
}
```

---

Complexity

· Time: O(n) – single pass to count modulo classes.
· Space: O(1) – constant extra space.

---

Code (Java)

```java
class Solution {
    public boolean stoneGameIX(int[] stones) {
        int[] cnt = new int[3];
        
        for (int x : stones) {
            cnt[x % 3]++;
        }
        
        if (cnt[0] % 2 == 0) {
            return cnt[1] > 0 && cnt[2] > 0;
        } else {
            return Math.abs(cnt[1] - cnt[2]) > 2;
        }
    }
}
```
