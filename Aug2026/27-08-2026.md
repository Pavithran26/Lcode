# LeetCode 3720 - Lexicographically Smallest Permutation Greater Than Target

## 📝 Problem Statement

Given two strings `s` and `target` of equal length `n` consisting of lowercase English letters, return the **lexicographically smallest permutation** of `s` that is **strictly greater** than `target`. If no such permutation exists, return an empty string `""`.

A string `a` is lexicographically strictly greater than `b` if at the first differing position, `a` has a character that appears later in the alphabet.

---

## 📌 Examples

### Example 1
```
Input: s = "abc", target = "bba"
Output: "bca"

Explanation:
Permutations of "abc" in order: "abc", "acb", "bac", "bca", "cab", "cba".
"bca" is the smallest permutation > "bba".
```

### Example 2
```
Input: s = "leet", target = "code"
Output: "eelt"
```

### Example 3
```
Input: s = "baba", target = "bbaa"
Output: ""

Explanation:
Permutations: "aabb", "abab", "abba", "baab", "baba", "bbaa".
None are > "bbaa".
```

---

## 🧠 Approach

The solution uses a **greedy + backtracking** strategy:

### 1. Character Frequency Counting
Count the occurrences of each character in `s` using an array `count[26]`.

### 2. Try to Match Prefix
Iterate over positions `i` from `0` to `n-1`:

- **Try placing the same character as `target[i]`** (`count[c] > 0`).
  - Place it temporarily (`count[c]--`).
  - Check if it's possible to form a permutation greater than the *remaining suffix* of `target` using the remaining characters.
  - If yes, keep this character and move to the next position.
  - If not, revert the count (`count[c]++`) and look for a larger character.

- **If matching is impossible**, find the **smallest character greater than `target[i]`** that is still available (`findGreater`).
  - Place that character at position `i`.
  - Fill all remaining positions with the smallest possible characters (ascending order) to ensure the final result is as small as possible.
  - Return the constructed string.

- If no such greater character exists, return `""`.

### 3. Helper Methods
- `canBeGreater(count, target, start)`: Checks if the remaining characters can form a suffix that is **greater** than `target.substring(start)`. It constructs the **maximum possible suffix** (sorted descending) and compares it with the target suffix.
- `findGreater(count, c)`: Finds the smallest character `> c` that still has remaining count.

## ⚙️ Code

```java
class Solution {
    public String lexGreaterPermutation(String s, String target) {
        int n = s.length();
        int[] count = new int[26];
        for (char ch : s.toCharArray()) {
            count[ch - 'a']++;
        }

        StringBuilder res = new StringBuilder();

        for (int i = 0; i < n; i++) {
            int c = target.charAt(i) - 'a';

            if (count[c] > 0) {
                // Try to match target[i]
                count[c]--;

                if (canBeGreater(count, target, i + 1)) {
                    res.append(target.charAt(i));
                    continue;
                }

                // Matching target[i] cannot lead to a valid greater string
                count[c]++;
            }

            // Need to place a character strictly greater than target[i] here
            int greater = findGreater(count, c);
            if (greater == -1) {
                return "";
            }

            res.append((char) ('a' + greater));
            count[greater]--;

            // Fill remaining characters in ascending order to minimize the result
            for (int ch = 0; ch < 26; ch++) {
                for (int k = 0; k < count[ch]; k++) {
                    res.append((char) ('a' + ch));
                }
            }

            return res.toString();
        }

        return "";
    }

    private boolean canBeGreater(int[] count, String target, int start) {
        if (start >= target.length()) {
            return false;
        }

        // Maximum possible string from remaining counts: descending order
        StringBuilder max = new StringBuilder();
        for (int ch = 25; ch >= 0; ch--) {
            for (int k = 0; k < count[ch]; k++) {
                max.append((char) ('a' + ch));
            }
        }

        return max.toString().compareTo(target.substring(start)) > 0;
    }

    private int findGreater(int[] count, int c) {
        for (int ch = c + 1; ch < 26; ch++) {
            if (count[ch] > 0) {
                return ch;
            }
        }
        return -1;
    }
}
```

---

## ⏱️ Complexity Analysis

- **Time Complexity:** `O(n * 26)` ≈ `O(n)`
  - The main loop runs `n` times.
  - `canBeGreater` iterates over 26 characters to build the max suffix.
  - `findGreater` iterates over at most 26 characters.
- **Space Complexity:** `O(n)` for the result string and the frequency array (constant size).
