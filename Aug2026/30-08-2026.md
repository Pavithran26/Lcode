# 2091. Removing Minimum and Maximum From Array

**LeetCode Problem**: [2091. Removing Minimum and Maximum From Array](https://leetcode.com/problems/removing-minimum-and-maximum-from-array/)

**Difficulty**: Medium  
**Topics**: Array, Greedy

---

## Problem Statement

You are given a **0-indexed** array of **distinct** integers `nums`.

There is an element in `nums` that has the **lowest** value and an element that has the **highest** value. We call them the **minimum** and **maximum** respectively. Your goal is to remove **both** these elements from the array.

A **deletion** is defined as either removing an element from the **front** of the array or removing an element from the **back** of the array.

Return the **minimum number of deletions** it would take to remove both the minimum and maximum element from the array.

### Examples

#### Example 1
```
Input: nums = [2,10,7,5,4,1,8,6]
Output: 5
Explanation:
The minimum element is nums[5] = 1.
The maximum element is nums[1] = 10.
We can remove both by removing 2 elements from the front and 3 elements from the back.
Total deletions = 2 + 3 = 5, which is the minimum.
```

#### Example 2
```
Input: nums = [0,-4,19,1,8,-2,-3,5]
Output: 3
Explanation:
Minimum is nums[1] = -4, maximum is nums[2] = 19.
Removing 3 elements from the front removes both.
```

#### Example 3
```
Input: nums = [101]
Output: 1
Explanation:
Only one element, so it is both min and max – remove with 1 deletion.
```

### Constraints
- `1 <= nums.length <= 10^5`
- `-10^5 <= nums[i] <= 10^5`
- All integers in `nums` are distinct.

---

## Approach

The key is to locate the **indices** of the minimum and maximum values. Since we can only delete from the ends, there are only **three possible strategies**:

1. **Delete both from the left** – we must delete all elements up to the farther of the two indices (the larger index).  
   `deletions = max(minIdx, maxIdx) + 1`

2. **Delete both from the right** – we must delete all elements from the end up to the nearer of the two indices (the smaller index).  
   `deletions = n - min(minIdx, maxIdx)`

3. **Delete one from the left and one from the right** – we delete from the front up to the smaller index, and from the back down to the larger index.  
   `deletions = (min(minIdx, maxIdx) + 1) + (n - max(minIdx, maxIdx))`

The answer is the **minimum** of these three values.

### Time Complexity
- **O(n)** – one pass to find indices of min and max.
- **O(1)** – constant extra space.

---

## Solution Code

```java
class Solution {
    public int minimumDeletions(int[] nums) {
        int n = nums.length;
        int minIdx = 0, maxIdx = 0;

        // Find indices of minimum and maximum
        for (int i = 1; i < n; i++) {
            if (nums[i] < nums[minIdx]) minIdx = i;
            if (nums[i] > nums[maxIdx]) maxIdx = i;
        }

        // Three possible ways
        int left = Math.max(minIdx, maxIdx) + 1;
        int right = n - Math.min(minIdx, maxIdx);
        int mixed = Math.min(minIdx, maxIdx) + 1 + (n - Math.max(minIdx, maxIdx));

        return Math.min(left, Math.min(right, mixed));
    }
}
```

---

## Complexity Analysis

- **Time**: `O(n)` – we traverse the array once.
- **Space**: `O(1)` – only a few integer variables.
