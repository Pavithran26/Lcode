# 486. Predict the Winner

## Problem Statement

You are given an integer array `nums`. Two players are playing a game with this array: **Player 1** and **Player 2**.

- Player 1 starts first.
- Both players start with a score of 0.
- At each turn, a player takes one number from either end of the array (i.e., `nums[0]` or `nums[nums.length - 1]`).
- The chosen number is added to the player's score.
- The array is reduced by one element.
- The game ends when no elements remain.

Return `true` if Player 1 can win the game. If scores are equal, Player 1 is still considered the winner, so return `true`. Assume both players play optimally.

### Examples

**Example 1:**
```
Input: nums = [1,5,2]
Output: false
Explanation: 
- Player 1 can pick 1 or 2.
- If Player 1 picks 2, Player 2 picks 5, Player 1 gets 1 → scores 3 vs 5 → lose.
- If Player 1 picks 1, Player 2 picks 5, Player 1 gets 2 → same result.
So Player 1 cannot win.
```

**Example 2:**
```
Input: nums = [1,5,233,7]
Output: true
Explanation:
- Player 1 picks 1 (left end).
- Player 2 must pick 5 or 7.
- If Player 2 picks 5, Player 1 picks 233 → scores 234 vs 12 → win.
- If Player 2 picks 7, Player 1 picks 233 → same result.
So Player 1 can force a win.
```

---

## Approach

We use **Dynamic Programming (DP)** to determine the maximum score difference the current player can achieve from any subarray `nums[i..j]`.

### DP Definition

Let `dp[i][j]` = the maximum score difference (current player's total – opponent's total) that the current player can guarantee from the subarray `nums[i..j]` when it's their turn.

### Recurrence

For a subarray `nums[i..j]`:

- If the current player picks `nums[i]`, they gain `nums[i]` points, and the opponent will play optimally on the remaining subarray `nums[i+1..j]`. The opponent's advantage on that remaining part is `dp[i+1][j]` (from the opponent's perspective). So the net difference for the current player becomes:
  ```
  nums[i] - dp[i+1][j]
  ```

- If the current player picks `nums[j]`, similarly:
  ```
  nums[j] - dp[i][j-1]
  ```

The current player will choose the move that maximizes their net advantage:

```
dp[i][j] = max( nums[i] - dp[i+1][j], nums[j] - dp[i][j-1] )
```

### Base Case

When there is only one element left (`i == j`):
```
dp[i][i] = nums[i]
```
because the current player takes that element and the opponent gets nothing, so the difference is simply `nums[i]`.

### Final Answer

Player 1 wins if the maximum score difference from the whole array `dp[0][n-1]` is **non‑negative** (since equal scores count as a win for Player 1).

---

## Complexity Analysis

- **Time Complexity:** `O(n²)` – we fill a 2D DP table of size `n × n`.
- **Space Complexity:** `O(n²)` for the DP table. (Can be optimized to `O(n)` using a 1D array, but this version uses `O(n²)` for clarity.)

---

## Java Code

```java
class Solution {
    public boolean predictTheWinner(int[] nums) {
        int n = nums.length;
        int[][] dp = new int[n][n];

        // Base case: one element
        for (int i = 0; i < n; i++) {
            dp[i][i] = nums[i];
        }

        // Fill DP for increasing subarray lengths
        for (int len = 2; len <= n; len++) {
            for (int i = 0; i + len - 1 < n; i++) {
                int j = i + len - 1;
                dp[i][j] = Math.max(
                    nums[i] - dp[i + 1][j],
                    nums[j] - dp[i][j - 1]
                );
            }
        }

        return dp[0][n - 1] >= 0;
    }
}
```

## Walkthrough (Example 2)

`nums = [1, 5, 233, 7]`

- `dp[0][0] = 1`, `dp[1][1] = 5`, `dp[2][2] = 233`, `dp[3][3] = 7`

- Length 2:
  - `dp[0][1] = max(1 - 5, 5 - 1) = max(-4, 4) = 4`
  - `dp[1][2] = max(5 - 233, 233 - 5) = max(-228, 228) = 228`
  - `dp[2][3] = max(233 - 7, 7 - 233) = max(226, -226) = 226`

- Length 3:
  - `dp[0][2] = max(1 - dp[1][2], 233 - dp[0][1]) = max(1 - 228, 233 - 4) = max(-227, 229) = 229`
  - `dp[1][3] = max(5 - dp[2][3], 7 - dp[1][2]) = max(5 - 226, 7 - 228) = max(-221, -221) = -221`

- Length 4:
  - `dp[0][3] = max(1 - dp[1][3], 7 - dp[0][2]) = max(1 - (-221), 7 - 229) = max(222, -222) = 222`

Since `dp[0][3] = 222 >= 0`, Player 1 can win.

---

## Notes

- The solution uses a bottom‑up DP approach.
- The game is a classic minimax problem that can also be solved via recursion with memoization.
- This DP computes the score difference directly, avoiding the need to track separate scores for each player.
