# 3302. Find the Lexicographically Smallest Valid Sequence

## Problem Statement

You are given two strings `word1` and `word2`.

A string `x` is called **almost equal** to `y` if you can change at most one character in `x` to make it identical to `y`.

A sequence of indices `seq` is called **valid** if:

1. The indices are sorted in ascending order.
2. Concatenating the characters at these indices in `word1` in the same order results in a string that is almost equal to `word2`.

Return an array of size `word2.length` representing the **lexicographically smallest valid sequence** of indices. If no such sequence exists, return an empty array.

> **Note:** The answer must represent the lexicographically smallest **array**, not the corresponding string formed by those indices.

---

## Examples

### Example 1

```
Input: word1 = "vbcca", word2 = "abc"
Output: [0, 1, 2]
```

**Explanation:**
The lexicographically smallest valid sequence of indices is `[0, 1, 2]`:

- Change `word1[0]` (`'v'`) to `'a'`
- `word1[1]` is already `'b'`
- `word1[2]` is already `'c'`

### Example 2

### Example 3


## Constraints

- `1 <= word2.length < word1.length <= 3 * 10^5`
- `word1` and `word2` consist only of lowercase English letters.

- `suf[m] = n` (sentinel, where `n = word1.length()`)
- For `i` from `m-1` down to `0`:
  - Find the rightmost occurrence of `word2[i]` in `word1[0 ... suf[i+1]-1]`
  - `suf[i]` = that position, or `-1` if not found.

Now, `suf[i] > pos` means the suffix `word2[i...]` can be matched **exactly** in `word1[pos+1 ...]`.

---

### Step 2: Precompute Suffix Matches with One Change

Let `oneSuf[i]` be the **rightmost** position in `word1` that can be used as the **last character** of a match of `word2[i...]` with **at most one change**.

- `oneSuf[m] = n`
- For `i` from `m-1` down to `0`:
  - **Case 1 (exact match at `i`):**  
    Find the rightmost occurrence of `word2[i]` in `word1[0 ... oneSuf[i+1]-1]`  
    → let this be `pos1`
  - **Case 2 (use the change at `i`):**  
    Find the rightmost position `p` in `word1[0 ... suf[i+1]-1]` such that `word1[p] != word2[i]`  
    → let this be `pos2`
  - `oneSuf[i] = max(pos1, pos2)` (the rightmost one that works)

Now, `oneSuf[i] > pos` means the suffix `word2[i...]` can be matched with **at most one change** in `word1[pos+1 ...]`.

---

### Step 3: Greedy Sequence Construction

We build the answer from left to right.

- `last = -1` (last chosen index)
- `changed = false` (whether we already used the one allowed change)

For each position `j` from `0` to `m-1`:

1. **Try exact match first**  
   Find the smallest `i > last` such that:
   - `word1[i] == word2[j]`
   - The remaining suffix `word2[j+1...]` can be matched with **at most one change**:  
     `j+1 == m || oneSuf[j+1] > i`

   If found, pick `i` and continue (no change used).

2. **If not found, try using the change**  
   (only if `!changed`)
   Find the smallest `i > last` such that:
   - `word1[i] != word2[j]`
   - The remaining suffix `word2[j+1...]` must be matched **exactly**:  
     `j+1 == m || suf[j+1] > i`

   If found, pick `i`, set `changed = true`, and continue.

3. **If neither works**, return `[]`.

---

## ⏱️ Complexity Analysis

| Operation | Complexity |
|-----------|------------|
| Precomputing `suf` | O(n + m) |
| Precomputing `oneSuf` | O(n + m) |
| Greedy construction | O(n + m) |
| **Total Time** | **O(n + m)** |
| **Total Space** | **O(n + m)** |

where `n = word1.length()` and `m = word2.length()`.

## 💻 Java Solution

```java
class Solution {
    public int[] validSequence(String word1, String word2) {
        int n = word1.length(), m = word2.length();
        
        // Step 1: Compute suf[i] = rightmost position of exact match for word2[i...]
        int[] suf = new int[m + 1];
        suf[m] = n;
        for (int i = m - 1; i >= 0; i--) {
            int pos = suf[i + 1] - 1;
            while (pos >= 0 && word1.charAt(pos) != word2.charAt(i)) pos--;
            suf[i] = pos;
            if (suf[i] == -1) {
                for (int j = i - 1; j >= 0; j--) suf[j] = -1;
                break;
            }
        }
        
        // Step 2: Compute oneSuf[i] = rightmost position of match for word2[i...] with at most one change
        int[] oneSuf = new int[m + 1];
        oneSuf[m] = n;
        for (int i = m - 1; i >= 0; i--) {
            // Case 1: exact match at i, suffix with at most one change
            int pos1 = -1;
            int limit1 = oneSuf[i + 1] - 1;
            if (limit1 >= 0) {
                for (int p = limit1; p >= 0; p--) {
                    if (word1.charAt(p) == word2.charAt(i)) {
                        pos1 = p;
                        break;
                    }
                }
            }
            
            // Case 2: change at i, suffix exact
            int pos2 = -1;
            int limit2 = (suf[i + 1] == -1) ? -1 : suf[i + 1] - 1;
            if (limit2 >= 0) {
                for (int p = limit2; p >= 0; p--) {
                    if (word1.charAt(p) != word2.charAt(i)) {
                        pos2 = p;
                        break;
                    }
                }
            }
            
            oneSuf[i] = Math.max(pos1, pos2);
        }
        
        // Step 3: Greedy construction
        int[] ans = new int[m];
        int last = -1;
        boolean changed = false;
        
        for (int j = 0; j < m; j++) {
            boolean found = false;
            
            // Try exact match first
            for (int i = last + 1; i < n; i++) {
                if (word1.charAt(i) == word2.charAt(j)) {
                    if (j + 1 == m || oneSuf[j + 1] > i) {
                        ans[j] = i;
                        last = i;
                        found = true;
                        break;
                    }
                }
            }
            
            if (found) continue;
            
            // Try using the one allowed change
            if (changed) return new int[0];
            for (int i = last + 1; i < n; i++) {
                if (word1.charAt(i) != word2.charAt(j)) {
                    if (j + 1 == m || suf[j + 1] > i) {
                        ans[j] = i;
                        last = i;
                        changed = true;
                        found = true;
                        break;
                    }
                }
            }
            
            if (!found) return new int[0];
        }
        
        return ans;
    }
}
```

## 🧩 Key Takeaways

- The problem requires **lexicographically smallest** index sequence, not the string.
- Greedy works when paired with **suffix precomputation** for both exact matches and matches with one change.
- The two suffix arrays (`suf` and `oneSuf`) allow O(1) feasibility checks during greedy construction.
- Time and space complexity are **O(n + m)**, making the solution suitable for the large constraints.
