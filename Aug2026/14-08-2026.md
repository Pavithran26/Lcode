# 3090. Maximum Length Substring With Two Occurrences

## Problem Description

Given a string `s`, return the **maximum length** of a substring such that it contains **at most two occurrences** of each character.

### Examples

**Example 1:**
```
Input: s = "bcbbbcba"
Output: 4
Explanation:
The substring "bcbb" (or "cbbb") has length 4 and each character appears at most twice.
```

**Example 2:**
```
Input: s = "aaaa"
Output: 2
Explanation:
The longest substring with at most two 'a's is "aa" (length 2).
```

### Constraints
- `2 <= s.length <= 100`
- `s` consists only of lowercase English letters.

---

## Approach: Sliding Window

We use a **sliding window** with two pointers (`left` and `right`) to maintain a valid substring where no character appears more than twice.

- Expand the window by moving `right` and increment the frequency of the current character.
- If the current character's frequency exceeds `2`, shrink the window from the left until the frequency becomes valid again.
- Update the maximum length of the window at each step.

### Algorithm

1. Initialize a frequency array of size 26 (for lowercase letters) to zero.
2. Set `left = 0` and `maxLen = 0`.
3. Iterate `right` from 0 to `s.length() - 1`:
   - Increment frequency of `s[right]`.
   - While `freq[s[right] - 'a'] > 2`:
     - Decrement frequency of `s[left]` and move `left++`.
   - Update `maxLen = max(maxLen, right - left + 1)`.
4. Return `maxLen`.

### Complexity Analysis
- **Time Complexity:** `O(n)` – each character is processed at most twice (once by `right`, once by `left`).
- **Space Complexity:** `O(1)` – constant extra space for the frequency array.

---

## Solution Code (Java)

```java
class Solution {
    public int maximumLengthSubstring(String s) {
        int[] freq = new int[26];
        int left = 0;
        int maxLen = 0;

        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);
            freq[c - 'a']++;

            // If current character appears more than twice, shrink window
            while (freq[c - 'a'] > 2) {
                char leftChar = s.charAt(left);
                freq[leftChar - 'a']--;
                left++;
            }

            maxLen = Math.max(maxLen, right - left + 1);
        }

        return maxLen;
    }
}
```

## Alternative Approaches

### Brute Force
- Check all substrings and verify frequency constraints – `O(n^2)` time, not optimal for larger inputs but works for `n ≤ 100`.

### Sliding Window with Map
- Use a `HashMap<Character, Integer>` instead of array, but array is faster and simpler for lowercase letters.

## Discussion

- This problem is a classic **sliding window** variant with a frequency cap of 2.
- It can be extended to `k` occurrences by changing the condition `> 2` to `> k`.
- Since the alphabet is limited to 26, the array-based frequency counting is efficient.
