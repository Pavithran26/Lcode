
## Solution Explanation

We need the **longest subsequence** (any subset, order doesn’t matter) whose XOR is **non‑zero**.

### Key Insight

- Let `X = XOR` of **all** elements in `nums`.
- If `X != 0`, we can take the **whole array** → answer = `n`.
- If `X == 0`, we must **remove at least one** element to get a non‑zero XOR.
  - Removing an element `a` leaves XOR = `X ^ a = 0 ^ a = a`.
  - So if **any** element `a != 0` exists, we can remove it and get a non‑zero XOR.
  - The longest subsequence then has length `n - 1`.
- If **all** elements are zero, every subsequence has XOR `0` → answer = `0`.

### Complexity
- **Time:** `O(n)` – single pass.
- **Space:** `O(1)`.

---

## Java Solution

```java
class Solution {
    public int longestSubsequence(int[] nums) {
        int xorAll = 0;
        boolean hasNonZero = false;
        for (int num : nums) {
            xorAll ^= num;
            if (num != 0) hasNonZero = true;
        }
        int n = nums.length;
        if (xorAll != 0) {
            return n;
        } else {
            return hasNonZero ? n - 1 : 0;
        }
    }
}
```

## Problem Statement

Given an integer array `nums`, return the **length of the longest subsequence** (not necessarily contiguous) whose **bitwise XOR** is **non‑zero**. If no such subsequence exists, return `0`.

### Examples

**Example 1:**
```
Input: nums = [1,2,3]
Output: 2
Explanation: [2,3] → 2 XOR 3 = 1 ≠ 0
```

**Example 2:**
```
Input: nums = [2,3,4]
Output: 3
Explanation: [2,3,4] → 2 XOR 3 XOR 4 = 5 ≠ 0
```

### Constraints
- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^9`

---

## Approach

1. Compute the XOR of all elements (`xorAll`).
2. Track whether any element is non‑zero (`hasNonZero`).
3. If `xorAll != 0` → the whole array is valid → answer = `n`.
4. Else (`xorAll == 0`):
   - If `hasNonZero` is `true`, remove **one** non‑zero element → remaining XOR equals that element (non‑zero) → answer = `n - 1`.
   - Otherwise, all elements are zero → every subsequence XOR is `0` → answer = `0`.

**Why removing exactly one element is optimal?**  
Because we want the longest subsequence; removing zero elements gives XOR = 0 (invalid), so we must remove at least one. Removing one non‑zero element always yields a non‑zero XOR when `xorAll == 0`.

---

## Complexity Analysis
- **Time:** `O(n)` – one pass through the array.
- **Space:** `O(1)` – only a few variables.
