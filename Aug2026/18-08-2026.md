# 3471. Find the Largest Almost Missing Integer

## Problem Statement

You are given an integer array `nums` and an integer `k`.  
An integer `x` is **almost missing** from `nums` if `x` appears in **exactly one** subarray of size `k` within `nums`.

Return the **largest** almost missing integer from `nums`. If no such integer exists, return `-1`.

A **subarray** is a contiguous sequence of elements within an array.

### Examples

**Example 1**  
```
Input: nums = [3,9,2,1,7], k = 3
Output: 7
Explanation:
- 1 appears in 2 subarrays of size 3: [9,2,1] and [2,1,7]
- 2 appears in 3 subarrays: [3,9,2], [9,2,1], [2,1,7]
- 3 appears in 1 subarray: [3,9,2]
- 7 appears in 1 subarray: [2,1,7]
- 9 appears in 2 subarrays: [3,9,2] and [9,2,1]
We return 7 (largest integer that appears exactly once).
```

**Example 2**  
```
Input: nums = [3,9,7,2,1,7], k = 4
Output: 3
Explanation:
- 1 appears in 2 subarrays
- 2 appears in 3 subarrays
- 3 appears in 1 subarray
- 7 appears in 3 subarrays
- 9 appears in 2 subarrays
The only integer appearing exactly once is 3, so we return 3.
```

**Example 3**  
```
Input: nums = [0,0], k = 1
Output: -1
Explanation:
No integer appears in exactly one subarray of size 1.
```

### Constraints

- `1 <= nums.length <= 50`
- `0 <= nums[i] <= 50`
- `1 <= k <= nums.length`

---

## Approach

We need to count, for each distinct integer, in how many **distinct** subarrays of length `k` it appears.  
An integer may appear multiple times within the same subarray, but that should only count **once** for that subarray. Therefore, for each subarray, we collect its unique elements and increment their occurrence count.

### Algorithm

1. Initialize an array `count` of size `51` (since `nums[i]` is between `0` and `50`) to store the number of subarrays in which each value appears.
2. Iterate over all subarrays of length `k`:
   - Use a boolean array `seen` of size `51` to mark which values have already been counted in the current subarray.
   - Traverse the subarray; for each element, if it hasn't been seen yet, mark it as seen and increment its `count`.
3. After processing all subarrays, iterate over possible values from `50` down to `0` and return the first value whose `count` equals `1`.
4. If no such value is found, return `-1`.

### Complexity Analysis

- **Time Complexity:**  
  - There are `(n - k + 1)` subarrays, each of length `k`.  
  - For each subarray, we iterate through its `k` elements and use constant-time operations (boolean array access).  
  - Total time = `O((n - k + 1) * k)`. Since `n <= 50`, this is at most `50 * 50 = 2500` operations, well within limits.

- **Space Complexity:**  
  - We use two auxiliary arrays of size `51`: `count` and `seen`. This is `O(1)` space (constant).

---

## Solution Code (Java)

```java
class Solution {
    public int largestInteger(int[] nums, int k) {
        int n = nums.length;
        int[] count = new int[51]; // nums[i] is between 0 and 50

        for (int start = 0; start + k <= n; start++) {
            boolean[] seen = new boolean[51];

            for (int i = start; i < start + k; i++) {
                int val = nums[i];
                if (!seen[val]) {
                    seen[val] = true;
                    count[val]++;
                }
            }
        }

        for (int val = 50; val >= 0; val--) {
            if (count[val] == 1) {
                return val;
            }
        }

        return -1;
    }
}
```

---

- The key is to count each integer **once per subarray** even if it appears multiple times.  
- We scan values from `50` downward to ensure we return the largest qualifying integer.
