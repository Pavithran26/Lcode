# 2213. Longest Substring of One Repeating Character

This repository contains a Java solution for LeetCode problem [2213. Longest Substring of One Repeating Character](https://leetcode.com/problems/longest-substring-of-one-repeating-character/).

## Problem Statement

You are given a 0‑indexed string `s` and two arrays: `queryCharacters` (length `k`) and `queryIndices` (length `k`).  
The i‑th query updates the character at index `queryIndices[i]` in `s` to `queryCharacters[i]`.  
After each update, you must return the length of the **longest substring consisting of only one repeating character** in the updated string.

### Constraints
- `1 <= s.length <= 10^5`
- `1 <= k <= 10^5`
- Characters are lowercase English letters.

### Example
```text
Input: s = "babacc", queryCharacters = "bcb", queryIndices = [1,3,3]
Output: [3,3,4]

Explanation:
- After 1st query: s = "bbbacc" → longest repeating substring "bbb" length 3
- After 2nd query: s = "bbbccc" → longest is "bbb" or "ccc" length 3
- After 3rd query: s = "bbbbcc" → longest "bbbb" length 4
```

---

## Solution Approach

We need to handle up to 10<sup>5</sup> point updates and answer a global query after each one.  
A naive scan after every update would be too slow. Instead, we use a **segment tree** that stores, for each segment:

- `pref` – length of the longest prefix consisting of a single character
- `suff` – length of the longest suffix consisting of a single character
- `best` – length of the longest substring of one repeating character within the segment
- `lc`, `rc` – the first and last characters of the segment
- `len` – total length of the segment

### Merge Operation

When combining two adjacent segments `L` and `R`, we compute the new values:

- `pref` = if `L` is all one character and its rightmost char equals `R`'s leftmost, then `pref = L.len + R.pref`; otherwise `pref = L.pref`
- `suff` = if `R` is all one character and `L.rc == R.lc`, then `suff = R.len + L.suff`; otherwise `suff = R.suff`
- `best` = max(`L.best`, `R.best`, `L.suff + R.pref` if `L.rc == R.lc`)

This allows us to answer the global `best` at the root in O(1) after each update.

### Algorithm Steps

1. Build a segment tree from the initial string `s`.
2. For each query `(idx, ch)`:
   - Update the leaf at `idx` with character `ch`.
   - Recompute the merged values along the path.
   - Record `tree[1].best` as the answer.
3. Return the result array.

---

## Complexity

- **Time**: Build O(n), each update O(log n), total O((n + k) log n).
- **Space**: O(n) for the segment tree.

## Code

```java
class Solution {
    private static class Node {
        int len, pref, suff, best;
        char lc, rc;

        Node(char c) {
            len = 1; pref = suff = best = 1; lc = rc = c;
        }
        Node() {}
    }

    private Node[] tree;
    private int n;

    public int[] longestRepeating(String s, String queryCharacters, int[] queryIndices) {
        n = s.length();
        tree = new Node[4 * n];
        build(1, 0, n - 1, s.toCharArray());

        int k = queryIndices.length;
        int[] ans = new int[k];

        for (int i = 0; i < k; i++) {
            update(1, 0, n - 1, queryIndices[i], queryCharacters.charAt(i));
            ans[i] = tree[1].best;
        }
        return ans;
    }

    private void build(int node, int l, int r, char[] arr) {
        if (l == r) { tree[node] = new Node(arr[l]); return; }
        int m = (l + r) / 2;
        build(node*2, l, m, arr);
        build(node*2+1, m+1, r, arr);
        tree[node] = merge(tree[node*2], tree[node*2+1]);
    }

    private void update(int node, int l, int r, int idx, char ch) {
        if (l == r) { tree[node] = new Node(ch); return; }
        int m = (l + r) / 2;
        if (idx <= m) update(node*2, l, m, idx, ch);
        else update(node*2+1, m+1, r, idx, ch);
        tree[node] = merge(tree[node*2], tree[node*2+1]);
    }

    private Node merge(Node a, Node b) {
        Node res = new Node();
        res.len = a.len + b.len;
        res.lc = a.lc; res.rc = b.rc;

        // prefix
        res.pref = a.pref;
        if (a.pref == a.len && a.rc == b.lc) res.pref += b.pref;

        // suffix
        res.suff = b.suff;
        if (b.suff == b.len && a.rc == b.lc) res.suff += a.suff;

        // best
        res.best = Math.max(a.best, b.best);
        if (a.rc == b.lc) res.best = Math.max(res.best, a.suff + b.pref);

        return res;
    }
}
```

## How to Run

1. Copy the `Solution` class into a Java file.
2. Use the LeetCode environment or a local testing harness.
3. Example usage:

```java
public class Main {
    public static void main(String[] args) {
        Solution sol = new Solution();
        String s = "babacc";
        String qc = "bcb";
        int[] qi = {1, 3, 3};
        int[] res = sol.longestRepeating(s, qc, qi);
        System.out.println(Arrays.toString(res)); // [3, 3, 4]
    }
}
```
