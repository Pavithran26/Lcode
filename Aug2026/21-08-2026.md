# 3116. Kth Smallest Amount With Single Denomination Combination

[LeetCode Problem Link](https://leetcode.com/problems/kth-smallest-amount-with-single-denomination-combination/)

## Problem Description

You are given an integer array `coins` representing coins of different denominations and an integer `k`.

You have an infinite number of coins of each denomination. However, you are **not allowed to combine coins of different denominations**.

Return the `kth` smallest amount that can be made using these coins.

In other words, each coin denomination `c` generates its own infinite arithmetic progression: `c, 2c, 3c, 4c, ...`.  
We take the union of all these progressions, sort them, and return the `k-th` element.

## Examples

### Example 1

```

Input: coins = [3,6,9], k = 3
Output: 9

```

**Explanation:**
- Coin 3 produces: 3, 6, 9, 12, 15, ...
- Coin 6 produces: 6, 12, 18, 24, ...
- Coin 9 produces: 9, 18, 27, 36, ...

Union (sorted): 3, 6, 9, 12, 15, 18, ...
The 3rd smallest is 9.

### Example 2

```

Input: coins = [5,2], k = 7
Output: 12

```

**Explanation:**
- Coin 5 produces: 5, 10, 15, 20, ...
- Coin 2 produces: 2, 4, 6, 8, 10, 12, ...

Union (sorted): 2, 4, 5, 6, 8, 10, 12, 14, 15, ...
The 7th smallest is 12.

## Constraints

- `1 <= coins.length <= 15`
- `1 <= coins[i] <= 25`
- `1 <= k <= 2 * 10^9`
- All `coins[i]` are pairwise distinct.

## Approach

### Key Insight

We need to find the `k-th` smallest number that is a multiple of at least one coin denomination.

Since `k` can be as large as `2 * 10^9`, linear iteration is impossible.  
Instead, we use **Binary Search** on the answer, combined with the **Inclusion-Exclusion Principle** to count how many numbers ≤ `X` are multiples of any given coin.

### Counting Multiples (`count(x)`)

For a given value `X`, the number of integers ≤ `X` that are divisible by at least one coin from `coins` is:

```

count(X) = Σ (X / coin_i) 
- Σ (X / lcm(coin_i, coin_j)) 
+ Σ (X / lcm(coin_i, coin_j, coin_k)) 
- ...

```

where `lcm` = Least Common Multiple.

Because `coins.length ≤ 15`, we can precompute the LCM and sign for every possible subset using bitmasking (2ⁿ ≤ 32768).

### Binary Search on Answer

- **Lower bound:** `0`
- **Upper bound:** `min(coins) * k`  
  (This is safe because the smallest denomination alone generates at least `k` multiples by `min(coins) * k`.)

We repeatedly test the middle value `mid`. If `count(mid) >= k`, we move the search space left; otherwise right.

### Precomputation Steps

1. For each mask from `1` to `(1 << n) - 1`, compute:
   - `lcm[mask]` = LCM of all coins in that subset.
   - `sign[mask]` = `+1` if subset size is odd, `-1` if even.
2. Use these in the counting function.

---

## Complexity Analysis

- **Time Complexity:**  
  `O(2^n * log(minCoin * k))`  
  Where `n = coins.length`.  
  Precomputing LCM for all masks takes `O(2^n)`.  
  Binary search takes `O(log(range)) ≈ log(minCoin * k)` iterations, and each `count()` call iterates over `2^n` masks.

- **Space Complexity:**  
  `O(2^n)` for storing the precomputed LCM and sign arrays.

---

## Java Solution

```java
class Solution {
    public long findKthSmallest(int[] coins, int k) {
        int n = coins.length;
        int total = 1 << n;

        long[] lcm = new long[total];
        int[] sign = new int[total];
        lcm[0] = 1;

        // Precompute LCM and inclusion-exclusion sign for every subset of coins
        for (int mask = 1; mask < total; mask++) {
            int bit = mask & -mask;
            int idx = Integer.numberOfTrailingZeros(bit);
            int prev = mask ^ bit;

            long a = lcm[prev];
            long b = coins[idx];
            lcm[mask] = a / gcd(a, b) * b;

            sign[mask] = (Integer.bitCount(mask) % 2 == 1) ? 1 : -1;
        }

        long minCoin = Long.MAX_VALUE;
        for (int c : coins) {
            minCoin = Math.min(minCoin, c);
        }

        long lo = 0;
        long hi = minCoin * k; // safe upper bound

        while (lo < hi) {
            long mid = lo + (hi - lo) / 2;

            if (count(mid, lcm, sign) >= k) {
                hi = mid;
            } else {
                lo = mid + 1;
            }
        }

        return lo;
    }

    private long count(long x, long[] lcm, int[] sign) {
        long result = 0;

        for (int mask = 1; mask < lcm.length; mask++) {
            result += sign[mask] * (x / lcm[mask]);
        }

        return result;
    }

    private long gcd(long a, long b) {
        while (b != 0) {
            long temp = a % b;
            a = b;
            b = temp;
        }
        return a;
    }
}
```

· This solution leverages bitmasking for compact subset iteration.
