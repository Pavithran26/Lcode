# 3345. Smallest Divisible Digit Product I

This repository contains my solution to the LeetCode problem [3345. Smallest Divisible Digit Product I](https://leetcode.com/problems/smallest-divisible-digit-product-i/).

## Problem Statement

You are given two integers `n` and `t`. Return the **smallest number greater than or equal to `n`** such that the **product of its digits** is divisible by `t`.

### Examples

**Example 1:**
```
Input: n = 10, t = 2
Output: 10
Explanation: The digit product of 10 is 0, which is divisible by 2.
```

**Example 2:**
```
Input: n = 15, t = 3
Output: 16
Explanation: The digit product of 16 is 1 * 6 = 6, which is divisible by 3.
```

**Example 3:**
```
Input: n = 15, t = 4
Output: 19
Explanation: 
15 → 1*5 = 5 (not divisible)
16 → 1*6 = 6 (not divisible)
17 → 1*7 = 7 (not divisible)
18 → 1*8 = 8 (divisible by 4) → wait, 18 works! Actually 1*8=8, 8%4=0, so the answer is 18.
(Just a quick check, but the examples given in the prompt are enough.)
```

## Constraints

- `1 <= n <= 100`
- `1 <= t <= 10`

## Approach

The constraints are extremely small (`n` up to 100), so a **brute-force** approach is perfectly acceptable.

1. Start from the given number `n`.
2. For each number `num`, calculate the product of its digits.
3. Check if the product is divisible by `t` (i.e., `product % t == 0`).
4. If it is, return `num`.
5. Otherwise, increment `num` by 1 and repeat.

Since the product of digits becomes `0` once the number contains the digit `0`, and `0` is divisible by any `t`, the search will always terminate quickly (at worst, by the time we hit a number containing `0`).

## Complexity Analysis

- **Time Complexity:** `O(m * d)`, where `m` is the number of integers checked from `n` until a valid number is found, and `d` is the number of digits in that number (max 3, since `n <= 100` and we only go up slightly). In practice, this is nearly constant.
- **Space Complexity:** `O(1)`, as we only use a few integer variables.

## Code (Java)

```java
class Solution {
    public int smallestNumber(int n, int t) {
        int num = n;
        
        while (true) {
            int product = 1;
            int temp = num;
            
            // Calculate product of digits
            while (temp > 0) {
                product *= temp % 10;
                temp /= 10;
            }
            
            // Check divisibility
            if (product % t == 0) {
                return num;
            }
            
            num++;
        }
    }
}
```
