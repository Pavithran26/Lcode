# LeetCode 3734 - Lexicographically Smallest Palindromic Permutation Greater Than Target

## Problem Description

You are given two strings `s` and `target`, each of length `n` (1 ≤ n ≤ 300) consisting of lowercase English letters.

Return the **lexicographically smallest string** that is both:

- a **palindromic permutation** of `s` (i.e., a palindrome that can be formed by rearranging the characters of `s`), and
- **strictly greater** than `target`.

If no such palindrome exists, return an empty string.

### Examples

**Example 1:**
```
Input: s = "baba", target = "abba"
Output: "baab"
Explanation: The palindromic permutations of s are "abba" and "baab". "baab" is the smallest > "abba".
```

**Example 2:**
```
Input: s = "baba", target = "bbaa"
Output: ""
Explanation: The palindromic permutations are "abba" and "baab", both ≤ "bbaa".
```

**Example 3:**
```
Input: s = "abc", target = "abb"
Output: ""
Explanation: No palindromic permutation exists (odd count > 1).
```

**Example 4:**
```
Input: s = "aac", target = "abb"
Output: "aca"
Explanation: The only palindromic permutation is "aca", which is > "abb".
```

---

## Approach

### Step 1: Check feasibility of a palindromic permutation

- Count the frequency of each character in `s`.
- A palindrome can be formed if at most one character has an odd frequency.
- If more than one odd frequency exists, return `""`.

### Step 2: Construct the palindrome from the first half

A palindrome of even or odd length is uniquely determined by its **first half** (plus an optional middle character if length is odd).

Let `halfLen = n / 2` and store half of each character's count (i.e., `count[i]/2`). This gives the multiset available for the first half.

### Step 3: Search for the lexicographically smallest palindrome > target

We need to construct a palindrome `P` such that `P > target` and `P` is the smallest possible.

We consider two main cases:

- **Case A:** The first half of `P` is exactly equal to the first half of `target`. In that case, the full palindrome can be built from that prefix. If that palindrome is already > `target`, it is a candidate.
- **Case B:** We find the **rightmost position** `i` in the first half where we can place a character larger than `target[i]`, while keeping the prefix before `i` exactly equal to `target[0..i-1]`. Then we fill the remaining positions with the smallest possible characters to make the whole half lexicographically minimal. Finally, we build the palindrome from that half (and middle character if any).

If no such position exists, return `""`.

### Step 4: Build palindrome from the half string

If the length `n` is odd, insert the middle character (the one with odd frequency) in the center, then append the reverse of the half.

## Code (Java)

```java
class Solution {
    public String lexPalindromicPermutation(String s, String target) {
        int n = s.length();
        int[] cnt = new int[26];
        for (char ch : s.toCharArray()) cnt[ch - 'a']++;

        // Check for palindromic permutation existence
        int odd = 0, midChar = -1;
        for (int i = 0; i < 26; i++) {
            if (cnt[i] % 2 == 1) {
                odd++;
                midChar = i;
            }
        }
        if (odd > 1) return "";

        int m = n / 2;
        int[] half = new int[26];
        for (int i = 0; i < 26; i++) half[i] = cnt[i] / 2;

        // Case 1: first half equals target's first half
        if (canFormPrefix(target, m, half)) {
            String H0 = target.substring(0, m);
            String P0 = buildPalindrome(H0, midChar);
            if (P0.compareTo(target) > 0) return P0;
        }

        // Case 2: find the rightmost position to increase a character
        for (int i = m - 1; i >= 0; i--) {
            // Check if prefix target[0..i-1] can be formed from half counts
            int[] pref = new int[26];
            for (int j = 0; j < i; j++) {
                pref[target.charAt(j) - 'a']++;
            }
            boolean feasible = true;
            for (int c = 0; c < 26; c++) {
                if (pref[c] > half[c]) {
                    feasible = false;
                    break;
                }
            }
            if (!feasible) continue;

            // Remaining characters after using the prefix
            int[] rem = half.clone();
            for (int c = 0; c < 26; c++) rem[c] -= pref[c];

            int need = target.charAt(i) - 'a';
            int chosen = -1;
            for (int c = need + 1; c < 26; c++) {
                if (rem[c] > 0) {
                    chosen = c;
                    break;
                }
            }
            if (chosen == -1) continue;

            // Build the first half
            char[] H = new char[m];
            for (int j = 0; j < i; j++) H[j] = target.charAt(j);
            H[i] = (char) ('a' + chosen);

            // Fill remaining positions with smallest characters
            int[] rem2 = half.clone();
            for (int j = 0; j < i; j++) rem2[target.charAt(j) - 'a']--;
            rem2[chosen]--;

            int idx = i + 1;
            for (int c = 0; c < 26 && idx < m; c++) {
                while (rem2[c] > 0 && idx < m) {
                    H[idx++] = (char) ('a' + c);
                    rem2[c]--;
                }
            }

            return buildPalindrome(new String(H), midChar);
        }

        return "";
    }

    private boolean canFormPrefix(String target, int len, int[] half) {
        int[] need = new int[26];
        for (int i = 0; i < len; i++) {
            need[target.charAt(i) - 'a']++;
        }
        for (int c = 0; c < 26; c++) {
            if (need[c] > half[c]) return false;
        }
        return true;
    }

    private String buildPalindrome(String half, int midChar) {
        StringBuilder sb = new StringBuilder();
        sb.append(half);
        if (midChar != -1) sb.append((char) ('a' + midChar));
        sb.append(new StringBuilder(half).reverse().toString());
        return sb.toString();
    }
}
```

---

## Complexity Analysis

- **Time Complexity:** O(n + 26 * n) ≈ O(n) because we iterate over the string and over the alphabet (constant 26). The loop for each position `i` (up to n/2) does O(26) work to check feasibility, so overall O(26 * n/2) = O(n).
- **Space Complexity:** O(1) extra space (excluding input and output) because we only use arrays of size 26. The output string is O(n) but that's required for the answer.

## Usage

Simply call the method with the two strings:

```java
Solution sol = new Solution();
String result = sol.lexPalindromicPermutation("baba", "abba");
System.out.println(result); // "baab"
```
