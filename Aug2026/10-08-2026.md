# 1140. Stone Game II

[LeetCode Problem Link](https://leetcode.com/problems/stone-game-ii/description/)

## Problem Description
Alice and Bob continue their games with piles of stones. There are a number of piles arranged in a row, and each pile has a positive integer number of stones `piles[i]`. The objective of the game is to end with the most stones.

Alice and Bob take turns, with Alice starting first. On each player's turn, that player can take **all the stones in the first `X` remaining piles**, where `1 <= X <= 2M`. Then, we set `M = max(M, X)`. Initially, `M = 1`. The game continues until all the stones have been taken.

Assuming both players play optimally, return the maximum number of stones Alice can get.

### Examples
**Example 1:**
```

Input: piles = [2,7,9,4,4]
Output: 10

```
**Explanation:**
- If Alice takes one pile (2), Bob takes two piles (7, 9), then Alice takes two piles (4, 4). Alice gets 2 + 4 + 4 = 10 stones.
- If Alice takes two piles (2, 7), then Bob takes all three remaining piles (9, 4, 4). Alice gets 2 + 7 = 9 stones.
Since 10 > 9, the optimal answer is 10.

**Example 2:**
```

Input: piles = [1,2,3,4,5,100]
Output: 104

```

### Constraints
- `1 <= piles.length <= 100`
- `1 <= piles[i] <= 10^4`

---

## Approach
We use **Dynamic Programming with Memoization** (Top-Down approach).

### Intuition
Since the game state is defined purely by the current starting index `i` and the current value of `M`, we can define a recursive function `dp(i, m)` that returns the **maximum number of stones the current player can obtain** from the remaining piles starting at index `i` with parameter `m`.

### Logic
1. **Precomputation**: Use a **Suffix Sum** array, `suffixSum[i]`, to quickly calculate the total number of stones remaining from index `i` to the end of the array.
2. **Base Cases**:
   - If `i >= n` (no piles left), return `0`.
   - If `2 * m >= n - i` (the current player can take all remaining piles), they will simply take everything. Return `suffixSum[i]`.
3. **Recursive Transition**: 
   - The current player tries taking `X` piles, where `1 <= X <= 2 * m` and `i + X <= n`.
   - If they take `X` piles, the remaining game starts at `i + X` with the opponent to play.
   - The opponent's optimal score for that sub-game is `dp(i + X, max(m, X))`.
   - The total stones the current player gets from this choice equals: `suffixSum[i] - dp(i + X, max(m, X))`.
   - We iterate over all valid `X` values and return the **maximum** result. Memoization ensures we never recompute the same `(i, m)` state twice.

---

## Complexity Analysis
- **Time Complexity**: `O(N^3)` in the worst case. However, since `N` is at most `100` (per constraints), this executes extremely fast in practice (about 1 million operations).
- **Space Complexity**: `O(N^2)` for the DP memoization table.

## Solution Code (Java)
```java
import java.util.Arrays;

class Solution {
    public int stoneGameII(int[] piles) {
        int n = piles.length;
        
        // Suffix sum to get total stones from i to end in O(1)
        int[] suffixSum = new int[n + 1];
        for (int i = n - 1; i >= 0; i--) {
            suffixSum[i] = suffixSum[i + 1] + piles[i];
        }
        
        // Memoization table
        int[][] memo = new int[n][n + 1];
        for (int[] row : memo) {
            Arrays.fill(row, -1);
        }
        
        return dfs(0, 1, suffixSum, memo);
    }
    
    private int dfs(int i, int m, int[] suffixSum, int[][] memo) {
        int n = suffixSum.length - 1;
        
        // No stones left
        if (i >= n) return 0;
        
        // Can take all remaining piles
        if (2 * m >= n - i) return suffixSum[i];
        
        // Return cached result if available
        if (memo[i][m] != -1) return memo[i][m];
        
        int maxStones = 0;
        for (int x = 1; x <= 2 * m; x++) {
            if (i + x > n) break;
            int newM = Math.max(m, x);
            // Current player takes X piles. The rest is played optimally by the opponent.
            int currentStones = suffixSum[i] - dfs(i + x, newM, suffixSum, memo);
            maxStones = Math.max(maxStones, currentStones);
        }
        
        memo[i][m] = maxStones;
        return maxStones;
    }
}
```

class Solution:
    def stoneGameII(self, piles: List[int]) -> int:
        n = len(piles)
        suffix_sum = [0] * (n + 1)
        for i in range(n - 1, -1, -1):
            suffix_sum[i] = suffix_sum[i + 1] + piles[i]
        
        from functools import lru_cache
        
        @lru_cache(None)
        def dp(i: int, m: int) -> int:
            if i >= n:
                return 0
            if 2 * m >= n - i:
                return suffix_sum[i]
            
            max_stones = 0
            for x in range(1, 2 * m + 1):
                if i + x > n:
                    break
                new_m = max(m, x)
                max_stones = max(max_stones, suffix_sum[i] - dp(i + x, new_m))
            return max_stones
