# 2958. Length of Longest Subarray With at Most K Frequency

## Problem Statement

You are given an integer array `nums` and an integer `k`.

The **frequency** of an element `x` is the number of times it occurs in an array.

An array is called **good** if the frequency of each element in this array is **less than or equal to** `k`.

Return the length of the **longest good subarray** of `nums`.

A **subarray** is a contiguous non‑empty sequence of elements within an array.

### Examples

**Example 1**
```
Input: nums = [1,2,3,1,2,3,1,2], k = 2
Output: 6
Explanation: The longest good subarray is [1,2,3,1,2,3] (each element appears at most twice).
```

**Example 2**
```
Input: nums = [1,2,1,2,1,2,1,2], k = 1
Output: 2
Explanation: The longest good subarray is [1,2] (each element appears at most once).
```

**Example 3**
```
Input: nums = [5,5,5,5,5,5,5], k = 4
Output: 4
Explanation: The longest good subarray is [5,5,5,5] (frequency of 5 equals 4).
```

---

## Approach

We use a **sliding window** with two pointers (`left` and `right`) and a **frequency map** to track counts of elements in the current window.

### Steps

1. Expand the window by moving `right` and adding `nums[right]` to the frequency map.
2. If the frequency of `nums[right]` exceeds `k`, we shrink the window from the left until that frequency becomes `≤ k`. This maintains the invariant that the window is always **good**.
3. At each valid window, update the answer with the current length `(right - left + 1)`.

Since each element is added and removed at most once, the solution runs in **O(n)** time.

---

## Java Solution

```java
class Solution {
    public int maxSubarrayLength(int[] nums, int k) {
        Map<Integer, Integer> freq = new HashMap<>();
        int left = 0;
        int maxLen = 0;

        for (int right = 0; right < nums.length; right++) {
            // Add current element to the window
            freq.put(nums[right], freq.getOrDefault(nums[right], 0) + 1);

            // If frequency exceeds k, shrink from left
            while (freq.get(nums[right]) > k) {
                freq.put(nums[left], freq.get(nums[left]) - 1);
                left++;
            }

            // Update the maximum length
            maxLen = Math.max(maxLen, right - left + 1);
        }

        return maxLen;
    }
}
```

---

## Complexity Analysis

- **Time Complexity:** `O(n)` – each element is processed at most twice (once when added, once when removed).
- **Space Complexity:** `O(n)` – in the worst case, the frequency map stores all distinct elements of the array.

---

## Key Takeaways

- The sliding window technique efficiently handles subarray constraints with frequency limits.
- The frequency map is essential for tracking counts in the current window.
- Shrinking the window only when necessary ensures we always consider the longest valid subarray ending at each position.
