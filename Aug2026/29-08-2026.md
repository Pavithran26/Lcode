# 2948. Make Lexicographically Smallest Array by Swapping Elements

[LeetCode Problem Link](https://leetcode.com/problems/make-lexicographically-smallest-array-by-swapping-elements/)

## Problem Statement

You are given a **0-indexed** array of positive integers `nums` and a positive integer `limit`.  

In one operation, you can choose any two indices `i` and `j` and swap `nums[i]` and `nums[j]` if `|nums[i] - nums[j]| <= limit`.  

Return the **lexicographically smallest** array that can be obtained by performing the operation any number of times.

An array `a` is lexicographically smaller than an array `b` if in the first position where they differ, `a` has an element that is less than the corresponding element in `b`.

### Example 1

```
Input: nums = [1,5,3,9,8], limit = 2
Output: [1,3,5,8,9]
```

### Example 2

```
Input: nums = [1,7,6,18,2,1], limit = 3
Output: [1,6,7,18,1,2]
```

### Example 3

```
Input: nums = [1,7,28,19,10], limit = 3
Output: [1,7,28,19,10]
```

### Constraints

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= limit <= 10^9`

---

## Approach

The key observation is that if two values differ by at most `limit`, they can be swapped directly. More generally, if values can be connected through a chain where each step is within `limit`, then all values in that connected component can be arbitrarily permuted.

### Algorithm

1. **Sort indices by value**  
   Create an array of indices `[0, 1, ..., n-1]` and sort them based on the corresponding values in `nums`. This allows us to process values in increasing order.

2. **Group values into connected components**  
   Iterate through the sorted indices. Start a new group whenever the difference between the current value and the previous value exceeds `limit`. All indices within the same group belong to values that are mutually reachable.

3. **Sort indices within each group**  
   For each group, collect the original indices and sort them in ascending order. This ensures that when we assign the smallest value in the group to the smallest index, we achieve the lexicographically smallest array for those positions.

4. **Place values back**  
   For each group, assign the sorted values (which are the values of the indices in the group, sorted by value) to the sorted positions in ascending order. This yields the lexicographically smallest arrangement for that group.

5. **Return the resulting array.**

### Why this works

- Because swaps are allowed between any two values with difference ≤ `limit`, the group defined by consecutive differences ≤ `limit` forms a connected component where any permutation is achievable.
- To get the lexicographically smallest array globally, we must make the earliest positions as small as possible. By sorting indices and assigning the smallest values to the smallest indices **within each independent component**, we achieve that without affecting other components (since components are independent).

### Complexity

- **Time:** `O(n log n)` – dominated by sorting the indices and sorting positions within each group (which total `O(n log n)` in worst case).
- **Space:** `O(n)` – for the index array and auxiliary arrays.

## Code (Java)

```java
import java.util.*;

class Solution {
    public int[] lexicographicallySmallestArray(int[] nums, int limit) {
        int n = nums.length;
        Integer[] idx = new Integer[n];
        for (int i = 0; i < n; i++) {
            idx[i] = i;
        }
        Arrays.sort(idx, (a, b) -> Integer.compare(nums[a], nums[b]));

        int[] ans = new int[n];
        int i = 0;

        while (i < n) {
            int j = i + 1;
            while (j < n && nums[idx[j]] - nums[idx[j - 1]] <= limit) {
                j++;
            }

            int[] positions = new int[j - i];
            for (int k = 0; k < positions.length; k++) {
                positions[k] = idx[i + k];
            }
            Arrays.sort(positions);

            for (int k = 0; k < positions.length; k++) {
                ans[positions[k]] = nums[idx[i + k]];
            }

            i = j;
        }

        return ans;
    }
}
```

## Example Walkthrough

**Example 1:**  
`nums = [1,5,3,9,8], limit = 2`

- Sorted indices by value:  
  values: [1,3,5,8,9] → indices: [0,2,1,4,3]
- Groups (difference ≤ 2):
  - Group1: values [1,3,5] → indices [0,2,1] → sorted positions [0,1,2] → assign values [1,3,5] → positions 0,1,2 become 1,3,5
  - Group2: values [8,9] → indices [4,3] → sorted positions [3,4] → assign values [8,9] → positions 3,4 become 8,9
- Result: `[1,3,5,8,9]`

## Notes

- The algorithm works for large inputs up to `10^5` elements.
- It is a classic “connectivity” approach using value differences as edges.
- All operations are performed without actually swapping; we directly construct the optimal arrangement.
