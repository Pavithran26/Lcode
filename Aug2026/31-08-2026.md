# LeetCode 2058. Find the Minimum and Maximum Number of Nodes Between Critical Points

## Problem Statement

A **critical point** in a linked list is defined as either a **local maxima** or a **local minima**.

- A node is a **local maxima** if its value is strictly greater than both the previous and next nodes.
- A node is a **local minima** if its value is strictly smaller than both the previous and next nodes.

> **Note:** A node can only be a critical point if it has both a previous and a next node.

Given the head of a singly linked list, return an array `[minDistance, maxDistance]` where:
- `minDistance` is the minimum distance between any two distinct critical points.
- `maxDistance` is the maximum distance between any two distinct critical points.

If there are fewer than two critical points, return `[-1, -1]`.

---

### Example 1

```
Input: head = [3,1]
Output: [-1,-1]
Explanation: There are no critical points.
```

### Example 2

```
Input: head = [5,3,1,2,5,1,2]
Output: [1,3]
Explanation: Critical points are at positions 3, 5, and 6.
minDistance = 1 (between positions 5 and 6)
maxDistance = 3 (between positions 3 and 6)
```

### Example 3

```
Input: head = [1,3,2,2,3,2,2,2,7]
Output: [3,3]
Explanation: Critical points are at positions 2 and 5.
Both min and max distances are 3.
```

---

## Approach

We can solve this problem in a **single pass** using a three-pointer technique:

1. Traverse the linked list while keeping track of three consecutive nodes: `prev`, `curr`, and `next`.
2. For each `curr` node (starting from the second node), check if it forms a local maxima or minima.
3. Maintain the following variables:
   - `firstPos` – position of the first critical point.
   - `lastPos` – position of the last critical point.
   - `prevPos` – position of the previously found critical point (used to compute the minimum distance).
   - `minDist` – the smallest distance between two consecutive critical points.
   - `count` – number of critical points found.
4. If the current node is a critical point:
   - If it's the first one, set `firstPos`.
   - Otherwise, update `minDist` with `pos - prevPos`.
   - Update `prevPos`, `lastPos`, and increment `count`.
5. After traversal:
   - If `count < 2`, return `[-1, -1]`.
   - Otherwise, `maxDistance = lastPos - firstPos`.
   - Return `[minDist, maxDist]`.

## Code (Java)

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public int[] nodesBetweenCriticalPoints(ListNode head) {
        if (head == null || head.next == null) {
            return new int[]{-1, -1};
        }

        ListNode prev = head;
        ListNode curr = head.next;
        
        int firstPos = -1;
        int lastPos = -1;
        int prevPos = -1;
        int minDist = Integer.MAX_VALUE;
        int count = 0;
        int pos = 2; // curr is the second node

        while (curr.next != null) {
            ListNode next = curr.next;

            boolean isCritical = false;

            // Check local maximum
            if (prev.val < curr.val && curr.val > next.val) {
                isCritical = true;
            }
            // Check local minimum
            if (prev.val > curr.val && curr.val < next.val) {
                isCritical = true;
            }

            if (isCritical) {
                if (count == 0) {
                    firstPos = pos;
                } else {
                    minDist = Math.min(minDist, pos - prevPos);
                }
                prevPos = pos;
                lastPos = pos;
                count++;
            }

            prev = curr;
            curr = next;
            pos++;
        }

        if (count < 2) {
            return new int[]{-1, -1};
        }

        int maxDist = lastPos - firstPos;
        return new int[]{minDist, maxDist};
    }
}
```

## Complexity Analysis

| Metric           | Complexity |
|------------------|------------|
| **Time**         | O(n) – Single pass through the linked list |
| **Space**        | O(1) – Only a few integer variables used |

---

## Key Points to Remember

- The positions are **1-indexed** (the first node is position 1).
- A node with equal consecutive values (e.g., `2, 2`) cannot be a critical point because the condition requires **strict** inequality.
- The minimum distance is only computed between **consecutive** critical points in the list, while the maximum is computed between the first and the last.
