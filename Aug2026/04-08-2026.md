# 3731. Find Missing Elements

## Problem Statement

You are given an integer array `nums` consisting of **unique integers**.

Originally, `nums` contained every integer within a certain range. However, some integers might have gone missing from the array.

The smallest and largest integers of the original range are still present in `nums`.

Return a sorted list of all the missing integers in this range. If no integers are missing, return an empty list.

---

### Examples

#### Example 1:
```
Input: nums = [1,4,2,5]
Output: [3]
```
**Explanation:**  
The smallest integer is `1` and the largest is `5`, so the full range should be `[1,2,3,4,5]`. Among these, only `3` is missing.

#### Example 2:
```
Input: nums = [7,8,6,9]
Output: []
```
**Explanation:**  
The smallest integer is `6` and the largest is `9`, so the full range is `[6,7,8,9]`. All integers are already present, so no integer is missing.

#### Example 3:
```
Input: nums = [5,1]
Output: [2,3,4]
```
**Explanation:**  
The smallest integer is `1` and the largest is `5`, so the full range should be `[1,2,3,4,5]`. The missing integers are `2`, `3`, and `4`.

---

## Constraints

- `2 <= nums.length <= 100`
- `1 <= nums[i] <= 100`

---

## Approach

1. **Find the range**: Traverse the array to find the minimum (`min`) and maximum (`max`) values.
2. **Store present elements**: Insert all elements of `nums` into a `HashSet` for O(1) lookup.
3. **Find missing numbers**: Iterate from `min + 1` to `max - 1` (since the endpoints are guaranteed to be present). If a number is not in the set, add it to the result list.
4. Return the result list (it will be naturally sorted because we iterate in increasing order).

### Complexity Analysis

- **Time Complexity**: `O(n)` where `n` is the length of `nums`.
  - Finding min/max and building the set takes `O(n)`.
  - Iterating over the range takes `O(max - min)` which is at most `O(100)` given constraints, but effectively `O(n)` in the worst case.
- **Space Complexity**: `O(n)` for the `HashSet`.

---

## Java Solution

```java
import java.util.*;

class Solution {
    public List<Integer> findMissingElements(int[] nums) {
        Set<Integer> present = new HashSet<>();
        int min = Integer.MAX_VALUE;
        int max = Integer.MIN_VALUE;

        // Find min, max and store present numbers
        for (int num : nums) {
            present.add(num);
            min = Math.min(min, num);
            max = Math.max(max, num);
        }

        List<Integer> missing = new ArrayList<>();

        // Check every number between min and max (exclusive)
        for (int num = min + 1; num < max; num++) {
            if (!present.contains(num)) {
                missing.add(num);
            }
        }

        return missing;
    }
}
```

---

## Edge Cases Considered

- All numbers present → returns empty list.
- Only min and max present → returns all numbers in between.
- Numbers are unsorted → still works because we compute min/max.
- Constraints guarantee unique integers and that min/max are present.

---

## Alternative Approach (Using Sorting)

Sort the array and then check for gaps between consecutive elements. However, the `HashSet` approach is simpler and more efficient.
