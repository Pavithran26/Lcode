# 1386. Cinema Seat Allocation

## Problem Statement

A cinema has `n` rows of seats, numbered from `1` to `n`. Each row has exactly 10 seats, numbered from `1` to `10`.

You are given a 2D integer array `reservedSeats`, where `reservedSeats[i] = [rowi, seati]` means that the seat `seati` in row `rowi` is already reserved.

A four-person group must be assigned to four seats in the same row. The group can be seated in one of the following seat blocks:

- seats `2, 3, 4, 5`
- seats `4, 5, 6, 7`
- seats `6, 7, 8, 9`

A block can be used only if none of its seats are reserved. Each seat can be assigned to at most one group.

Return the **maximum** number of four‑person groups that can be assigned.

### Example 1

```
Input: n = 3, reservedSeats = [[1,2],[1,3],[1,8],[2,6],[3,1],[3,10]]
Output: 4
```

### Example 2

```
Input: n = 2, reservedSeats = [[2,1],[1,8],[2,6]]
Output: 2
```

### Example 3

```
Input: n = 4, reservedSeats = [[4,3],[1,4],[4,6],[1,7]]
Output: 4
```

---

## Approach

We need to maximize the number of groups. Since each row has only 10 seats and the possible blocks are fixed, we can process each row independently.

### Key Observations

- There are only **three possible blocks** per row:
  - Left block: seats 2–5
  - Middle block: seats 4–7
  - Right block: seats 6–9
- A row without any reserved seats can accommodate **two groups** (left block + right block). The middle block cannot be combined with either left or right because they overlap.
- For a row with reserved seats, we check the availability of each block using bitmasks.

### Bitmask Representation

We map each seat number `col` (1‑based) to a bit position `(col - 1)`:

- Seat 1 → bit 0
- Seat 2 → bit 1
- …
- Seat 10 → bit 9

We precompute bitmasks for the three blocks:

| Block      | Seats        | Binary mask (bits 0‑9)        |
|------------|--------------|-------------------------------|
| Left       | 2,3,4,5      | `0b0000011110` (bits 1‑4 set) |
| Middle     | 4,5,6,7      | `0b0001111000` (bits 3‑6 set) |
| Right      | 6,7,8,9      | `0b0111100000` (bits 5‑8 set) |

For each row that has at least one reserved seat, we store its mask (OR of all reserved seat bits). Rows with no reserved seats are not stored.

### Algorithm

1. **Build a `Map<Integer, Integer>`** where the key is a row number and the value is the bitmask of reserved seats in that row.
2. **Initialise answer**:
   - Each row with **zero reserved seats** can always take 2 groups.
   - So start with `ans = 2 * (n - rowMask.size())`.
3. **Process each row with reserved seats**:
   - Check if the left block is free: `(mask & LEFT_MASK) == 0`.
   - Check if the middle block is free: `(mask & MID_MASK) == 0`.
   - Check if the right block is free: `(mask & RIGHT_MASK) == 0`.
   - **If both left and right are free** → we can place 2 groups (left and right) → add 2.
   - **Else if at least one block is free** → we can place 1 group → add 1.
   - (The case where no block is free adds nothing.)
4. Return `ans`.

### Complexity

- **Time:** `O(m)` where `m = reservedSeats.length`, because we iterate over the reservations once and then over the distinct rows that appear. In the worst case `m ≤ 10⁴`.
- **Space:** `O(distinct rows)` for the hashmap, up to `O(m)`.

## Java Solution

```java
import java.util.*;

class Solution {
    public int maxNumberOfFamilies(int n, int[][] reservedSeats) {
        // Map each row to a bitmask of reserved seats
        Map<Integer, Integer> rowMask = new HashMap<>();
        for (int[] seat : reservedSeats) {
            int row = seat[0];
            int col = seat[1];
            rowMask.put(row, rowMask.getOrDefault(row, 0) | (1 << (col - 1)));
        }

        // Precomputed masks for the three blocks (bits 0‑9)
        int leftBlock  = (1 << 1) | (1 << 2) | (1 << 3) | (1 << 4);  // seats 2,3,4,5
        int midBlock   = (1 << 3) | (1 << 4) | (1 << 5) | (1 << 6);  // seats 4,5,6,7
        int rightBlock = (1 << 5) | (1 << 6) | (1 << 7) | (1 << 8);  // seats 6,7,8,9

        // Rows with no reservations always fit 2 groups
        int ans = 2 * (n - rowMask.size());

        // Process only rows that have at least one reservation
        for (int mask : rowMask.values()) {
            boolean leftFree  = (mask & leftBlock) == 0;
            boolean midFree   = (mask & midBlock) == 0;
            boolean rightFree = (mask & rightBlock) == 0;

            // Left and right can be combined; middle cannot be combined with either
            if (leftFree && rightFree) {
                ans += 2;
            } else if (leftFree || midFree || rightFree) {
                ans += 1;
            }
        }

        return ans;
    }
}
```

## Conclusion

The bitmask approach is efficient and simple because each row has only 10 seats. The key is to note that rows without any reserved seats contribute the maximum (2 groups) and rows with reservations are handled individually using masks.
