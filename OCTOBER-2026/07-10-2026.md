# LeetCode 301 — Remove Invalid Parentheses

## Problem Statement

Given a string `s` that contains parentheses and letters, remove the minimum number of invalid parentheses to make the input string valid.

Return **a list of unique strings** that are valid with the **minimum number of removals**. You may return the answer in **any order**.

---

## Examples

### Example 1
```
Input:  s = "()())()"
Output: ["(())()","()()()"]
```

### Example 2
```
Input:  s = "(a)())()"
Output: ["(a())()","(a)()()"]
```

### Example 3
```
Input:  s = ")("
Output: [""]
```

---

## Constraints

- `1 <= s.length <= 25`
- `s` consists of lowercase English letters and parentheses `'('` and `')'`.
- There will be at most **20 parentheses** in `s`.

---

## Approach — BFS (Level-by-Level Removal)

Since we must remove the **minimum** number of parentheses, a **Breadth-First Search (BFS)** is a natural fit. Each "level" of BFS represents removing one more character than the previous level. The first level at which we find valid strings gives us the minimum removals.

### Algorithm

1. Initialize a **queue** with the original string `s`.
2. Maintain a **visited set** to avoid processing duplicate strings.
3. Maintain a boolean flag `found` — set to `true` once we discover any valid string at the current level.
4. While the queue is not empty:
   - Pop a string `curr`.
   - If `curr` is valid → add it to the result and set `found = true`.
   - If `found` is `true` → skip expansion (we don't want deeper levels).
   - Otherwise, for each parenthesis in `curr`, generate a new string by removing that character. If not already visited, add it to the queue and visited set.
5. Return the result list.

### Validity Check

A string is valid if:
- Scanning left to right, the count of `'('` never falls below the count of `')'` (i.e., the balance never goes negative).
- At the end, the balance is exactly `0`.

## Java Solution

```java
class Solution {
    public List<String> removeInvalidParentheses(String s) {
        List<String> result = new ArrayList<>();
        if (s == null) return result;

        Set<String> visited = new HashSet<>();
        Queue<String> queue = new LinkedList<>();
        queue.offer(s);
        visited.add(s);

        boolean found = false;

        while (!queue.isEmpty()) {
            String curr = queue.poll();

            if (isValid(curr)) {
                result.add(curr);
                found = true;
            }

            // If valid strings found at this level, don't go deeper
            if (found) continue;

            // Try removing each parenthesis
            for (int i = 0; i < curr.length(); i++) {
                char c = curr.charAt(i);
                if (c != '(' && c != ')') continue;

                String next = curr.substring(0, i) + curr.substring(i + 1);
                if (!visited.contains(next)) {
                    visited.add(next);
                    queue.offer(next);
                }
            }
        }

        return result;
    }

    private boolean isValid(String s) {
        int count = 0;
        for (char c : s.toCharArray()) {
            if (c == '(') count++;
            else if (c == ')') {
                count--;
                if (count < 0) return false;
            }
        }
        return count == 0;
    }
}
```

## Complexity Analysis

| Metric | Complexity |
|--------|------------|
| Time   | `O(2^n)` — in the worst case, where `n` is the number of parentheses (≤ 20) |
| Space  | `O(2^n)` — for the queue and visited set |

## Walkthrough — `s = "()())()"`

| Level | Strings Generated | Valid? |
|-------|-------------------|--------|
| 0 | `"()())()"` | ❌ |
| 1 | `")())()"`, `"())()"`, `"()()()"`, `"()())("`, `"()())()"`, ... | ✅ `"()()()"`, `"(())()"` found |
| 2+ | *(skipped — `found = true`)* | — |

**Result:** `["()()()", "(())()"]` (order may vary)

---

## Key Insights

- **BFS guarantees minimum removals** because we explore strings with fewer removals first.
- The **`visited` set** prevents redundant work and infinite loops.
- The **`found` flag** stops us from exploring deeper (i.e., removing more characters than necessary) once we've found at least one valid string at the current level.
- This approach naturally handles **duplicates** — strings appearing multiple times are only processed once.

---

## Alternative Approaches

| Approach | Notes |
|----------|-------|
| **DFS + Backtracking** | Compute the number of misplaced `(` and `)` first, then DFS removing exactly that many. More code but often faster in practice. |
| **BFS (this solution)** | Simpler to reason about; directly yields minimum removals. |
