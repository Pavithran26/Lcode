# 1541. Minimum Insertions to Balance a Parentheses String

## 📋 Problem Statement

Given a parentheses string `s` containing only the characters `'('` and `')'`. A parentheses string is **balanced** if:

1. Any left parenthesis `'('` must have a corresponding **two consecutive right parentheses** `'))'`.
2. Left parenthesis `'('` must go **before** the corresponding two consecutive right parenthesis `'))'`.

In other words, we treat `'('` as an **opening parenthesis** and `'))'` as a **closing parenthesis**.

### Examples of Balanced Strings
- `"())"`
- `"())(())))"`
- `"(())())))"`

### Examples of Unbalanced Strings
- `")()"`
- `"()))"`
- `"(()))"`

You can insert the characters `'('` and `')'` at **any position** of the string to balance it if needed.

**Return the minimum number of insertions needed to make `s` balanced.**

---

## 🔍 Examples

### Example 1
```
Input:  s = "(()))"
Output: 1
```
**Explanation:** The second `'('` has two matching `'))'`, but the first `'('` has only `')'` matching. We need to add one more `')'` at the end of the string to be `"(())))"`, which is balanced.

### Example 2
```
Input:  s = "())"
Output: 0
```
**Explanation:** The string is already balanced.

### Example 3
```
Input:  s = "))())("
Output: 3
```
**Explanation:** Add `'('` to match the first `'))'`, add `'))'` to match the last `'('`.

---

## 📌 Constraints

- `1 <= s.length <= 10^5`
- `s` consists of `'('` and `')'` only.

---

## 💡 Approach — Greedy / One Pass

We scan the string from **left to right** while tracking two counters:

| Variable    | Meaning                                  |
|-------------|------------------------------------------|
| `open`      | Number of unmatched `'('` so far         |
| `insertions`| Total insertions needed so far           |

### Logic

While iterating through the string:

- **If we see `'('`** → increment `open`.

- **If we see `')'`**:
  - **If the next character is also `')'`** → we have a `"))"` pair (a valid closing unit).
    - If `open > 0` → consume one `'('` (`open--`).
    - Else → insert a `'('` (`insertions++`).
    - Skip the next `')'` (`i += 2`).
  - **If the next character is NOT `')'`** (single `')'`):
    - Insert one `')'` to complete the pair (`insertions++`).
    - If `open > 0` → consume one `'('` (`open--`).
    - Else → also insert a `'('` (`insertions++`).
    - Advance by 1 (`i++`).

- **At the end**, each remaining `'('` needs **two `')'`** → add `2 * open` to `insertions`.

---

## 🧑‍💻 Java Solution

```java
class Solution {
    public int minInsertions(String s) {
        int open = 0;        // unmatched '('
        int insertions = 0;  // total insertions needed
        int i = 0;
        int n = s.length();

        while (i < n) {
            if (s.charAt(i) == '(') {
                open++;
                i++;
            } else { // s.charAt(i) == ')'
                if (i + 1 < n && s.charAt(i + 1) == ')') {
                    // We have a "))" pair
                    if (open > 0) {
                        open--; // match with an existing '('
                    } else {
                        insertions++; // insert a '(' to match this pair
                    }
                    i += 2; // skip both ')'
                } else {
                    // Single ')' — need one more ')' to form "))"
                    insertions++; // add a ')'
                    if (open > 0) {
                        open--; // now matched
                    } else {
                        insertions++; // also need to insert a '('
                    }
                    i++;
                }
            }
        }

        // Each remaining '(' needs two ')'
        insertions += open * 2;

        return insertions;
    }
}
```

## 🧪 Walkthrough

### Example 1: `s = "(()))"`

| Step | Char | Action                       | open | insertions |
|------|------|------------------------------|------|------------|
| i=0  | `(`  | Increment open               | 1    | 0          |
| i=1  | `(`  | Increment open               | 2    | 0          |
| i=2  | `)`  | Next is `)` → pair, open--   | 1    | 0          |
| i=4  | `)`  | Single `)` → insert `)`, open-- | 0  | 1          |
| End  | —    | open = 0 → add 0             | 0    | 1          |

**Output:** `1` ✅

### Example 2: `s = "())"`

| Step | Char | Action                       | open | insertions |
|------|------|------------------------------|------|------------|
| i=0  | `(`  | Increment open               | 1    | 0          |
| i=1  | `)`  | Next is `)` → pair, open--   | 0    | 0          |
| End  | —    | open = 0 → add 0             | 0    | 0          |

**Output:** `0` ✅

---

### Example 3: `s = "))())("`

| Step | Char | Action                          | open | insertions |
|------|------|---------------------------------|------|------------|
| i=0  | `)`  | Next is `)` → pair, open=0 → insert `(` | 0 | 1     |
| i=2  | `(`  | Increment open                  | 1    | 1          |
| i=3  | `)`  | Next is `)` → pair, open--      | 0    | 1          |
| i=5  | `(`  | Increment open                  | 1    | 1          |
| End  | —    | open = 1 → add 1×2 = 2          | 0    | 3          |

**Output:** `3` ✅

| Metric | Complexity | Reason                              |

| Space  | **O(1)**   | Only a few integer counters used    |

## 🔑 Key Insights

1. **Two consecutive `')'`** = one complete closing unit → matches one `'('`.
2. **Single `')'`** = broken closing unit → must insert one `')'`; and if no `'('` is available, insert one `'('` too.
3. **At the end**, each leftover `'('` needs **2 insertions** (`'))'`).
4. Greedy works because we always resolve the earliest possible mismatch.
