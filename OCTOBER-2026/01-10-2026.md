# LeetCode 20: Valid Parentheses

## Problem Statement

Given a string `s` containing just the characters `'('`, `')'`, `'{'`, `'}'`, `'['` and `']'`, determine if the input string is valid.

An input string is valid if:

1. Open brackets must be closed by the same type of brackets.
2. Open brackets must be closed in the correct order.
3. Every close bracket has a corresponding open bracket of the same type.

### Examples

**Example 1:**
```
Input: s = "()"
Output: true
```

**Example 2:**
```
Input: s = "()[]{}"
Output: true
```

**Example 3:**
```
Input: s = "(]"
Output: false
```

**Example 4:**
```
Input: s = "([])"
Output: true
```

**Example 5:**
```
Input: s = "([)]"
Output: false
```

### Constraints

- `1 <= s.length <= 10^4`
- `s` consists of parentheses only `'()[]{}'`

---

## Solution

### Approach: Stack-Based Matching

The problem is a classic **stack** problem. Brackets must be closed in the correct order — the most recently opened bracket must be closed first (LIFO). A stack naturally models this behavior.

### Algorithm

1. Create an empty stack.
2. Create a hash map that maps each **closing** bracket to its corresponding **opening** bracket:
   - `')' → '('`
   - `'}' → '{'`
   - `']' → '['`
3. Iterate through each character in the string:
   - If the character is a **closing bracket**:
     - Pop the top element from the stack.
     - If the popped element does not match the expected opening bracket → return `false`.
   - Otherwise (it's an **opening bracket**):
     - Push it onto the stack.
4. After the loop, return `true` if the stack is empty, otherwise `false`.

### PHP Implementation

```php
class Solution {

    /**
     * @param String $s
     * @return Boolean
     */
    function isValid($s) {
        $stack = [];
        $map = [
            ')' => '(',
            '}' => '{',
            ']' => '['
        ];

        for ($i = 0; $i < strlen($s); $i++) {
            $char = $s[$i];

            if (isset($map[$char])) {
                // Closing bracket - check if it matches top of stack
                $top = array_pop($stack);
                if ($top !== $map[$char]) {
                    return false;
                }
            } else {
                // Opening bracket - push onto stack
                $stack[] = $char;
            }
        }

        // Valid only if stack is empty (all brackets matched)
        return empty($stack);
    }
}
```

## Dry Run

### Example: `s = "([])"`

| Step | Char | Action | Stack |
|------|------|--------|-------|
| 1 | `(` | Push | `[` `(` `]` |
| 2 | `[` | Push | `[` `(` `,` `[` `]` |
| 3 | `]` | Pop `[`, matches `]` | `[` `(` `]` |
| 4 | `)` | Pop `(`, matches `)` | `[]` |
| 5 | — | Stack empty → `true` | — |

### Example: `s = "([)]"`

| Step | Char | Action | Stack |
|------|------|--------|-------|
| 1 | `(` | Push | `[` `(` `]` |
| 2 | `[` | Push | `[` `(` `,` `[` `]` |
| 3 | `)` | Pop `[`, expected `(` → mismatch | ❌ Return `false` |

| Metric | Complexity | Explanation |
|--------|------------|-------------|
| **Time** | O(n) | Single pass through the string of length `n`. |
| **Space** | O(n) | Worst case: all characters are opening brackets (e.g., `"((((("`). |

---

## Edge Cases

| Case | Input | Output | Reason |
|------|-------|--------|--------|
| Empty string | `""` | `true` | No brackets to match. |
| Single opening | `"("` | `false` | Unmatched opening bracket. |
| Single closing | `")"` | `false` | Closing bracket with no opener. |
| Starts with closing | `")("` | `false` | Pop on empty stack returns `null` → mismatch. |
| Nested valid | `"{[()]}"` | `true` | Properly nested and closed. |
| Interleaved | `"([)]"` | `false` | Wrong closing order. |

---

## Key Takeaways

- **Stack** is the ideal data structure for problems involving nested or ordered matching.
- Mapping **closing → opening** brackets simplifies the comparison logic.
- Always check the **stack is empty** at the end — this catches unmatched opening brackets.
- Using `array_pop()` on an empty array returns `null` in PHP, which safely fails the match check.
