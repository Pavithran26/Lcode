# LeetCode 856. Score of Parentheses

## Problem Statement

Given a **balanced parentheses string** `s`, return the **score** of the string.

The score of a balanced parentheses string is based on the following rules:

1. `"()"` has score **1**.
2. `AB` has score `A + B`, where `A` and `B` are balanced parentheses strings.
3. `(A)` has score `2 * A`, where `A` is a balanced parentheses string.

---

## Examples

### Example 1
```
Input: s = "()"
Output: 1
```

### Example 2
```
Input: s = "(())"
Output: 2
```

### Example 3
```
Input: s = "()()"
Output: 2
```

---

## Constraints

- `2 <= s.length <= 50`
- `s` consists of only `'('` and `')'`.
- `s` is a **balanced** parentheses string.

---

## Approach: Stack-Based Simulation

We simulate the nested structure of parentheses using a **stack**. Each element in the stack represents the score accumulated at a particular nesting depth.

### Algorithm

1. Initialize a stack and push `0` (the base score).
2. Traverse each character `c` in `s`:
   - If `c == '('`:
     - Push `0` onto the stack (start a new nesting level).
   - If `c == ')'`:
     - Pop the top value `top` (score of the inner content).
     - Compute `score = max(2 * top, 1)`:
       - If `top == 0`, the pair is `"()"` → score is `1`.
       - Otherwise, it's `(A)` → score is `2 * A`.
     - Pop the next value, add `score` to it, and push the result back.
3. Return the last remaining value in the stack.

---

## Java Solution

```java
class Solution {
    public int scoreOfParentheses(String s) {
        Stack<Integer> stack = new Stack<>();
        stack.push(0); // Base score

        for (char c : s.toCharArray()) {
            if (c == '(') {
                stack.push(0);
            } else {
                int top = stack.pop();
                int score = Math.max(2 * top, 1);
                stack.push(stack.pop() + score);
            }
        }

        return stack.pop();
    }
}
```

## Dry Run

### Input: `"(())"`

| Step | Char | Action                          | Stack        |
|------|------|---------------------------------|--------------|
| 1    | `(`  | Push 0                          | `[0, 0]`     |
| 2    | `(`  | Push 0                          | `[0, 0, 0]`  |
| 3    | `)`  | Pop 0 → score = max(0,1) = 1    | `[0, 1]`     |
| 4    | `)`  | Pop 1 → score = max(2,1) = 2    | `[2]`        |

**Result:** `2` ✅

---

### Input: `"()()"`

| Step | Char | Action                          | Stack        |
|------|------|---------------------------------|--------------|
| 1    | `(`  | Push 0                          | `[0, 0]`     |
| 2    | `)`  | Pop 0 → score = 1               | `[1]`        |
| 3    | `(`  | Push 0                          | `[1, 0]`     |
| 4    | `)`  | Pop 0 → score = 1               | `[2]`        |

**Result:** `2` ✅

## Complexity Analysis

| Metric           | Value |
|------------------|-------|
| Time Complexity  | O(n)  |
| Space Complexity | O(n)  |

- **Time:** We iterate through the string once, performing O(1) stack operations per character.
- **Space:** In the worst case (e.g., `"((((...))))"`), the stack holds up to `n/2 + 1` elements.

---

## Alternative Approach (Without Stack)

We can also solve this using a **depth counter**, since the score contribution of each `"()"` pair is `2^(depth)`.

```java
class Solution {
    public int scoreOfParentheses(String s) {
        int score = 0;
        int depth = 0;

        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(') {
                depth++;
            } else {
                depth--;
                if (s.charAt(i - 1) == '(') {
                    score += 1 << depth; // 2^depth
                }
            }
        }

        return score;
    }
}
```

**Idea:** Every primitive `"()"` at depth `d` contributes `2^d` to the total score.

| Metric           | Value |
|------------------|-------|
| Time Complexity  | O(n)  |
| Space Complexity | O(1)  |

## Key Takeaways

- The problem is a classic example of **stack-based parsing** of nested structures.
- The recurrence `(A) = 2 * A` and `AB = A + B` maps naturally to a stack simulation.
- An O(1) space solution exists by tracking **depth** and summing `2^depth` for each leaf `"()"`.
