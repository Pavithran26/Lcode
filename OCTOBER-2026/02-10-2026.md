# LeetCode 22: Generate Parentheses

## Problem Description

Given `n` pairs of parentheses, write a function to generate all combinations of well-formed parentheses.

### Examples

**Example 1:**
```text
Input: n = 3
Output: ["((()))","(()())","(())()","()(())","()()()"]
```

Example 2:

```text
Input: n = 1
Output: ["()"]
```

Constraints

· 1 <= n <= 8

---

Approach: Backtracking

We can solve this problem using a backtracking algorithm. The idea is to build the string character by character, making choices at each step while adhering to the rules of well-formed parentheses.

Rules for Valid Parentheses:

1. We can add an opening parenthesis ( as long as we haven't used all n opening parentheses. (open < n)
2. We can add a closing parenthesis ) only if the number of closing parentheses used is strictly less than the number of opening parentheses used. (close < open)
3. The base case is when the length of the current string reaches 2 * n, meaning we have used exactly n opening and n closing parentheses.

Algorithm Steps:

1. Initialize an empty List<String> to store the results.
2. Create a recursive backtrack function that takes the results list, a StringBuilder for the current string, counts for open and close parentheses, and the maximum n.
3. Base Case: If current.length() == 2 * n, add the string to the results list and return.
4. Recursive Step 1 (Open): If open < n, append (, increment open, and recursively call backtrack. After the call returns, remove the last character (backtrack).
5. Recursive Step 2 (Close): If close < open, append ), increment close, and recursively call backtrack. After the call returns, remove the last character (backtrack).

---

Complexity Analysis

· Time Complexity: O(4^n / sqrt(n)). This is the n-th Catalan number, which represents the exact number of valid well-formed parentheses combinations. The recursion explores this many valid paths.
· Space Complexity: O(n). The recursion stack depth can go up to 2n, and the StringBuilder holds up to 2n characters. Auxiliary space for the output list is not included in this analysis.

---

Java Implementation

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> generateParenthesis(int n) {
        List<String> result = new ArrayList<>();
        // Start backtracking with an empty StringBuilder, 0 open, 0 close, and max = n
        backtrack(result, new StringBuilder(), 0, 0, n);
        return result;
    }

    private void backtrack(List<String> result, StringBuilder current, int open, int close, int max) {
        // Base case: if the current string length is 2*n, we have a valid combination
        if (current.length() == max * 2) {
            result.add(current.toString());
            return;
        }

        // Choice 1: Add an opening parenthesis if we haven't reached the limit
        if (open < max) {
            current.append('(');
            backtrack(result, current, open + 1, close, max);
            // Backtrack: remove the last character to explore other paths
            current.deleteCharAt(current.length() - 1);
        }

        // Choice 2: Add a closing parenthesis if it won't make the string invalid
        if (close < open) {
            current.append(')');
            backtrack(result, current, open, close + 1, max);
            // Backtrack
            current.deleteCharAt(current.length() - 1);
        }
    }
}
```
