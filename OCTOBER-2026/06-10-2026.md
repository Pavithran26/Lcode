# 921. Minimum Add to Make Parentheses Valid

## Problem Statement

A parentheses string is valid if and only if:

- It is the empty string, **or**
- It can be written as `AB` (A concatenated with B), where A and B are valid strings, **or**
- It can be written as `(A)`, where A is a valid string.

You are given a parentheses string `s`. In one move, you can insert a parenthesis at any position of the string.

Return the **minimum number of moves** required to make `s` valid.

---

## Examples

### Example 1
```
Input:  s = "())"
Output: 1
```
**Explanation:** Insert one `(` at the beginning → `"(())"`.

### Example 2
```
Input:  s = "((("
Output: 3
```
**Explanation:** Append three `)` at the end → `"((()))"`.

---

## Constraints

- `1 <= s.length <= 1000`
- `s[i]` is either `'('` or `')'`

---

## Approach

We use a **single-pass counting** technique:

1. Maintain two counters:
   - `open` → number of unmatched `(`
   - `close` → number of unmatched `)`
2. Iterate through each character:
   - If `'('` → increment `open`
   - If `')'`:
     - If `open > 0` → pair it (decrement `open`)
     - Else → increment `close` (this `)` needs a matching `(` inserted)
3. The answer is `open + close`.

### Why It Works

- Every unmatched `)` needs an opening `(` inserted **before** it.
- Every unmatched `(` at the end needs a closing `)` inserted **after** it.
- Both cases are independent, so we simply add them.

---

## Solution (Java)

```java
class Solution {
    public int minAddToMakeValid(String s) {
        int open = 0;
        int close = 0;

        for (char c : s.toCharArray()) {
            if (c == '(') {
                open++;
            } else {
                if (open > 0) {
                    open--;
                } else {
                    close++;
                }
            }
        }

        return open + close;
    }
}
```

---

## Dry Run

### Input: `s = "())"`

| Step | Char | open | close | Action              |
|------|------|------|-------|---------------------|
| 1    | `(`  | 1    | 0     | Increment open      |
| 2    | `)`  | 0    | 0     | Pair with `(`       |
| 3    | `)`  | 0    | 1     | No match → close++  |

**Result:** `open + close = 0 + 1 = 1`

### Input: `s = "((("`

| Step | Char | open | close |
|------|------|------|-------|
| 1    | `(`  | 1    | 0     |
| 2    | `(`  | 2    | 0     |
| 3    | `(`  | 3    | 0     |

**Result:** `open + close = 3 + 0 = 3`

---

## Complexity Analysis

| Metric | Value | Reason                              |
|--------|-------|-------------------------------------|
| Time   | O(n)  | Single pass through the string      |
| Space  | O(1)  | Only two integer counters used      |

## Alternative Approach (Stack)

You can also solve this using a stack, but the counting method is more space-efficient.

```java
class Solution {
    public int minAddToMakeValid(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        int close = 0;

        for (char c : s.toCharArray()) {
            if (c == '(') {
                stack.push(c);
            } else {
                if (!stack.isEmpty()) {
                    stack.pop();
                } else {
                    close++;
                }
            }
        }

        return stack.size() + close;
    }
}
```

## Key Takeaways

- 💡 **Greedy matching** works perfectly for parentheses problems.
- 💡 Two counters replace the need for a stack here — O(1) space.
- 💡 The answer is simply `unmatched_opening + unmatched_closing`.
- 💡 Same pattern applies to similar problems like **32. Longest Valid Parentheses** and **1249. Minimum Remove to Make Valid Parentheses**.
