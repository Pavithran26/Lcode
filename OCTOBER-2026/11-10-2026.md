# LeetCode 2778. Sum of Squares of Special Elements

## Problem Statement

You are given a **1-indexed** integer array `nums` of length `n`.

An element `nums[i]` of `nums` is called **special** if `i` divides `n`, i.e. `n % i == 0`.

Return the **sum of the squares** of all special elements of `nums`.

---

## Examples

### Example 1

**Input:**
```java
nums = [1,2,3,4]
```

**Output:**
```java
21
```

**Explanation:**

There are exactly 3 special elements in `nums`:
- `nums[1]` since `1` divides `4`
- `nums[2]` since `2` divides `4`
- `nums[4]` since `4` divides `4`

Sum of squares:
```
nums[1]² + nums[2]² + nums[4]²
= 1² + 2² + 4²
= 1 + 4 + 16
= 21
```

---

### Example 2

**Input:**
```java
nums = [2,7,1,19,18,3]
```

**Output:**
```java
63
```

**Explanation:**

There are exactly 4 special elements in `nums`:
- `nums[1]` since `1` divides `6`
- `nums[2]` since `2` divides `6`
- `nums[3]` since `3` divides `6`
- `nums[6]` since `6` divides `6`

Sum of squares:
```
nums[1]² + nums[2]² + nums[3]² + nums[6]²
= 2² + 7² + 1² + 3²
= 4 + 49 + 1 + 9
= 63
```

## Constraints

| Constraint | Value |
|------------|-------|
| `n == nums.length` | `1 <= n <= 50` |
| `nums[i]` | `1 <= nums[i] <= 50` |

---

## Solution

### Java

```java
class Solution {
    public int sumOfSquares(int[] nums) {
        int n = nums.length;
        int sum = 0;

        for (int i = 1; i <= n; i++) {
            if (n % i == 0) {
                sum += nums[i - 1] * nums[i - 1];
            }
        }

        return sum;
    }
}
```

---

## Approach

The problem is straightforward:

1. The array is **1-indexed** in the problem, so index `i` corresponds to `nums[i - 1]` in the 0-indexed Java array.
2. Loop `i` from `1` to `n`.
3. If `n % i == 0`, then `i` divides `n`, so `nums[i - 1]` is a **special element**.
4. Add its **square** to the running sum.
5. Return the sum.

### Walkthrough (`nums = [1,2,3,4]`, `n = 4`)

| i | n % i | Special? | Value | Square |
|---|-------|----------|-------|--------|
| 1 | 0     | ✅ Yes   | 1     | 1      |
| 2 | 0     | ✅ Yes   | 2     | 4      |
| 3 | 1     | ❌ No    | —     | —      |
| 4 | 0     | ✅ Yes   | 4     | 16     |

**Sum = 1 + 4 + 16 = 21** ✅

## Complexity Analysis

| Metric | Complexity | Reason |
|--------|------------|--------|
| **Time** | `O(n)` | Single pass through the array |
| **Space** | `O(1)` | Only a constant amount of extra space |

## Key Takeaways

- Remember the array is **1-indexed** in the problem statement — always convert to 0-indexed when accessing Java arrays.
- A divisor check `n % i == 0` determines whether an index is special.
- The problem is a simple linear scan with constant extra space.
