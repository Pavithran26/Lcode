# LeetCode 3723. Maximize Sum of Squares of Digits

## Problem

You are given two positive integers `num` and `sum`.

A positive integer `n` is **good** if it satisfies both:
- The number of digits in `n` is exactly `num`.
- The sum of digits in `n` is exactly `sum`.

The **score** of a good integer `n` is the sum of the squares of its digits.

Return a string denoting the good integer `n` that achieves the maximum score. If there are multiple possible integers, return the maximum one. If no such integer exists, return an empty string.

## Examples

### Example 1
```
Input: num = 2, sum = 3
Output: "30"
Explanation:
Good integers: 12, 21, 30.
Scores: 1² + 2² = 5, 2² + 1² = 5, 3² + 0² = 9.
Maximum score is 9, achieved by 30.
```

### Example 2
```
Input: num = 2, sum = 17
Output: "98"
Explanation:
Good integers: 89, 98.
Both have score 8² + 9² = 145.
The maximum integer is 98.
```

### Example 3
```
Input: num = 1, sum = 10
Output: ""
Explanation:
There are no 1-digit numbers whose digits sum to 10.
```

## Approach

To maximize the sum of squares for a fixed digit sum, we want the digits to be as large as possible. The square function is convex, so concentrating the sum into fewer, larger digits yields a higher sum of squares.

1. If `sum > 9 * num`, it is impossible to form such a number. Return `""`.
2. Compute `nines = sum / 9` and `remainder = sum % 9`.
3. Append `nines` copies of `'9'`.
4. If `remainder > 0`, append the digit `remainder`.
5. Fill the remaining positions with `'0'` until the length is `num`.

This construction also produces the lexicographically largest string among those with the maximum score.

## Complexity

- **Time:** `O(num)` — building the result string.
- **Space:** `O(num)` — storing the result.

## Java Solution

```java
class Solution {
    public String maxSumOfSquares(int num, int sum) {
        // Maximum possible sum of digits with exactly num digits
        if (sum > 9 * num) {
            return "";
        }

        int nines = sum / 9;
        int remainder = sum % 9;

        StringBuilder ans = new StringBuilder(num);

        for (int i = 0; i < nines; i++) {
            ans.append('9');
        }

        if (remainder > 0) {
            ans.append((char) ('0' + remainder));
        }

        while (ans.length() < num) {
            ans.append('0');
        }

        return ans.toString();
    }
}
```
