# LeetCode 32. Longest Valid Parentheses

## Problem Description

Given a string containing just the characters `'('` and `')'`, return the length of the longest valid (well-formed) parentheses substring.

### Examples

**Example 1:**
```text
Input: s = "(()"
Output: 2
Explanation: The longest valid parentheses substring is "()".
```

Example 2:

```text
Input: s = ")()())"
Output: 4
Explanation: The longest valid parentheses substring is "()()".
```

Example 3:

```text
Input: s = ""
Output: 0
```

Constraints

· 0 <= s.length <= 3 * 10^4
· s[i] is '(', or ')'.

---

Solution Approach: Two Passes (Space Optimized)

This solution uses a Two-Pass Scanning technique to achieve O(N) time complexity and O(1) auxiliary space complexity.

Why Two Passes?

A single left-to-right pass fails for strings like (() because the extra open parenthesis prevents the counters from ever being equal, even though the substring () is valid. Similarly, a single right-to-left pass fails for strings like ()).

By scanning the string twice (once left-to-right, and once right-to-left), we ensure that we correctly identify valid substrings regardless of whether the extra unmatched parentheses are at the beginning or the end.

Algorithm:

1. Initialize left, right, and maxLen to 0.
2. Left-to-Right Pass:
   · Increment left for '(', and right for ')'.
   · If left == right, update maxLen = max(maxLen, 2 * right).
   · If right > left, reset left and right to 0 (invalid substring).
3. Right-to-Left Pass:
   · Reset left and right to 0.
   · Traverse from the end of the string to the beginning.
   · Increment left for '(', and right for ')'.
   · If left == right, update maxLen = max(maxLen, 2 * left).
   · If left > right, reset left and right to 0 (invalid substring).
4. Return maxLen.

Complexity Analysis

· Time Complexity: O(N), where N is the length of the string. We traverse the string twice.
· Space Complexity: O(1), as we only use a few integer variables.

---

Java Implementation

```java
class Solution {
    public int longestValidParentheses(String s) {
        int left = 0, right = 0, maxLen = 0;
        
        // First pass: Left to Right
        // Handles cases like "()()" and extra '(' at the end (e.g., "(()")
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(') {
                left++;
            } else {
                right++;
            }
            
            if (left == right) {
                maxLen = Math.max(maxLen, 2 * right);
            } else if (right > left) {
                // Reset counters if we have more closing brackets than opening ones
                left = 0;
                right = 0;
            }
        }
        
        // Second pass: Right to Left
        // Handles cases like extra ')' at the beginning (e.g., "())")
        left = 0;
        right = 0;
        for (int i = s.length() - 1; i >= 0; i--) {
            if (s.charAt(i) == '(') {
                left++;
            } else {
                right++;
            }
            
            if (left == right) {
                maxLen = Math.max(maxLen, 2 * left);
            } else if (left > right) {
                // Reset counters if we have more opening brackets than closing ones
                left = 0;
                right = 0;
            }
        }
        
        return maxLen;
    }
}
```

Alternative Approach (Using Stack)

If O(N) space is acceptable, a Stack-based approach is also a very intuitive way to solve this problem. It involves pushing indices onto a stack.

```java
import java.util.Stack;

class Solution {
    public int longestValidParentheses(String s) {
        Stack<Integer> stack = new Stack<>();
        stack.push(-1); // Base index for the first valid substring
        int maxLen = 0;
        
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(') {
                stack.push(i);
            } else {
                stack.pop();
                if (stack.isEmpty()) {
                    stack.push(i); // Mark starting point for next valid substring
                } else {
                    maxLen = Math.max(maxLen, i - stack.peek());
                }
            }
        }
        return maxLen;
    }
}
```

· Time Complexity: O(N)
· Space Complexity: O(N) due to the stack.
