# 2897. Apply Operations on Array to Maximize Sum of Squares

## Problem Statement

You are given a **0-indexed** integer array `nums` and a positive integer `k`.

You can perform the following operation on the array **any number of times**:

- Choose any two **distinct** indices `i` and `j`.
- Simultaneously update:
  - `nums[i] = nums[i] AND nums[j]`
  - `nums[j] = nums[i] OR nums[j]`

Here, `AND` denotes the bitwise AND operation, and `OR` denotes the bitwise OR operation.

You have to choose `k` elements from the final array and calculate the **sum of their squares**.

Return the **maximum sum of squares** you can achieve.

Since the answer can be very large, return it **modulo** `10^9 + 7`.

---

## Examples

### Example 1

**Input:**
```
nums = [2,6,5,8], k = 2
```

**Output:**
```
261
```

**Explanation:**
- Choose `i = 0` and `j = 3`:
  - `nums[0] = 2 AND 8 = 0`
  - `nums[3] = 2 OR 8 = 10`
  - Resulting array: `[0,6,5,10]`
- Choose `i = 2` and `j = 3`:
  - `nums[2] = 5 AND 10 = 0`
  - `nums[3] = 5 OR 10 = 15`
  - Resulting array: `[0,6,0,15]`
- Pick `15` and `6`: `15² + 6² = 225 + 36 = 261`

### Example 2

**Input:**
```
nums = [4,5,4,7], k = 3
```

**Output:**
```
90
```

**Explanation:**
- No operations needed.
- Pick `7, 5, 4`: `7² + 5² + 4² = 49 + 25 + 16 = 90`

---

## Constraints

- `1 <= k <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

---

## Approach

### Key Observations

1. **Sum Preservation**
   ```
   (a AND b) + (a OR b) = a + b
   ```
   The total sum of the array never changes.

2. **Bit Redistribution**
   - Bits set in **both** numbers remain in both.
   - Bits set in **only one** number get moved to the `OR` result.
   - This means any set bit can be freely moved between numbers.

3. **Maximizing Sum of Squares**
   - With a fixed total sum, sum of squares is maximized when values are as **unequal** as possible.
   - So we want to concentrate bits into `k` large numbers.

### Algorithm

1. Count the number of set bits at each bit position (0 to 30) across all numbers.
2. Build `k` numbers greedily:
   - For each of the `k` numbers, take one bit from every bit position that still has remaining bits.
   - This forms the largest possible values.
3. Compute the sum of squares modulo `10^9 + 7`.

---

## Java Solution

```java
class Solution {
    public int maxSum(List<Integer> nums, int k) {
        int MOD = 1_000_000_007;
        int[] bitCount = new int[31];

        // Step 1: Count set bits at each position
        for (int num : nums) {
            for (int b = 0; b < 31; b++) {
                if (((num >> b) & 1) == 1) {
                    bitCount[b]++;
                }
            }
        }

        long result = 0;

        // Step 2: Build k largest numbers greedily
        for (int i = 0; i < k; i++) {
            long val = 0;
            for (int b = 0; b < 31; b++) {
                if (bitCount[b] > 0) {
                    val |= (1L << b);
                    bitCount[b]--;
                }
            }
            result = (result + (val % MOD) * (val % MOD)) % MOD;
        }

        return (int) result;
    }
}
```

## Complexity Analysis

| Metric | Complexity |
|--------|------------|
| Time   | `O(31 × (n + k))` ≈ `O(n + k)` |
| Space  | `O(31)` = `O(1)` |

Where `n = nums.length`.

## Dry Run

### Input: `nums = [2,6,5,8]`, `k = 2`

Binary representations:
```
2  = 0010
6  = 0110
5  = 0101
8  = 1000
```

Bit counts:
| Bit | Count |
|-----|-------|
| 0   | 1     |
| 1   | 2     |
| 2   | 2     |
| 3   | 1     |

Build number 1 (take all available bits):
```
bits 0,1,2,3 → 1111 = 15
```

Build number 2:
```
remaining bits: bit1=1, bit2=1
bits 1,2 → 0110 = 6
```

Sum of squares:
```
15² + 6² = 225 + 36 = 261 ✅
```

---

## Why Greedy Works

- The operation preserves the **multiset of bits** across all numbers.
- We can rearrange them freely between positions.
- To maximize `Σ xᵢ²` with a fixed `Σ xᵢ`, we want extreme values (concentrated bits).
- Greedily building each of the `k` numbers with one bit from every available position yields the `k` largest possible numbers.
