# LeetCode 1021. Remove Outermost Parentheses

## Problem Statement

A **valid parentheses string** is either:
- Empty `""`
- `"(" + A + ")"` where `A` is a valid parentheses string
- `A + B` where both `A` and `B` are valid parentheses strings

A valid parentheses string `s` is **primitive** if it is non-empty and cannot be split into `s = A + B` where both `A` and `B` are non-empty valid parentheses strings.

Given a valid parentheses string `s`, consider its **primitive decomposition**: `s = P₁ + P₂ + ... + Pₖ`, where each `Pᵢ` is a primitive valid parentheses string.

Return `s` after **removing the outermost parentheses** of every primitive string in the decomposition.

---

## Examples

### Example 1
```
Input:  s = "(()())(())"
Output: "()()()"

Explanation:
Primitive decomposition: "(()())" + "(())"
Remove outer parens:     "()()"   + "()"   = "()()()"
```

### Example 2
```
Input:  s = "(()())(())(()(()))"
Output: "()()()()(())"

Explanation:
Primitive decomposition: "(()())" + "(())" + "(()(()))"
Remove outer parens:     "()()"   + "()"   + "()(())" = "()()()()(())"
```

### Example 3
```
Input:  s = "()()"
Output: ""

Explanation:
Primitive decomposition: "()" + "()"
Remove outer parens:     ""   + ""   = ""
```

---

## Constraints

- `1 <= s.length <= 10⁵`
- `s[i]` is either `'('` or `')'`
- `s` is a valid parentheses string

---

## Solution (Java)

```java
class Solution {
    public String removeOuterParentheses(String s) {
        StringBuilder result = new StringBuilder();
        int depth = 0;

        for (char c : s.toCharArray()) {
            if (c == '(') {
                if (depth > 0) {
                    result.append(c);
                }
                depth++;
            } else {
                depth--;
                if (depth > 0) {
                    result.append(c);
                }
            }
        }

        return result.toString();
    }
}
```

---

## Approach

Use a **depth counter** to track the current nesting level while scanning the string:

1. **On `'('`:**
   - If `depth > 0`, this parenthesis is **not** the outermost — append it.
   - Increment `depth`.
2. **On `')'`:**
   - Decrement `depth` first.
   - If `depth > 0`, this parenthesis is **not** the outermost — append it.

The outermost `'('` of each primitive has `depth == 0` before incrementing, and the outermost `')'` has `depth == 0` after decrementing — both are skipped automatically.

### Dry Run for `s = "(()())(())"`

| Char | depth before | Action          | depth after |
|------|--------------|-----------------|-------------|
| `(`  | 0            | skip (outermost)| 1           |
| `(`  | 1            | append `(`      | 2           |
| `)`  | 2            | append `)`      | 1           |
| `(`  | 1            | append `(`      | 2           |
| `)`  | 2            | append `)`      | 1           |
| `)`  | 1            | skip (outermost)| 0           |
| `(`  | 0            | skip (outermost)| 1           |
| `(`  | 1            | append `(`      | 2           |
| `)`  | 2            | append `)`      | 1           |
| `)`  | 1            | skip (outermost)| 0           |

Result: `"()()" + "()" = "()()()"` ✅

| Metric  | Complexity | Reason |
|---------|------------|--------|
| Time    | **O(n)**   | Single pass through the string |

---

## Key Insight

> The primitive decomposition is implicitly handled by the `depth` counter — every time `depth` returns to `0`, a primitive string has just ended, and the next `'('` starts a new one. No explicit splitting is needed.
