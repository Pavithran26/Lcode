# 2913. Subarrays Distinct Element Sum of Squares I

**Difficulty:** Easy  
**Topics:** Array, Hash Table, Counting

## Problem

You are given a **0-indexed** integer array `nums`.

The **distinct count** of a subarray `nums[i..j]` is the number of distinct values in that subarray.

Return the sum of the squares of the distinct counts of all subarrays of `nums`.

A subarray is a contiguous non-empty sequence of elements within an array.

## Examples

### Example 1

```text
Input: nums = [1,2,1]
Output: 15
Explanation:
The six subarrays are:
[1]      -> 1 distinct value
[2]      -> 1 distinct value
[1]      -> 1 distinct value
[1,2]    -> 2 distinct values
[2,1]    -> 2 distinct values
[1,2,1]  -> 2 distinct values

Sum of squares = 1² + 1² + 1² + 2² + 2² + 2² = 15
```

### Example 2

```text
Input: nums = [1,1]
Output: 3
Explanation:
The three subarrays are:
[1]    -> 1 distinct value
[1]    -> 1 distinct value
[1,1]  -> 1 distinct value

Sum of squares = 1² + 1² + 1² = 3
```

## Constraints

- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`

## Approach

Use two nested loops to generate every subarray.

- Fix the starting index `i`.
- Expand the ending index `j` from `i` to `n - 1`.
- Maintain a `HashSet` to track distinct elements in the current subarray `nums[i..j]`.
- For each subarray, add `set.size() * set.size()` to the answer.

Since the constraints are small (`n <= 100`), an `O(n²)` solution is efficient enough.

## Complexity Analysis

- **Time Complexity:** `O(n²)`
- **Space Complexity:** `O(n)` for the `HashSet`

## Java Solution

```java
import java.util.List;
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int sumCounts(List<Integer> nums) {
        int n = nums.size();
        int sum = 0;

        for (int i = 0; i < n; i++) {
            Set<Integer> set = new HashSet<>();
            for (int j = i; j < n; j++) {
                set.add(nums.get(j));
                int distinct = set.size();
                sum += distinct * distinct;
            }
        }

        return sum;
    }
}
```

## Notes

- The problem can also be solved with other brute-force variations.
- The key observation is that we only need the number of distinct elements in each subarray.
- A sliding window or more advanced technique is not required for this version.
